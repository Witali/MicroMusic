# Codec2 3200 → AVR: продолжение работ после R2 (25.10.2026)

## Что удалось восстановить

Последняя завершённая ветка: `Codec2_ATtiny13A_Quality_R2_2026-10-24.zip`. Она содержит 959-Б однокадровую демопрошивку, 35 Б глобальных данных, 3 резонатора, оценку ISR/тактов и аудио двух тестовых потоков. В каталоге `Codec2_Tiny13_Quality_R2/` — распакованные оригиналы, НЕ ИЗМЕНЕНЫ. Дополнительно исходный ZIP включается в handoff-архив. На реальном ATtiny13A полного потока не проверяли. Нет AVR GCC; для исследовательского объекта применён LLVM AVR.

## Новая работа в этом продолжении

1. `codec2_3200_full_parameters.c`: отдельный оригинально ориентированный парсер всех полей стандартного 64-битного кадра, в том числе всех **10 индексов LSPD** и накопленных значений частот в единицах 25 Гц. Без float и MUL. Это НЕ полная распаковка аудио.
2. `test_full_parameters.py`: сравнение с сохранённым независимым парсером `fields()` на **365 реальных архивных кадрах** (218 EN + 147 RU) и **10 000 случайных кадрах**: 10 365/10 365 совпали все 14 поля и 10 восстановленных частот.
3. AVR LLVM `-Os` успешно создал `build/parameters_avr.o`: **332 байта секции .text**, без `.data`/`.bss`. Размер функции пока дополнителен к R2, не размер законченной прошивки.
4. `compare_resonators.py` и `results/comparison.csv`: повторно исследованы 3, 4 и 5 резонаторов по двум потокам при равных/взвешенных уровнях. Простое включение 4-го или 5-го резонатора **не увеличило STOI** ни для английского, ни для русского.

| Режим модели | STOI EN | STOI RU |
|---|---:|---:|
| 3 резонатора, модель R2 | 0.5991 | 0.5958 |
| 4, равные | 0.5907 | 0.5775 |
| 4, взвешенные | 0.5969 | 0.5886 |
| 5, равные | 0.5707 | 0.5621 |
| 5, взвешенные | 0.5901 | 0.5781 |
| 5, с приоритетом низких | 0.5907 | 0.5857 |

Это **host-модели**, не AVR-прошивки. Качество измерялось против оригинального декодированного Codec2; результаты ограничены двумя синтетическими фразами. Эти метрики не являются замером на живой речи.

## Главный вывод

Текущая R2 НЕ реализует оригинальное восстановление **амплитуд гармоник** из LPC-спектра (`aks_to_M2`), **фазовый синтез** и окно overlap-add. Простое добавление резонаторов не заменяет восстановление этих амплитуд. Следующим значимым шагом станет реализация фиксированно-точечного спектрального огибающего генератора из всех 10 LSP: преобразование LSP→LPC и вычисление амплитуд **небольшого числа гармоник** по формуле оригинала, с аппроксимацией фазы. Это нужно сначала реализовать и оценить на ПК. Режим 9,6 МГц, без MUL: аппаратная жизнеспособность не доказана.

**Важный барьер:** у однокадровой R2 оставалось 65 Б Flash (959/1024) и 29 Б SRAM до стека. Отдельный универсальный 10-LSP парсер занимает 332 байта машинного кода LLVM, значит совместить его с R2 без удаления/серьёзного перераспределения кода невозможно. Нельзя заявлять, что этот новый модуль «уже помещается в Tiny13». Дальнейшие качественные эксперименты разумно проводить с лимитом памяти временно снятым и затем использовать профиль/ASM оптимизацию.

## Запуск

```
python3 test_full_parameters.py
python3 compare_resonators.py
clang --target=avr -mmcu=attiny13 -Os -ffreestanding -fno-builtin -c codec2_3200_full_parameters.c -o build/parameters_avr.o
```

## Сохранение

- R2 **не изменена**; экспериментальная ветка отдельная.
- В ZIP упакованы текущие разработки, результаты, объектный файл, архив R2 и полный каталог R2 для следующего агента.
