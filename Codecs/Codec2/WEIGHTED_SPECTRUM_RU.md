# Fixed-point спектр взвешенного LPC

Отдельный `src/spectral_decoder.c` сохраняет все стадии Codec2 3200,
но вычисляет gamma-взвешенный LPC-спектр целочисленно. Он также использует
целочисленные inverse FFT и степень постфильтра. Основной LPC-спектр
в знаменателе, часть постфильтров и фаза пока float. Предыдущие C-реализации
`hybrid_postfilter.c` и `compact_decoder.c` остаются явно выбираемыми путями.

## Разрядность выбирается совместно со следующим этапом

Критерий сохранён: SNR >=50 дБ, ошибка <=256 единиц PCM16 относительно
upstream. Проверяются 11 333 кадра / 1 813 280 отсчётов, обе архивные фразы
отдельно после reset и состояние RNG после каждого кадра. Локальная ошибка
спектра сама по себе недостаточна: пороги фонового постфильтра управляют RNG.

Первый поиск из девяти вариантов сохраняет исходный sparse radix-four граф:
16/24/32 бита данных × Q14/Q22/Q30 twiddle. Минимум 24/Q22 проходит, но первый
AVR smoke медленнее предыдущего декодера. Эти исходники и отрицательная оценка
сохранены отдельным коммитом; `source_revision` в
[`weight-precision.json`](reports/weight-precision.json) и
[`weight-wide-baseline.json`](reports/weight-wide-baseline.json) указывает
историческую Git-ревизию, к которой относятся их хеши исходников.

Новый парный граф сокращает умножения, но меняет округления. Поэтому заново
проверены 18 сочетаний: те же разрядности спектра и twiddle, inverse FFT
с Q9 либо Q10. [`weight-direct-precision.json`](reports/weight-direct-precision.json)
содержит все результаты, PCM-хеши и покадровые сравнения RNG.

| Парный спектр / inverse FFT | Смешанный корпус: SNR | Макс. ошибка PCM16 | Результат |
| --- | ---: | ---: | --- |
| 16/Q22 / 16/Q10 | 1,29 дБ | 58 804 | RNG расходится с кадра 2303 |
| 24/Q14 / 16/Q10 | 12,10 дБ | 50 329 | RNG расходится с кадра 10072 |
| 24/Q22 / 16/Q9 | 54,52 дБ | 265 | Превышен предел ошибки |
| **24/Q22 / 16/Q10** | **57,54 дБ** | **237** | Проходит, RNG сохранён |
| 24/Q30 / 16/Q9 | 54,55 дБ | 248 | Проходит с более точным twiddle |
| 32/Q22 / 16/Q9 | 54,63 дБ | 248 | Проходит с более широкими данными |

Выбран минимум среди изученных конфигураций: сначала разрядность спектра,
затем его twiddle, затем inverse FFT. Это **24/Q22 + 16/Q10**, степень
постфильтра остаётся Q11/64. Повышение Q9 до Q10 не расширяет 16-битные данные
IFFT или 32-битные произведения. Прежний минимум Q9 остаётся верным для
прежнего графа; он не переносится автоматически на совместные аппроксимации.
Это ограниченный поиск по корпусу и машинным разрядностям, не доказательство
минимума каждого отдельного бита или достаточности для любой речи.

## Арифметика и сокращение работы

L1-сумма 11 gamma-взвешенных коэффициентов задаёт общий показатель блока.
Коэффициенты переводятся один раз на полукадр; суммарный масштаб оставляет
запас для промежуточных сумм. На host каждое сужение проверяется assert.
По умолчанию 24-битный диапазон хранится в `int32_t`, произведения — `int64_t`.
Это разрядность арифметического диапазона, а не трёхбайтная упаковка памяти.
Границы модуля возвращают float с масштабом степени двойки.

Шесть упакованных complex-входов дают Z(k) и Z(-k) за общий проход:
для первых четырёх ненулевых комплексных членов используются общие rr, ii,
ri, ir; последний вход вещественный, поэтому два произведения переиспользуются.
С учётом real-postprocess это 22 вещественных произведения на пару вместо 44
в прежнем раздельном графе. DC считается суммой коэффициентов. При k=128
сохранён порядок записи, где последний negative-выход заменяет positive.
Сопряжение округлённого положительного twiddle может отличаться от отдельно
округлённого отрицательного; новый граф проверяется как новая аппроксимация.

`weight_round.h` выполняет точное симметричное округление int64 через два
беззнаковых 32-битных слова. Смещение — `2^(q-1) - sign`, перенос учитывается
явно, отрицательных знаковых сдвигов нет. Контракт: 1<=q<=30, результат входит
в int32. Границы полуцелых значений и миллион случайных случаев сравнены
с прежним округлением по неотрицательному модулю.

Twiddle-таблицы Q22 занимают 3072 Б Flash и хранятся в int32. Они получены
из pinned binary32 KISS; полные BSD-условия сохранены. Аппаратные Flash-чтения
в `spectral_table_access.h` отделены от арифметики, CPU-макросы не подменяются.
Ручного ASM нет. Опции `--split24`, `--avr-int24`, `--legacy-round` оставляют
экспериментальные C-пути явно выбираемыми; они не включены в измеренный профиль.
Split24 проверен на 10 000 граничных и миллионе случайных комплексных операций.
Эксперимент с разложением 24×24 и трёхбайтным GNU-типом не дал ускорения
в ранних двухкадровых smoke; более узкий тип сам по себе не гарантирует выигрыш.

## Проверка настоящего AVR-кода

[`weight-kernel.json`](reports/weight-kernel.json) проверяет 512 одинаковых
наборов: нулевой, базисные и случайные коэффициенты с масштабами 2^-16..2^16.
Все 256 комплексных выходов каждого набора **побайтно совпали** между checked
native C и release AVR. Самостоятельное ядро с граничными преобразованиями:
8516 Б Flash, 2094 Б статики, 222 Б стека; среднее 2 061 088 тактов.
Это размеры и время отдельного harness, не всей программы.

Полный профиль записывается в [`spectral-decoder.json`](reports/spectral-decoder.json):
AVR-GCC 7.3.0 `-Os`, ATmega64A AVR5/MUL, обычный C ABI, реальные 4 КБ SRAM.
Границы получены из заголовка производителя и заданы линкеру; SP проверяется
на каждой инструкции, heap отсутствует, таблицы размещены в near Flash.
Синтетические архивные фразы проверяются целиком; активных IRQ и платы нет.
Основной LPC-спектр и фаза ещё требуют переноса. Реальное время пока не достигнуто.

| Полный поток AVR | Кадров / отсчётов | SNR к upstream | Макс. ошибка PCM16 |
| --- | ---: | ---: | ---: |
| EN | 218 / 34 880 | 60,03 дБ | 35 |
| RU | 147 / 23 520 | 59,94 дБ | 25 |

Полная программа: **31 194 Б Flash, 711 Б статики +2664 Б наблюдаемого стека
=3375 Б SRAM**, свободно **721 Б**. Прежний режим Q11-постфильтра занимал
26 276 Б Flash /3263 Б SRAM. Средние такты EN/RU: 12 754 415 /12 864 516 →
12 495 498 /12 604 418, снижение **2,03% /2,02%** на том же полном корпусе.
Худший кадр — **13 677 224 такта, 0,855 с при 16 МГц**, бюджет 20 мс
по-прежнему превышен. Более высокая точность PCM здесь включает Q10-IFFT;
нельзя приписывать всё изменение качества только взвешенному спектру.

Сохранены ненормализованные WAV:
[EN AVR](validation/spectral-3200/english_avr.wav),
[EN upstream](validation/spectral-3200/english_upstream.wav),
[RU AVR](validation/spectral-3200/russian_avr.wav),
[RU upstream](validation/spectral-3200/russian_upstream.wav),
[происхождение и хеши](validation/spectral-3200/PROVENANCE.json).
Это архивная синтетическая речь и ISA-симуляция, не запись с физической платы.

Повторение из корня рабочей копии после подготовки toolchain и базовых
корпусов по [DEVELOPMENT_RU.md](DEVELOPMENT_RU.md):

```sh
python Codecs/Codec2/tools/study_weight_precision.py --record
python Codecs/Codec2/tools/verify_weight_kernel.py --record
python Codecs/Codec2/tools/verify_spectral.py --record
python Codecs/Codec2/tools/export_decoder_audio.py --spectral
```

`--frames N` пригоден для smoke и запрещён вместе с `--record`.
Библиотечный API — `codec2_hybrid_init/decode`, состояние то же, что у
компактного декодера: 378 Б AVR / 380 Б host. Вместо `hybrid_postfilter.c`
выбираются `spectral_decoder.c` и `fixed_weight.c`; остальные исходники —
`fixed_inverse.c`, `fixed_fifth.c`, `compact_fft.c`, `parameters.c`, pinned
vendor `lsp.c`. Include-пути: `include/`, `src/`, vendor `src/`. C99, binary32,
`-fno-strict-aliasing`, без fast-math. Обязательные настройки данного профиля:

```text
CODEC2_WEIGHT_BITS=24 CODEC2_WEIGHT_TWIDDLE_Q=22 CODEC2_WEIGHT_DIRECT_PAIR=1
CODEC2_WEIGHT_SPLIT24=0 CODEC2_WEIGHT_AVR_INT24=0 CODEC2_WEIGHT_ROUND_LEGACY=0
CODEC2_FIXED_BITS=16 CODEC2_FIXED_TWIDDLE_Q=10 CODEC2_FIXED_WIDE_LAST=0
CODEC2_ROOT_Q=11 CODEC2_ROOT_TABLE_BITS=6
```

Отчёты сохраняют флаги и хеши; выбор одного исходника без этих настроек
не означает воспроизведение измеренного профиля.
