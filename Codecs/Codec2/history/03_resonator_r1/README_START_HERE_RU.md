# Codec2 3200 → ATtiny13A: три синусоидальных резонатора второго порядка

**Версия R1, 24.10.2026.** Target: ATtiny13A (classic tiny AVR), 9.6 MHz **CKDIV8 OFF**, 1024 байта Flash, 64 байта SRAM, без инструкции `MUL`.

## Что изменено относительно предыдущей версии

- Оставлен разбор **оригинального Codec2 3200**: 8 байт/20 мс, Gray код полей, высота тона, энергия, два признака звонкости, 10 индексов LSP (синтез использует первые шесть).
- Вместо 3 прямоугольных DDS применены **3 затухающих дискретных резонатора второго порядка** с синусоидальными колебаниями. Частота каждого резонатора определяется средним положением пары LSP. Они **не** привязываются к гармоникам f0: звуковой тракт работает как формантный резонатор, обрабатывающий периодический или шумовой сигнал.
- В звонких сегментах общий источник возбуждения создаёт короткие импульсы с частотой f0; в глухих сегментах используется псевдослучайное возбуждение.
- Не используется 512-точечная IFFT, плавающая точка, `MUL` или постоянная таблица сэмплов синуса. Нужна **31-байтовая таблица коэффициентов резонаторов**, от 0 до 3000 Гц с дискретностью ~100 Гц. Высота основного тона вычисляется точнее, чем в предыдущем 25-Гц квантовании (ошибка <0.54 Гц при точном 9.6 МГц).
- 16-битная программная процедура 8×8 Q7 (сдвиги/сложения) позволяет реализовать коэффициент `k` без аппаратного умножителя. Исправлено асимметричное округление (убрано значительное смещение постоянного уровня); суммарный PCM ограничивается перед удвоением громкости.
- Дорогой расчёт звука вынесен из ISR в основной цикл. Timer0 ISR обслуживает FIFO глубиной **один отсчёт**, не вычисляя резонаторы. Это принципиально, потому что обработка отсчёта может занимать >256 тактов, а переполнение Timer0 повторяется каждые 256 тактов.

## Математика

`v` и `y` — **8-битные знаковые** состояния, `k` — unsigned Q7 коэффициент из Flash.

```
v <- v - trunc(k*y/128) - sign(v)*ceil(abs(v)/16) + excitation
y <- y + trunc(k*v/128)
output <- saturate(2 * (y0 + y1 + y2), -128..126) + 128
```

Это *симплектический* цифровой осциллятор второго порядка с утечкой (резонатор, возбуждаемый импульсами). Без потерь его частота приблизительно описывается `k = 256 sin(pi * f / 8000)`, где `f` — частота формы синуса. Умножение использует симметричное округление к нулю; затухание округляется от нуля, чтобы не сохранять слишком большие малые колебания. Дополнительно защищён переход через предел положительного 8-битного значения при расчёте затухания. Это **не классический прямой IIR biquad** с коэффициентами `2r cos(w)` и `r²`, но линейное ядро по смыслу является устойчивой двумерной реализацией второго порядка и формирует затухающие синусоидальные компоненты. 8-битное квантование вызывает дополнительные гармоники и небольшие предельные циклы на уровне младших разрядов даже без возбуждения.

Коэффициенты F1/F2/F3 берутся из центров первых трёх пар LSP. Безопасный максимум таблицы: 3000 Гц (`k=237`, менее предела устойчивости `256`). Среднее значение пары вычисляется в целых 25-Гц единицах. Имеется квантование формантной частоты ~±50 Гц — это сознательный компромисс ради Flash.

## Результат сборки

| Показатель | Результат |
|---|---:|
| Машинная прошивка `.bin` / `.hex` | **821 байт** из 1024 |
| SRAM переменные `0x60..0x7D` | **30 байт** из 64 |
| Расход стека | До ~9 байт в предусмотренных путях, вместе с вызовами и ISR; не замер реальной платы |
| Типовой такт декодирования кадра | **893 такта** |
| Генерация PCM | **909–963 такта** на отсчёт из 1200 |
| Timer0 overflow ISR | **26–38 тактов**, среднее 28.56 |
| Бюджет грубой оценки пика | `963 + 5×38 + 20 = 1173` из 1200 тактов |
| Проверка ASM с независимой целочисленной моделью | **48 кадров / 7680 отсчётов**, полное совпадение |
| Проверка частоты IRQ | 750 overflow → 160 PCM обновлений (8 кГц) |

**Важно:** это результаты *интерпретации исходных AVR-инструкций и дизассемблированных путей*, а не замер на микроконтроллере. Ассемблер успешно собран LLVM 17 для `attiny13`, ELF-релокации явно разрешены, HEX проверен по контрольным суммам. `avr-gcc` в данной среде нет. Запаса по самому длинному пути мало, физические тесты обязательны.

## Как пользоваться

```sh
./BUILD_AND_TEST.sh
# На выходе: build/tiny13_resonator_demo.hex и .bin
```

Для прошивки на **ATtiny13A** проверь low fuse и тактирование: намерение — 9.6 МГц, CKDIV8 выключен (например low fuse `0x7A`, если остальные биты соответствуют необходимой схеме). Проект не записывает fuse самостоятельно.

Подключение: **PB1/OC0B → двухступенчатый RC-фильтр → разделительный конденсатор по постоянному току → вход усилителя**, а не динамик непосредственно на порт. Например два звена 3.3 кОм + 10 нФ (около 4.8 кГц каждое), при высокоомной нагрузке последующего усилителя; при каскадировании реальная АЧХ зависит от сопротивлений и нагрузки. PWM: 37.5 кГц, PCM: 8 кГц, 8-битная амплитуда, середина 128. Постоянная составляющая выходного сигнала не обязана быть точно нулевой из-за однополярного импульсного возбуждения; поэтому разделительный конденсатор полезен.

`demo_packet` — один реальный 8-байтовый кадр Codec2 3200, который **повторяется**. Это тест резонансного звука, **НЕ** проигрыватель целой фразы на чипе. Для полноценного воспроизведения потока нужно добавить внешнее хранилище / источник пакетов, безопасную передачу 8 байт каждые 20 мс и распределить разбор кадров без нарушения дедлайнов 8-кГц PCM. 1 КБ Flash и 64 байта SRAM делают такую интеграцию непростой.

## Прослушивание и проверка

- `audio/speech.c2zx.resonator_full.wav` — английская фраза 4.36 секунды, восстановленная **независимой целочисленной моделью** резонаторов.
- `audio/codec2_3200_8byte_frames.bin.resonator_full.wav` — русская тестовая синтезированная речь 2.94 секунды, той же моделью.
- `audio/*.resonator_avr.wav` — первые 0.48 секунды обеих записей, полученные **пошаговым исполнением AVR-ассемблера**. Эти отсчёты идентичны целочисленной модели.
- `audio/*resonator_ac_coupled.wav` — для прослушивания модель с программным низкочастотным разделительным фильтром (не исходный байтовый PWM).
- `audio/*square_old.wav` — копии старого прямоугольного варианта для сравнения, не запись железа.
- `tests/test_resonator.py` — тесты парсера, коэффициентов, точного PCM, тактов и Timer0 ISR; стандартная библиотека Python, без внешних pip-зависимостей.
- `tests/prototype.py` и `tests/sweep_damping.py` — необязательные исследовательские инструменты (нужен `numpy`).

## Что не реализовано

**Это не полный Codec2-декодер**. Хотя входной формат правильный, синтез отличается от эталона: не восстанавливаются все амплитуды гармоник и фазы Codec2, не используется 512-точечная IFFT, а только три приблизительные резонансные полосы из шести LSP. Качество и разборчивость речи не проверены субъективными прослушиваниями или STOI на настоящих записях. Численные тесты подтверждают правильность реализации выбранного *упрощённого* синтеза, а не совпадение звука с оригинальным Codec2.

Нет полной потоковой прошивки, динамического ввода, тестов непрерывных 20-мс кадров, аппаратного осциллографирования PB1 и измерений реальной загрузки с учётом асинхронного ввода.
