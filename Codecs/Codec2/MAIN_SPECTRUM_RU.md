# Основной LPC-спектр: точность около нулей

Исходная база — [взвешенный fixed-point спектр](WEIGHTED_SPECTRUM_RU.md),
IFFT16/Q10 и Q11-постфильтр. Основной LPC-спектр определяет одновременно
амплитуды и фазу. Его перенос нельзя оценивать только средней ошибкой FFT.

Первое исследование проверяет 18 вариантов: 16/24/32 бита данных,
Q14/Q22/Q30 twiddle, исходный radix-граф либо сокращённый парный граф.
[`analysis-precision.json`](reports/analysis-precision.json) и
[`analysis-radix-precision.json`](reports/analysis-radix-precision.json)
сохраняют полный PCM, покадровый RNG и спектральную диагностику. Ни один
вариант не проходит прежние SNR >=50 дБ / max <=256 PCM16 на 11 333 кадрах.

Вариант 24/Q22 проходит обе короткие фразы примерно с SNR 60 дБ, но на
смешанном корпусе меняет RNG с кадра 3090. Даже 32/Q30 при сохранённом RNG
даёт только 19,36 дБ /max 28 539 для парного графа и 20,94 дБ /max 28 155
для radix. При этом средний SNR **самого спектра** — 138,92 и 142,44 дБ.
Следовательно, локальный SNR FFT не подтверждает качество всего декодера.

На том же корпусе L1-сумма LPC достигает 1002,49, а минимальный модуль
исходного спектра равен нулю. Для 32/Q30 максимальная относительная ошибка
регуляризованной мощности составляет 9,87% /6,41% (парный/radix).
Это объясняет необходимость отдельно проверять глубокое взаимное вычитание
и фазовые решения; одной разрядности взвешенного спектра недостаточно.

`src/fixed_analysis.c` переиспользует арифметику `fixed_weight.c` с отдельными
настройками. `src/analysis_decoder.c` явно выбирает основное FFT через общий
интерфейс `codec2_analysis_forward`; прежний `spectral_decoder.c` остаётся
доступен. Ни один из этих простых кандидатов не принят как полный AVR-профиль.
Результаты здесь относятся к native Clang 24, binary32, без fast-math,
с проверками диапазона каждого сужения; это не AVR-замер и не реальное время.

```sh
python Codecs/Codec2/tools/study_analysis_precision.py --record
python Codecs/Codec2/tools/study_analysis_precision.py --radix --record
```

Следующий опыт должен сохранить целочисленный общий масштаб и порядок
округлений исходного FFT, прежде чем подбирать минимальную ширину сетки.
