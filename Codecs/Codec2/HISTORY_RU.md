## Проверки при импорте

- Все 134 распакованных файла и внешний ZIP сверены с исходным архивом.
  `.gitattributes` отключает преобразование переводов строк для этого каталога;
  дополнительная проверка читает байты непосредственно из Git.
- Содержимое R2 в `BASELINE_R2_UNMODIFIED.zip` совпадает с распакованной R2.
- Все имеющиеся файлы из исходных SHA256SUMS совпадают. В списке R1 есть два
  отсутствующих файла: `tests/__pycache__/codec2_test_common.cpython-313.pyc`
  и `tests/__pycache__/test_resonator.cpython-313.pyc`. Их нет уже в исходном
  ZIP R1; они не восстанавливались. Дублирование R1 в baseline повторяет
  ту же особенность.
- MIDI-файлов и исходной Git-истории внутри архивов не обнаружено.

Результаты повторного запуска доступных тестов при импорте вынесены в
[`IMPORT_VERIFICATION.json`](IMPORT_VERIFICATION.json). Старые аппаратные,
тактовые и качественные оценки следует читать с оговорками соответствующих
README. Побитовое совпадение модели с ASM-интерпретатором само по себе
не подтверждает непрерывную работу устройства с активными прерываниями.
