# Общий разбор спектра кадра LPX v9 на AVR

Обе сборки с ASM проверяют индексы спектра в том же диапазоне
1…32 или 1…64, в котором хранят их в SRAM. При чтении нового
спектра декодер сохраняет предыдущее значение по мере замены
каждого индекса. Повтор кадра использует уже готовые опоры LPC.
Первый кадр инициализирует кэш по текущему спектру.

| Целевая ASM-сборка | Flash до / после, без звука | Наибольшее среднее время с IRQ | SRAM / пиковый стек |
| --- | ---: | ---: | ---: |
| ATtiny88 | 4084–4085 / 4084–4085 Б | 1585,01 такта/отсчёт | 433 / 45 Б |
| ATmega328/328P | 4178–4179 / 4126–4127 Б | 787,91 такта/отсчёт | 433 / 35 Б |

На всех 22 нагрузках каждого чипа PWM совпал с C. Пропусков,
замедлений и роста пикового времени заполнения очереди не было.
Сравнение 60 корректных и повреждённых входов покрыло повтор,
абсолютные индексы, разности, нарушение порядка и усечение.
Все 18 образов WebUI совпали побайтно. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
