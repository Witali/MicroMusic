# Ширина Rice при обработке escape на ATtiny88

Для поддерживаемых спектральных профилей `bits=5+(profile&2)/2`,
`k=bits-4-delta` и `width=bits+delta`. Поэтому ширина escape равна
`6+(profile&2)-k`. Вычисление при обработке escape освобождает
байт, который удерживался на протяжении чтения префикса.
Смена арифметики на C ключом `LPX4_ENABLE_ASM=0` сохраняет общий
декодер Rice и прежний аргумент ширины.

| ATtiny88 | До (`0968d30c`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3692–3693 Б | 3684–3685 Б |
| Статическая SRAM / пиковый стек | 422 / 38 Б | 422 / 37 Б |
| Наибольшее среднее время с IRQ | 1578,69 такта/отсчёт | 1578,44 такта/отсчёт |

Все 22 нагрузки дали побитно прежние PWM с IRQ и без пропусков.
Среднее и пиковое время сократились во всех прогонах. Дополнительные
повреждённые потоки сравнили ошибки, остаток Flash и битовый буфер.
Прогоны двух ATmega и пересборка 18 образов WebUI прошли.
[Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц при 8 кГц, два сегмента
LPC, очередь 32 с начальным заполнением 24. Замеры выполнены в симуляторе.
