# Точное насыщение LPC на AVR25

Универсальная сборка ATtiny88 v9 с SRAM512 сохраняет LPX-параметры в файле.
Деление полиномиальной суммы к нулю проверяет диапазон по старшему байту
до сдвига. При насыщении результата синтеза `EOR` оставляет исходный
знак в переносе, чтобы восстановить средний байт через `ROR`.
Прибавление переноса заменяет точное значение −32768 на −32767.
Оптимизация выбирается для AVR25 v9 с включённым ASM. Переносимый
C-бэкенд остаётся доступен тем же ключом сборки.

| Показатель | База `bd8121a5` | После |
| --- | ---: | ---: |
| Программа, включая плеер и таблицы, без звука | 4434–4435 Б | 4418–4419 Б |
| Наибольшее среднее время декодера с IRQ | 1623,387289 такта | 1622,193879 такта |
| Статическая SRAM / пиковый стек | 433 / 50 Б | 433 / 50 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

На каждой из 22 нагрузок PWM побитно совпал с предыдущей прошивкой и
независимым C-декодером. Среднее процессорное время декодера с IRQ
сократилось на 0,001–1,193 такта на отсчёт. Самый длинный вызов
декодера на каждой нагрузке сократился на 30–39 тактов. Все 18 прежних
образов WebUI воспроизвелись при сборке побайтно.

Проверка AVR25 C, ASM и принудительного generic прошла по 675 478
случаев на бэкенд. Отдельный ELF проверил оба варианта насыщения
перебором 16 777 216 входов signed24 в simavr. Для независимого
эталона деление отрицательных чисел рассчитано через сдвиг модуля.

[Парные замеры](measurements.json) фиксируют параметры AVR-GCC 7.3.0,
GNU AVR ABI, simavr 1.6 и хеши потоков. Модель использует 16 МГц,
8 кГц, FIFO 32 и предварительное заполнение 24.
