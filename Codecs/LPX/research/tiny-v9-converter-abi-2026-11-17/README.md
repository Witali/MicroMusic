# Частная ASM-функция преобразования LSF на ATtiny88

Преобразование LSF использует отдельную последовательность инструкций
из `Lpx4ConvertAvr25.inc`. Её основа — вывод AVR-GCC 7.3.0 для прежнего
проектного C++ преобразователя, с динамическими this, опорой и выходным
массивом. Смещения полей задаёт offsetof. Сохранение регистров согласовано
с вызывающим кодом через явные clobber-операнды.

Указатель результата временно хранится в свободных четвёртых байтах
P0 и Q0 в существующей рабочей области кольца. Qbase вычисляется
из Pbase+24. Это освобождает регистры, сокращая вложенные push/pop.
Последовательность сохраняет r3/r4/r6/r7/r8/r14/r17/Y, оставляет
r1/r2/r5/r10/r11/r15 нетронутыми и содержит ноль вложенных вызовов.

Включение ограничено явно выбранным AVR25 ASM, универсальным v9
SRAM512/LPC2 и картой IRQ r10/r11. Сборщик получает числовые дескрипторы
из существующего `irq_registers.inc`. Альтернативные карты, обычный IRQ,
другие настройки ширины полосы и инструментирование выбирают C++ тело.
`LPX4_ENABLE_ASM=0` сохраняет переносимый C-референс на том же AVR.

| ATtiny88 | До (`bfcd72e2`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3610–3611 Б | 3594–3595 Б |
| Статическая SRAM / пиковый стек | 418 / 35 Б | 418 / 28 Б |
| Наибольшее среднее время с IRQ | 1571,89 такта/отсчёт | 1571,72 такта/отсчёт |

Все 22 нагрузки с IRQ дали точный PWM относительно C и прежнего ASM,
без пропусков. Среднее время сохранилось или уменьшилось до 0,17 такта,
пиковое уменьшилось на 27 тактов. Запас очереди сохранился или вырос.
44 прогона ATmega прошли, 18 образов WebUI совпали побайтно.
[Парные замеры](measurements.json)

На текущих исходниках проверены 2304 прямых вызова для каждой из старой
ASM, новой ASM и C, с тремя профилями, опорами 0/8/16 и всеми 256
положениями кольца. Проверка охватывает внешний выходной массив,
145 живых отсчётов истории, защитные байты, ABI, r1, SP и активный IRQ.
30 сценариев сброса/ошибок дали 15 720 точных строк API и 15 366 отсчётов.
Восемь режимов штатного сборщика подтвердили включение и fallback,
включая совпадение полного C-образа. Проба сохранена в
`tests/avr25_lsf_converter.cpp`.

AVR-GCC 7.3.0, GNU AVR ABI/GAS, simavr 1.6 и модель AVRCore,
16 МГц при 8 кГц, очередь 32 с заполнением 24. Симуляторные измерения
ограничены этой конфигурацией. Ассемблерная последовательность требует
параллельного сопровождения с исходным C++ телом.
