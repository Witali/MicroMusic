# Дробное умножение Q14 на AVR5

Ограниченное произведение коэффициента 0…16384 на signed16 состояние
использует FMUL, FMULS и FMULSU. Эти инструкции сдвигают частичные
произведения на один бит, поэтому окончательное выделение Q14 требует
одного 24-битного сдвига. Эквивалентное тело на C выбирается ключом
`LPX4_ENABLE_ASM=0`. Общий полноразрядный множитель сохраняет свой контракт.

Перенос младшего беззнакового произведения прибавляется к чётному байту
старшего произведения, поэтому эта сумма не переполняет байт. Старший
байт коэффициента не превышает 64. Первое перекрёстное произведение
неотрицательно и имеет нулевой исходный бит15. Второе использует обычную
поправку знака. Результат сохраняет исходные биты14…29 произведения.

| ATmega328 и ATmega328P | До (`d75d66e3`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3093–3094 Б | 3089–3090 Б |
| Наибольшее среднее время с IRQ | 710,90 такта/отсчёт | 706,90 такта/отсчёт |
| Статическая SRAM / пиковый стек | 421 / 24 Б | 421 / 24 Б |

Все 44 нагрузки двух ATmega совпали по PWM с C и предыдущим ASM, без
пропусков. Среднее и пиковое время сохранились или уменьшились до четырёх
тактов на отсчёт. Запас очереди и стоимость IRQ прежние. 22 образа
ATtiny88 и 18 образов WebUI совпали побайтно. Для каждого из C и ASM
проверены 2 424 832 произведения при активном Timer1 IRQ. Проверка
охватывает все signed16 состояния для 35 граничных коэффициентов и
131 072 псевдослучайные пары. Регистр r1 после вызова равен нулю.
[Парные замеры](measurements.json)

AVR5 с дробными MUL, AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6,
16 МГц при 8 кГц, два сегмента LPC, очередь 32 с начальным
заполнением 24. Замеры выполнены в симуляторе.
