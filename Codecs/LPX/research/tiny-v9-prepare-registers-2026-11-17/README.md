# Регистры подготовки подкадра на ATtiny88

Для универсального v9 ROM с двумя сегментами LPC функция
`prepareSubframe` использует локальные параметры AVR-GCC
`no-tree-forwprop,no-tree-ter`. На AVR-GCC 7.3.0 это сокращает
сохранение регистров при подготовке подкадра. Арифметические блоки
и порядок декодирования сохраняются. Выбор C через
`LPX4_ENABLE_ASM=0` использует обычные настройки компилятора.

| ATtiny88 | До (`2e1e4a04`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3684–3685 Б | 3668–3669 Б |
| Статическая SRAM / пиковый стек | 422 / 37 Б | 422 / 35 Б |
| Наибольшее среднее время с IRQ | 1578,44 такта/отсчёт | 1578,05 такта/отсчёт |

Все 22 нагрузки с IRQ совпали побитно с C и предыдущим ASM, без пропусков.
Среднее время уменьшилось на 0,35–0,39 такта, пиковое уменьшилось во всех
прогонах. Минимальный запас очереди прежний. 44 прогона ATmega прошли,
а 18 поставляемых образов WebUI совпали побайтно.
[Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц при 8 кГц, очередь 32
с начальным заполнением 24. Применимость настройки ограничена измеренной
архитектурой и конфигурацией. Замеры выполнены в симуляторе.
