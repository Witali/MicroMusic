# Самостоятельная сборка арифметики AVR25

Условие выбора компактного ограничения суммы использовало
`LPX4_COMPACT_VERSION` в операнде C++, хотя самостоятельный
`Lpx4Math.h` допускает отсутствие версии контейнера. Теперь версия
проверяется препроцессором. Сборка AVR25 ASM без версии использует
прежний общий операнд. V9 на AVR5 выбирает компактный вариант.
Новый тест компилирует математический модуль AVR25 без версии LPX.

Код и замеры всех 22 нагрузок на каждом целевом чипе совпали
с `cdf197ce`. Пересборка 18 образов WebUI дала прежние байты.
Самостоятельный математический модуль собран в ASM, C и
forced-generic. [Проверка исходников и замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6 для проигрывателя.
