# Общее выровненное кольцо возбуждения на AVR25 и AVR5

Универсальный ROM-плеер с выделенными регистрами ISR хранит кольцо
возбуждения на границе 256 Б SRAM. Индекс подставляется в младший байт
адреса, старший загружается из адреса массива. В AVR25 выходная пара
фиксирована как Z, AVR5 разрешает компилятору выбрать верхнюю пару.
Обе сборки используют один макрос адресации. С C-бэкендом кольцо
доступно через обычное сложение указателя и индекса.

| ATmega328/328P ASM | База `799f7b57` | После |
| --- | ---: | ---: |
| Flash с плеером и таблицами, без звука | 4830–4831 Б | 4800–4801 Б |
| Наибольшее среднее время с IRQ | 784,77 такта | 782,26 такта |
| Наибольший измеренный стек | 37 Б | 36 Б |
| Полный ISR | 39 тактов | 39 тактов |

На четырёх нагрузках каждого чипа выигрыш 2,49–2,52 такта на отсчёт
и 87 тактов в пиковом вызове декодера. PWM совпал побитно.
Пропусков не было. Сборки C без выделенных регистров совпали с базой
побайтно. В восьми дополнительных прогонах арифметика C с выровненным
кольцом и ASM ISR также дала тот же PWM.

На ATtiny88 совпали все 22 бинарных образа и замеры с IRQ.
18 образов WebUI пересобрались побайтно. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
SRAM512, очередь 32 с заполнением 24.
