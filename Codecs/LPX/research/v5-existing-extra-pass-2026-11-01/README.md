# Existing-extra full-record pilot

Read [PROTOCOL.md](PROTOCOL.md) before execution. The separate study compares
the old and causal pulse positions on the same six complete P4 input contexts.
It changes no production default or decoder and makes no audible-quality claim.

`prepare_existing.py` reopens the original pre-pilot baseline/target binding,
the two terminal prior exports and the frozen native-library closure. It only
unpacks stream fields and checks metadata/bytes; it does not fit, synthesize or
call a search helper. Its private binding records the initial eligibility and
common trial limit, fixed jobs, old saved secondary rows and source bridges.
The revised preparation also requires `--historical-preflight` naming the intact
six-call source-3f256c1d preflight v1. It binds that superseded preparation and
its paid costs separately; the revised metadata/preflight outputs use fresh v2
directories. Historical, revised and worker warm calls total eighteen synthetic
helpers, additional to the twenty real corpus helpers.

`run_existing.py --preflight-only` makes the six fixed synthetic helper calls.
Then `--arm legacy` and `--arm causal`, with `--preflight` naming that completed
directory, each make three warm calls and ten full-coverage corpus calls. Real
workers require integration review first. Every output path must be fresh and
under this worktree's ignored `build` directory. Redirect stdout/stderr there.
Use the repository's numerical-environment launcher, with all numerical thread
counts set to one and the exact frozen `--source-root` named in the protocol.
No helper is automatically restarted after a failure or a lost process handle.
Callback streams are persisted before producer continuation, and each completed
whole admission is persisted before the next measurement. Failure-retention
contracts inject later failures without invoking a numerical helper.

Run the pure contracts without any media or production imports:

```text
python -m unittest discover -s Codecs/LPX/research/v5-existing-extra-pass-2026-11-01 -p test_extra_*.py
```

Both independent model/native catalogue checks and whole metrics can reuse only
exact bytes within this fresh process; counters and whole-cache provenance are
saved. Prior metrics are used only for the separately labelled saved secondary
comparison, after the unchanged-measurement bridge passes. Source ordinals and
numeric aggregates may be exported publicly. Spatial group lists, sample-error
locations, media, private paths, target/stream fingerprints and source identities
remain in private ignored artifacts.

This package contains a frozen recipe and harness, not executed outcomes.
