This is a separate encoder-only experiment. Keep all earlier studies immutable.
Integration has frozen source de78a32376f9f9c17b64720a1a108ac85a3cf74b. No real

## Identical inputs and fixed scope

Use the exact original pre-joint-rate strongest canonical plus positively
target-admitted matched-CPU baseline binding and levels. Select the same P4
contexts: speech ordinals 3, 16 (auto-quiet), 20, 42 and NS 10, 65. Keep complete targets,
all five source 42 resets and every stored packet/tail. These are six records,
ten reset contexts per arm, two arms, twelve arm records, twenty helper calls
and thirty-six derived cap decisions. No later V1/anchor winner is a seed or
candidate incumbent. The corpus has already been examined; no heldout claim.

Both arms start from exactly the same ordered bytes/target:

- legacy: optional-only whole pass with the original cheap position policy;
- causal: the identical whole pass plus actual mandatory-pulse positions.

Both retain the original cheap amplitude rule. In particular -8/+7 are not
automatically added when the original amplitude is far away; an illegal +8
cancellation is never clamped into a claimed exact result. No dense all-40/full-
amplitude search or parameter/base-pulse refinement is silently substituted.

## Eligibility, invariants and actual work

An eligible group is initially active and played: amp!=0 and
40*group+position < actual samples. Freeze this initial set before either arm.
Only those rows may change; every inactive/unplayed pulse, spectra, parameters,
mandatory pulse, profile, rate, length and filter is preserved. Require exact
header[:20], preserving the original extra flag with force_extras. Payload-size
bytes 20:22 may update consistently with the complete serializer. Preserve all
unplayed stored data; do not trim it to manufacture a size gain. Zero-amplitude
position aliases represent no pulse and may canonicalize; amplitude and all
actual active/unplayed pulse fields remain exact.

For each reset both arms have max_trial_evaluations=49*eligible_count and
cpu_seconds=None. Zero eligibility gives a zero trial budget and honest no-op.
No CPU cutoff, unused-budget transfer, early outcome tuning or helper restart is
allowed. A zero-error baseline may skip work explicitly: report groups_visited=0
and stopped_by, never pretend the eligible set was actually visited. Otherwise
require every eligible group exactly once and complete coverage. Count actual
trial evaluations, visited/completed groups and helper/whole-workflow CPU.

Each trial starts from the real current working-stream prefix, retaining future
extras. Reset state only at actual reset boundaries. Keep original input bytes
as rollback. The pass may keep a locally improved working path separate from its
best fully measured checkpoint; do not roll back fields without rebuilding state.
Local horizon SSE is not a whole-record quality claim.

## Catalogue, checkpoints and nine fixed whole roles

The frozen API returns selected,pcm,report,raw. Its sink(blob,integer fullSSE)
emits baseline and every distinct scored complete candidate in catalogue order,
before the next quota check. Bind catalogue IDs, actual bytes, exact full-model
SSE and returned selected/raw identities to captured bytes. No hidden fitted seed.

Require four fixed initial-active-group coverage slots per reset, with explicit
slots 1..4 mapping to catalogue IDs. Repeated slots may honestly refer to the same
candidate. A real baseline-valued slot differs from an unreached slot. For a
missing slot only, use its last actually completed full snapshot, including an
explicit interrupted-final snapshot, or baseline if none exists; retain the
missing-slot/fallback reason and actual progress. An interrupted-final snapshot
may remain in the catalogue, not masquerade as
a completed coverage slot. The real no-cutoff pilot permits no unexplained
missing coverage. Zero-error/no-op exceptions are explicit and preserved.

Assemble only these whole-record roles, then deduplicate exact ordered bytes:
baseline; common slots 1, 2, 3, 4; concatenated selected; concatenated raw; per-reset
minimum-byte catalogue point; per-reset minimum-full-SSE catalogue point.
There are at most nine roles, with deterministic (bytes,SSE,ID) and
(SSE,bytes,ID) local tie breaks. No Cartesian product, independent slot mixture,
new depth recipe, DP or per-cap refit is introduced.

Freshly verify baseline/model/common/v5 PCM/PWM and every stored baseline whole
value before new work. Independently verify each captured serialized candidate's
geometry, invariants and full-model SSE; separately count that audit. Measure
all distinct new whole roles with the unchanged complete PCM/PWM SSE/STOI,
period-coverage, clipping and voice/noise/joint gates relative to the same input.
Keep all known feasible input/checkpoint choices. Rank at B/floor(.95B)/floor(.90B)
without additional search. Verify each real row has exactly [100,95,90].

admissible whole-row union at the identical source/profile/level/target/cap.
Use all eligible saved whole rows, not just their selected 100% winner; filter
actual bytes by the current cap and rederive gates relative to the fresh current
input anchor. Rank by joint score, actual bytes, fixed study/arm/job/candidate
order. Do not feed these winners into new helpers, whole roles or incumbents.

Require closed old producer/export receipts and exact ordered bytes/reference/
geometry. Explicitly bridge unchanged C/header/table/native libraries and recipe,
decoder/model and metric dependency files, Python/package/thread runtime fields,
and target/level. Changed encoder operators do not excuse a changed DSP/metric
dependency. If a required bridge fails, stop or mark that secondary unavailable;
never label old measurements as fresh or silently loosen the bridge. Report

The secondary is prior saved evidence, not new current target/LTO/playback proof.

## Validation, accounting and boundary

Before corpus work, source/API contracts and fixed synthetic preflight must pass
under forbidden-fit/build guards. Preflight is six calls: both arms on the
published causal P4 fixture (640 samples, one played active group), the same
baseline as its own exact target (honest zero-error skip), and a 201-sample

worker pays these three warm calls as well: twelve synthetic calls total,
separate from twenty corpus helpers. Preserve original packet geometry when
building the 201-sample recipe. Final-source contracts cover default parity,
full-cap repositioning, partial tails, unplayed rows, interruption retention and
precise slot fallback. There is no P6 search arm.

separately. Both arms pay a complete pass; larger candidate sets are extra work,
not automatically a same-CPU improvement. Retain failed/interrupted attempts,
