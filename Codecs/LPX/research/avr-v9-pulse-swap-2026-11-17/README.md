# Извлечение координат импульсов P6 через SWAP

По индексу от 0 до 24 таблица Flash выдаёт две старшие части
координат P6. В сборке AVR v9 старшая часть первой координаты
занимает биты 2…4, а второй — биты 6, 7 и 0. После `SWAP`
ко второй координате применяется та же маска 28. Таблица занимает
25 Б, её значения вычисляются при компиляции. Младшие два бита
по-прежнему приходят из потока LPX.

| Целевая ASM-сборка | Flash до / после, без звука | Наибольшее среднее время с IRQ после | SRAM / пиковый стек |
| --- | ---: | ---: | ---: |
| ATtiny88 | 3956–3957 / 3952–3953 Б | 1584,64 такта/отсчёт | 433 / 44 Б |
| ATmega328/328P | 3916–3917 / 3912–3913 Б | 782,83 такта/отсчёт | 433 / 35 Б |

Все 400 пар координат проверены. На всех 22 нагрузках каждого чипа
PWM совпал с C, пропусков и замедлений не было. Все 18 образов WebUI
совпали побайтно. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
