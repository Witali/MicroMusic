# Выровненное кольцо возбуждения LPX v9 на ATtiny88

ROM-плеер с выделенными регистрами IRQ размещает один 256-байтовый
массив возбуждения отдельно от прочего состояния. Он выровнен на
границу страницы и занимает адреса `0x0100`–`0x01ff`. Очередь начинается
с `0x0200`. При обращении к кольцу младший байт Z получает индекс,
старший вычисляется при линковке из адреса массива. Этот же доступ
используют полиномы LPC в свободных ячейках кольца.

| Показатель | База `cf013a74` | После |
| --- | ---: | ---: |
| Программа с плеером и таблицами, без звука | 4238–4239 Б | 4190–4191 Б |
| Наибольшее среднее время декодера с IRQ | 1617,54 такта | 1610,56 такта |
| Статическая SRAM / пиковый стек | 433 / 50 Б | 433 / 48 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

На всех 22 потоках PWM совпал побитно с предыдущей AVR-сборкой и
переносимым C-декодером. Среднее время с IRQ сократилось на 3,99–7,01
такта на отсчёт. Пиковое время одного вызова декодера сократилось
на 498–499 тактов. Два теста повтора проверили сброс кольца между
записями, дополнительный тест проверил очередь на 24 отсчёта.
В AVR-сборке с C-арифметикой все 12 800 сформированных отсчётов
совпали с ПК, а очередь опустошалась на частоте 8 кГц. Все 18 образов
WebUI воспроизвелись при повторной сборке побайтно.

[Парные замеры](measurements.json) фиксируют AVR-GCC 7.3.0, GNU AVR ABI,
simavr 1.6, 16 МГц, 8 кГц, SRAM512 и очередь 32 с заполнением 24.
