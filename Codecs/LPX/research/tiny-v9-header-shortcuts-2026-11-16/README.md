# Чтение заголовка кадра LPX на AVR25

Компактные профили v9 читают шкалу сразу из байта заголовка. Младший
бит задаёт мантиссу, следующие четыре бита задают группу. Из группы
вычитается 12, чтобы получить знаковый счётчик сдвига. При чтении полей
с положительной шириной счётчик проверяется после сдвига. Вычисление
ширины LSF использует известные смещения между профилями P4 и P6.

| ATtiny88 ASM | База `67e41ea9` | После |
| --- | ---: | ---: |
| Flash с плеером и таблицами, без звука | 4128–4129 Б | 4108–4109 Б |
| Наибольшее среднее время с IRQ | 1591,61 такта | 1591,38 такта |
| Статическая SRAM / пиковый стек | 433 / 45 Б | 433 / 45 Б |

На 22 нагрузках PWM совпал с C и предыдущей ASM-сборкой. Время
декодирования и пиковое время заполнения очереди не выросли, пропусков
не было. Ещё 81 прогон подтвердил прежнее поведение для корректных
и повреждённых потоков. Все 18 образов WebUI совпали побайтно.
[Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
