# Общий Q14-постфильтр LPX v9 на AVR25

После проверки заголовка внутреннее представление коэффициентов 64 и
8192 получает смещение `0xa000`. Одно сравнение старшего байта с 64
различает общее произведение, единичный коэффициент и два сдвига. При
единичном коэффициенте результат уже находится в регистрах возврата ABI.
Общее произведение использует один блок из шести раундов для остатка
младшего байта и для старшего байта. Масштаб и округление сохранены.

| Показатель | База `3fc60834` | После |
| --- | ---: | ---: |
| Программа с плеером и таблицами, без звука | 4258–4259 Б | 4238–4239 Б |
| Наибольшее среднее время декодера с IRQ | 1617,535848 такта | 1617,535848 такта |
| Статическая SRAM / пиковый стек | 433 / 50 Б | 433 / 50 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

Все 22 нагрузки сохранили точный PWM относительно базы и C-декодера.
Время декодирования с IRQ сократилось на 0–8 тактов на отсчёт. Проверка
арифметики сопоставляет обычное Q14-умножение с подготовленными
коэффициентами на AVR25 ASM. Проверены все 16385 допустимых коэффициентов
на граничных отсчётах и весь диапазон signed16 для семи коэффициентов,
включая оба сдвига и единичный случай. AVR25 ASM, AVR25 C и принудительный
generic прошли по 760 285 проверок с контролем ABI и активными
прерываниями. У всех 18 образов WebUI повторная сборка дала те же байты.

Смещение применяется к двум значениям в SRAM. Сжатые данные и
формат заголовка сохраняются. [Парные замеры](measurements.json)
фиксируют SRAM512, AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц
и очередь 32 с заполнением 24.
