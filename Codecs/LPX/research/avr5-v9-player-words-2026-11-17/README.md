# Слова состояния проигрывателя AVR5

Локальная настройка `no-split-wide-types,no-tree-ccp` для `main`
сокращает код обвязки универсального v9 проигрывателя с двумя
сегментами LPC на AVR-GCC 7.3.0. Она включается для целевой ASM-сборки
AVR5. Переносимая арифметика доступна через `LPX4_ENABLE_ASM=0`.

| ATmega328 и ATmega328P | До (`527dd8a3`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3089–3090 Б | 3083–3084 Б |
| Статическая SRAM / пиковый стек | 421 / 24 Б | 421 / 24 Б |

Все 44 нагрузки с IRQ дали точный PWM с прежними SRAM, стеком и запасом
очереди, без пропусков. Среднее и пиковое время уменьшились во всех
прогонах. 22 образа ATtiny88 и 18 образов WebUI совпали побайтно.
[Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц при 8 кГц, два сегмента
LPC, очередь 32 с начальным заполнением 24. Применимость настройки
ограничена измеренной конфигурацией. Замеры выполнены в симуляторе.
