# Интерполяция LPC для нечётных фаз на ATtiny88

В универсальном v9 интерполяция между двумя наборами коэффициентов LPC
использует нечётные фазы. Младшая единица уже учтена при начальном
делении модуля разности пополам. Остальные биты фазы компилятор
подготавливает до входа в inline ASM. Он же выделяет выходной регистр
под текущее значение, из которого ASM вычитает предыдущую опору.
Округлённый модуль прибавляется к предыдущей опоре или вычитается из неё.
Знаковая разность может занимать до 17 бит, её модуль помещается в 16 бит.

| Показатель | База `b5f59cfc` | После |
| --- | ---: | ---: |
| Программа с плеером и таблицами, без звука | 4184–4185 Б | 4178–4179 Б |
| Наибольшее среднее время декодирования с IRQ | 1595,62 такта | 1594,96 такта |
| Статическая SRAM / пиковый стек | 433 / 48 Б | 433 / 48 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

На всех 22 нагрузках PWM совпал с предыдущей AVR25 ASM и эталоном C.
Последовательность входных LPX-байтов и параметры сборки взяты из
парных замеров базовой версии. Новая сборка выиграла 0,05–0,67 такта
на отсчёт. Все 18 образов WebUI повторно собраны с побайтным совпадением.

[Замеры](measurements.json) фиксируют AVR-GCC 7.3.0, GNU AVR ABI,
simavr 1.6, 16 МГц, 8 кГц, SRAM512 и очередь 32 с заполнением 24.
