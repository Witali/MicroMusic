# Общий расчёт округлённого PWM на AVR25 и AVR5

При коэффициенте усиления 130 округлённое заполнение равно
`floor((x + floor(x/64) + 16448)/128)` с насыщением до 0–255. В AVR
сдвиг вправо на шесть бит заменён выборкой старших байтов из
расширенного значения, сдвинутого влево на два. Внутри допустимого
для постфильтра диапазона `[-27853,27853]` бит 15 суммы обозначает
насыщение, а бит 14 различает нижний и верхний предел. Обе сборки
используют одни и те же ограничения операндов GNU AVR GCC. Выбор
ASM требует обычного явного разрешения. C использует формулу Q14.

| Целевая ASM-сборка | Flash до / после, без звука | Выигрыш с IRQ на отсчёт | Максимальное среднее после | SRAM / стек |
| --- | ---: | ---: | ---: | ---: |
| ATtiny88 | 4108–4109 / 4102–4103 Б | 2–3 такта | 1589,38 такта | 433 / 45 Б |
| ATmega328/328P | 4536–4537 / 4520–4521 Б | 3–8 тактов | 803,08 такта | 433 / 35 Б |

На 22 нагрузках каждого чипа PWM совпал с C и предыдущей ASM-сборкой.
Пропусков не было, стек и пиковое время заполнения очереди не выросли.
Арифметическая проверка AVR25 прошла весь диапазон входов общего
преобразования и отдельно весь signed16 для полного Q14 PWM.
Все 18 образов WebUI совпали побайтно. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
