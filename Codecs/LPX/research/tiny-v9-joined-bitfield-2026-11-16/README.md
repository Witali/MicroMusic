# Битовое поле LPX v9 после подгрузки байта

Знак разности между длиной кэша и шириной поля выбирает подгрузку.
Подгрузка добавляет восемь бит, поэтому остаток всегда находится в трёх
младших битах разности. После объединения кэша и нового байта нужна
одна маска. Оба байтовых сдвига проверяют нулевой счётчик до цикла.

| Показатель | База `881d40b6` | После |
| --- | ---: | ---: |
| Программа, включая плеер и таблицы, без звука | 4412–4413 Б | 4404–4405 Б |
| Наибольшее среднее время декодера с IRQ | 1620,015106 такта | 1619,933547 такта |
| Статическая SRAM / пиковый стек | 433 / 50 Б | 433 / 50 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

Все 22 нагрузки в simavr 1.6 сохранили точный PWM при сравнении с
предыдущей сборкой и независимым C-декодером. Среднее процессорное
время декодера с IRQ сократилось на 0,07–0,39 такта на отсчёт.
Самый длинный вызов на каждой нагрузке сократился на 16–34 такта.
При повторной сборке все 18 прежних образов WebUI совпали побайтно.

В AVR25 ASM, AVR25 C и принудительном generic отдельный ELF перебрал
587 520 сочетаний ширины поля, содержимого кэша и следующего байта.
Ещё 4590 состояний на бэкенд проверили конец потока и уже установленную
ошибку. Эталон проверял результат, кэш, число битов, указатель, остаток
в ROM и флаг ошибки с помощью 16-битного окна.

[Парные замеры](measurements.json) фиксируют сборку SRAM512 на
AVR-GCC 7.3.0 и GNU AVR ABI. Симуляция использует 16 МГц, 8 кГц,
FIFO 32 и предварительное заполнение 24.
