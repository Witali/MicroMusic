# Генерация главного цикла ATtiny88

Локальные параметры AVR-GCC `no-tree-dominator-opts,no-tree-ter`
сокращают обвязку главного цикла универсального v9 ROM-проигрывателя
с двумя сегментами LPC. Код арифметических блоков сохраняется.
Настройка ограничена целевым AVR25 ASM. C-референс доступен через
`LPX4_ENABLE_ASM=0`.

| ATtiny88 | До (`dd3a5f28`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3646–3647 Б | 3640–3641 Б |
| Статическая SRAM / пиковый стек | 421 / 35 Б | 421 / 35 Б |
| Наибольшее среднее время с IRQ | 1576,05 такта/отсчёт | 1576,05 такта/отсчёт |

Все 22 нагрузки с IRQ сохранили точный PWM, среднее и пиковое время,
очередь, SRAM и стек. Пропусков нет. Все 44 прогона ATmega прошли,
18 образов WebUI совпали побайтно. Дополнительные 33 проверки
жизненного цикла подтвердили ошибки, повторы и частичные хвосты.
[Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц при 8 кГц, очередь 32
с начальным заполнением 24. Применимость настройки ограничена
измеренной конфигурацией. Замеры выполнены в симуляторе.
