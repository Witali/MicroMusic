# Малое возбуждение через общий модуль на AVR25

Для кодов ±1, ±2 и ±3 используется общий расчёт модуля и
общая смена знака результата. Удвоение выполняется сдвигом трёх
байтов. Для утроения к нему добавляется исходный масштаб.
Результат не превышает 196605 и помещается в этих трёх байтах.
Оптимизация применяется к шестибитной специализации возбуждения Q4.
Общий byte×word и переносимый C сохраняют свои ветки.

| ATtiny88 | До (`05fdea6c`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3700–3701 Б | 3692–3693 Б |
| Наибольшее среднее время с IRQ | 1579,49 такта/отсчёт | 1578,69 такта/отсчёт |
| Статическая SRAM / пиковый стек | 422 / 38 Б | 422 / 38 Б |

Все 22 нагрузки дали прежние PWM побитно с IRQ, без пропусков,
роста времени и памяти. Самостоятельный арифметический тест проверил
все 2048 сочетаний кода и масштаба LPX в ASM, C и forced-generic
с активным IRQ и контролем ABI. Прогоны обоих ATmega и пересборка
18 образов WebUI прошли. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6 для проигрывателя, 16 МГц при
8 кГц, два сегмента LPC, очередь 32 с начальным заполнением 24.
