# Выпуск LPX для WebUI после слияния оптимизаций

Объединены оптимизации универсального декодера `41472750` и подготовленный
перевод Tiny88 WebUI на v9 `a959270d`. Исходный main — `1fe7048d`.
Общий проигрыватель сохранил карту IRQ r10/r11, GPIOR и alias ошибки.
В него включено чтение усиления из байта ROM после потока. Этот байт
исключается из длины LPX при первом и повторном открытии. C-арифметика
и C-ISR доступны явно. Сборщик Tiny88 по умолчанию использует unroll2
и включает карту регистров IRQ в контрольные суммы исходников.

| Сборки | Количество | Полный Flash вместе со звуком |
| --- | ---: | ---: |
| ATtiny88, универсальный LPX v9 | 9 | 4032–5520 Б |
| ATmega328P, речевые записи LPX v5 | 8 | 4942–6418 Б |
| ATmega328P, «Разговор у Совы» | 1 | 10 386 Б |

Все девять Tiny88-образов уменьшились на 1188–1480 Б относительно
прежних опубликованных v5/v8 образов. Они помещаются в 6012 Б области
приложения USB-загрузчика MH-ET LIVE. Статическая SRAM занимает 418 Б,
пиковый стек 28 Б. Каталог учитывает завершающее выравнивание секции
из avr-size в консервативном зазоре между BSS и стеком, равном 65 Б.
Это сохраняет прежнее правило суммы полей каталога в 511 Б.

Перепаковка девяти открытых потоков в v9 выполняется без потерь.
На каждой записи среднее время декодера с полным IRQ сохранилось или
уменьшилось относительно прежнего выпуска. Наибольшее среднее время
составляет 1416,27 такта на отсчёт. Работа основного цикла с очередью
проверена полным воспроизведением. Сам IRQ занимает 35 тактов.

На каждом из 18 фактических ELF выполнено полное воспроизведение с IRQ.
Все 345 470 значений PWM совпали с публичными WAV, пропусков нет.
Tiny88 дополнительно сравнивается с C-оракулом и прежней ASM-прошивкой.
Повторная независимая сборка всех 18 образов совпала с итоговыми HEX
побайтно. Девять Nano-образов также побайтно совпадают с прежними HEX.
Их каталоги получили свежие исходные хеши и результаты проверки IRQ.
Штатный Tiny88 v9 без ROM-усиления совпал с проверенным HEX `41472750`.

Прошли полный набор тестов WebUI, 13 тестов профилей/C-арифметики и
проверка актуальности инвентаризации речевых файлов. Параметры сборки,
контрольные суммы исходников, потоков, WAV и образов, а также результаты
IRQ сохранены в [отчёте](rebuild.json).

AVR-GCC 7.3.0, GNU AVR ABI/GAS, 16 МГц, 8 кГц, simavr 1.6.
Для Tiny88 применяется закреплённый ATtiny_DFP 3.4.278. Результаты
получены в симуляторе. Выход Tiny88 — D9/OC1A, Nano — D3/OC2B.
