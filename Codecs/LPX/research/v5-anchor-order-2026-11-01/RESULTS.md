# Separate anchor-order pilot: completed results

Priority reaches the intended branches, but the whole-record quality result is
mixed. Old generation gains three lower-score selections and loses two; new
generation gains three and loses four versus its temporal control. There is no
speech byte reduction and no 95% or 90% admission. The only preserved-quality
byte savings are one-byte non-speech frontier points. These measurements do not
justify a default change, audible-equivalence claim or full-corpus effectiveness
claim.

## Exact scope, source and attempts

The separate protocol and harness were committed before outcomes. The campaign
completed 48 arm records, 80 fresh corpus helpers and 144 actual cap decisions,
plus eight preflight and eight worker warm helpers. Both corpus workers exited
0, as did the successful saved projector and independent cap postcheck. Every
actual row contains exactly [100,95,90], with public decisions matching private
records. All 40 paired reset nominated sets match between time and priority.
There were no failed, interrupted, repeated or omitted corpus/synthetic helpers,
no initial fits and no native builds. All 22 research contracts pass, including
the real terminal-data schema, native bridge and clean standalone import checks.

The numerical epoch is actual root HEAD 55ebc0d94e919fa7aeec4819e3bf83cfaf81fa6a,
whose tools/tests/src match implementation ancestor 099d040afa2a2e77e1a15e3082de20c585a46929.
Integration reported 220 passing production tests and eight disabled-budget
temporal byte/report parity cases before launch. This research did not rerun
that suite. Production origins and every bound file were checked at startup,
terminal and saved projection. Old native libraries retain their separately
bound source/compiler/recipe epoch and exact binary/C-header dependency bridge;
they were not relabeled as a current build or new target proof.

The exact pre-pilot 104-context binding and 12 complete contexts were preserved,
including all five resets of source 42 and the original declared levels/targets.
None of the earlier pilot's winners was a free seed or incumbent. Each context
received fresh full baseline model/common/v5 PCM/PWM and common metric checks.
Independent live audits reconstructed each actual anchor plan from baseline PCM
and adjacent-spectrum coding costs, separately charged outside helper CPU.

Saved projection had two preserved failures: an import bootstrap failure before
output creation, then a manifest-key mismatch before local-pool processing.
Both were corrected only in the new projector, with standalone/schema contracts;
neither performed decoding, metrics or search. An isolated test-name collision
was also corrected. The successful output is export-v3; failed logs/receipts are
kept separately. The executed campaign, V1 evidence and original guarded sources
were unchanged. The narrow cap postcheck is cap-postcheck-v1, not a helper rerun.

## Boundary and reproduction

The private export retains 25 distinct changed eligible tuples with every cap,
minimum-byte and eligible-frontier context, common rollback and target/level
provenance. It has been handed off for a finite target-cost plan only. There are
no target jobs, new linked-Flash measurements, playback/listening results,
full-corpus expansion or follow-up mixtures here. Root owns those separate
decisions. No numerical gate is relaxed to admit rejected lower-rate audio.

The immutable [README.md](README.md) describes preparation, preflight and workers.
After terminal source guards, the successful saved command was:

```text
python project_anchor.py --baselines <anchor-binding> --preflight <preflight-output> --shards <profile 4-output> <profile 6-output> --output build/anchor-order/export-v3
python cap_postcheck.py --export build/anchor-order/export-v3 --output build/anchor-order/cap-postcheck-v1
```

The projector performs no codec execution. Its source-bound exact byte recipes,
quality gates, costs and cache provenance are retained privately; public evidence
contains only anonymous numeric results. The same already examined sources are
reused, so this remains a bounded tuning study with no independent heldout claim.
