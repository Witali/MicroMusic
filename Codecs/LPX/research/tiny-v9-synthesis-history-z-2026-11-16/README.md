# Повторное использование Z в синтезе LPX v9

После десяти шагов обратного обхода истории LPC пара Z уже содержит
адрес `hist_[0]`. Код сохраняет этот указатель до конца ограничения
амплитуды и записывает новое слово через `STD Z+1` и `ST Z`. Каждая
запись занимает два такта, как и соответствующая абсолютная `STS`.
C-бэкенд выполняет ту же запись через адрес начала массива.

| Показатель | База `f37f1b81` | После |
| --- | ---: | ---: |
| Программа с плеером и таблицами, без звука | 4262–4263 Б | 4258–4259 Б |
| Наибольшее среднее время декодера с IRQ | 1617,535848 такта | 1617,535848 такта |
| Статическая SRAM / пиковый стек | 433 / 50 Б | 433 / 50 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

На 22 нагрузках PWM совпал побитно с предыдущим AVR-плеером и C-декодером.
Время декодирования с IRQ совпало на каждой нагрузке. 18 образов WebUI
воспроизвелись при повторной сборке побайтно.

[Парные замеры](measurements.json) фиксируют SRAM512, AVR-GCC 7.3.0,
GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц и очередь 32 с заполнением 24.

## Сборка прошивки из вывода компилятора

Скомпилируйте `player.cpp` и `Lpx4HybridCore.cpp` с флагами измеренной
сборки в отдельные LTO-объекты. Сохраните `*.ltrans0.s` при линковке
через `-save-temps`. Замените тело массива `_ZL5voice` на
`.incbin "audio.lpx"` и вычислите размер по разности меток конца и начала.
Два непосредственных операнда проверки длины полезной нагрузки
получаются из `lpx_audio_end-_ZL5voice-13` через `lo8()` и `hi8()`.

Исходник собирается из каталога с `audio.lpx` штатной AVR-средой
запуска и `libgcc`.

```sh
avr-g++ -mmcu=attiny88 -mrelax -mcall-prologues -Wl,--gc-sections \
    -x assembler /path/to/universal-v9.S -o player.elf
avr-objcopy -O ihex -R .eeprom player.elf player.hex
```

Один `.S` с каждым из 22 файлов дал тот же HEX, что и обычная сборка
плеера. Совпали все 308 339 отсчётов PWM и все показатели симулятора
с активным IRQ. Параметры записи остаются в LPX. Сгенерированный `.S`
отражает размещение полей и ABI конкретной сборки SRAM512.
