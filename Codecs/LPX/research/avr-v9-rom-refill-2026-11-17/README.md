# Проверка границы при заполнении битового буфера LPX v9

Универсальный ASM-проигрыватель с выводом PWM проверяет длину
перед каждым чтением Flash. При исчерпании потока счётчик
остаётся нулевым, поэтому последующие запросы внутри того же
поля тоже возвращают ноль. Остальные ошибки возвращают управление
вызывающему коду до следующего чтения. Это позволяет убрать из
внутреннего чтения дублирующую проверку ошибки. Путь общего
декодера сохраняет обе проверки.

| Целевая ASM-сборка | Flash до / после, без звука | Наибольшее среднее время с IRQ после | SRAM / пиковый стек |
| --- | ---: | ---: | ---: |
| ATtiny88 | 3962–3963 / 3956–3957 Б | 1584,64 такта/отсчёт | 433 / 44 Б |
| ATmega328/328P | 3922–3923 / 3916–3917 Б | 782,88 такта/отсчёт | 433 / 35 Б |

На всех 22 нагрузках каждого чипа PWM совпал с C. Пропусков,
замедлений и роста пикового времени заполнения очереди не было.
На дополнительных 237 потоках сверены выданные отсчёты, код ошибки
и число непрочитанных байтов, в том числе при обрыве после каждого
байта данных. Все 18 образов WebUI совпали побайтно. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
