# Универсальный LPX v9 для всех Nano-прошивок WebUI

Все восемь речевых образов ATmega328P и «Разговор у Совы» используют общий
проигрыватель Tiny88/Mega и универсальный v9-декодер. Он читает параметры
P4, P6 и sparse80 из потока. Аппаратный MUL включается реальным выбором
`-mmcu=atmega328p` и явным `LPX4_ENABLE_ASM=1`. Ключ `LPX25_NANO_PWM=1`
выбирает D3/OC2B, Timer2 fast PWM 62,5 кГц и Timer1 CTC 8 кГц.
Арифметика C/ASM и вариант ISR выбираются независимо от аппаратного выхода.

| Запись | Полный Flash до, Б | Полный Flash v9, Б |
| --- | ---: | ---: |
| Чего тебе нужно / compact | 5008 | 3638 |
| Чего тебе нужно / quality | 5262 | 3892 |
| Что ж ты не отвечаешь / compact | 4942 | 3566 |
| Что ж ты не отвечаешь / quality | 5246 | 3788 |
| Сова, открывай / compact | 5824 | 4316 |
| Сова, открывай / quality | 6418 | 4936 |
| И того, и другого / compact | 5480 | 4112 |
| И того, и другого / quality | 6370 | 4998 |
| Разговор у Совы | 10 386 | 8946 |

Размер включает все звуковые данные. Программа отдельных записей занимает
3116–3117 Б, программа диалога 3397 Б, включая таблицу длин и ROM-усиление.
Сжатые сегменты диалога уменьшились с 5806 до 5549 Б. Исходный выпуск
сравнения закреплён коммитом `717d20aa`.

Статическая SRAM отдельных записей уменьшилась с 756 до 417 Б, диалога
с 756 до 420 Б. Пиковый стек целевых ASM-образов равен 24 Б. Очередь
занимает 32 Б с prefill 24. GPIOR0/1/2 используются для её индексов
и остановки, карта IRQ закрепляет r10/r11. Средняя активная стоимость
декодера с полным IRQ составляет до 679,01 такта на отсчёт для этих
записей. Сам IRQ занимает 35–36 тактов, включая вход и RETI.

Диалог состоит из семи полных v9-потоков. `audio.inc` содержит их
конкатенацию, `segment_lengths.inc` хранит длины в PROGMEM. Плеер
сбрасывает декодер через публичный begin() между сегментами, сохраняя
состояние очереди и таймера. Один финальный ROM-байт задаёт усиление
всего разговора. Паузы 0,5 / 1,5 / 0,5 с и прежняя нормализация сохранены.
Поддерживается повтор всей последовательности.

На девяти фактических ELF с IRQ проверены все 203 762 значения PWM.
Они совпадают побитно с прежними публичными WAV и переносимым C-оракулом,
пропусков нет. Наблюдатель проверяет сохранение незарезервированных
регистров CPU и живых флагов SREG после каждого IRQ, включая прерывания
при ненулевом r1 во время MUL. Проверены остановка таймера, EOF, пустая
очередь, стек и интервалы PWM.

Дополнительная матрица проверила 12 конфигураций и 8040 отсчётов,
сочетания C/ASM-арифметики и C/ASM-ISR, сегменты на 1/320/81 отсчёт,
полные кадры, короткие хвосты, повтор 1/2 и усиление 128/255. Все результаты
точные и без пропусков. Проверены обычный Path и список из одного файла,
явный ASM, C по умолчанию и четыре случая отказа на неверных списках.

Повторная независимая сборка всех 18 LPX-образов WebUI дала точные HEX.
Девять Tiny88 HEX совпадают с исходным выпуском побайтно. Их исходные
хеши обновлены после проверки общего проигрывателя. Веб-адаптер показывает
v9 для записей и диалога, сохраняет прежние идентификаторы и загрузку D3.
Ключи кэша модулей и каталогов обновлены.

[Замеры, хеши и дополнительные проверки](rebuild.json) связаны с
[переходом исходников](source-transition.json). Исторические измерения
сохраняют свои прежние исходники и результаты. Проверены устройство
`__AVR_ATmega328P__`, архитектура AVR5 и `__AVR_HAVE_MUL__`. Адреса
регистров получены из выбранного компилятором неизменённого заголовка
Microchip `avr/iom328p.h`, BSD-3-Clause, в avr-libc 2.0.0. Его версия,
лицензия и точный SHA-256 сохранены в отчёте.

Для пересборки из открытых потоков нужны Python стандартной библиотеки,
AVR-GCC 7.3.0, host g++, simavr 1.6 и libelf. Из корня репозитория

```text
python tools/build-nano-lpx-v9.py --retain --jobs 3
```

На Windows добавьте `--wsl Ubuntu`. Низкоуровневый сборщик
`build_atmega328p_player.build` принимает Path или список потоков,
`assembly=False` выбирает C, `asm_isr=False` выбирает C-ISR.
Все измерения выполнены в симуляторе при 16 МГц и 8 кГц.
