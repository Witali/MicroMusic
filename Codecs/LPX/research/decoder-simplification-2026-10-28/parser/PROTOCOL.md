# Bounded v5 parser experiments

The source baseline is commit `3f717df5`. Each patch in `experiments/` applies independently to that baseline; combination patches are complete combinations, not cumulative patch series. `sources.json` pins every measured source inventory. Audio bytes and output values are unchanged. Generated corpus manifests, source audio, byte-array headers and firmware binaries remain private in ignored build storage.

The screen uses the shortest and longest selected speech recordings in profiles 4 and 6: 8,000 and 281,632 samples respectively. All variants use the same ordered private streams. The long recording resets between five segments in one linked firmware; the short recording uses one segment. Recreate source copies in ignored build storage, apply one patch to an exact baseline copy, then call `measure_speech_firmware.measure(streams, output, avr_bin, source=source_copy)` from the repository Python environment. Count complete `.text + .data`, including reset tables/dispatcher and shared decoder once. The original compiler recipe is AVR-GCC 7.3.0, ATmega328P/AVR5,16MHz/8kHz, `-Os -flto -mcall-prologues -mrelax`, unroll1/tuning0, compact-only, explicit ASM. Hardware Flash access and portable C arithmetic selection are unchanged.

The retained combination uses bounded payload subtraction, signed8 spectral parse locals and one compact format-flags byte. It saves38 bytes in each short image and24 in each long image; static SRAM falls one byte. Standalone signed-nibble XOR grows the images. Dropping a redundant compact pair bound and replacing zigzag decoding with XOR each save code on the long images but grow the short images because linked code generation changes; they are rejected as universal defaults. Shorter expressions did not predict smaller programs.

`tests/compact_parser.cpp` constructs headers and bounded Rice/pulse fields independently. The trace was first frozen against an immutable baseline source copy, then checked against each retained step. It covers all16-bit input lengths with boundary payloads; all payloads at lengths20/21/22/65535; every flag/version with wide-count failures and subsequent null begin; every bounded gap/delta tuple; radix20/extras and selected EOF cuts. The trace includes public metadata/errors, residual byte/bit state, normalized format flags, spectral/pulse state and diagnostic reader counters. The persistent Python test checks1,838,989 cases in each common/compact-only and ROM-pointer/base-cursor build,7,355,956 total. Run `test_compact_parser.py` alongside the existing bit-reader, compact, speech-v4 and anchor tests.

Representative current-selected validation compares portable native common/v5-only before and after against the integer model:26 distinct streams,1,251,264 samples and208 PCM/PWM comparisons, all exact. This sample does not replace the parent task's full corpus admission.

Eight actual AVR runs compare baseline/current, profiles4/6 and normal/+100-cycle IRQ load on the short inputs. All complete PWM bytes match the model, with zero underruns/errors and full timing coverage. Per-image mean/max/stack figures are in `measurements.json`; these are simulator observations for these inputs, not a physical-board or universal timing claim. The parent task separately checks the integrated decoder and full corpus before publication.
