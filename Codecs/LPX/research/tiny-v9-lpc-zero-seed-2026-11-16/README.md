# Начальный шаг умножения LPC на AVR25

Проверка нуля копирует слово истории командой `MOVW` и объединяет его
байты. Младший байт в `r22` остаётся множителем. Первый шаг даёт либо
ноль, либо половину беззнакового коэффициента. Во втором случае
копирование и логический сдвиг дают тот же результат, что сложение с
нулевым накопителем и последующий поворот. Остальные семь шагов,
знаковая поправка и отдельное округление каждого произведения сохраняют
точность C-референса.

| Показатель | База `ce0b1c93` | После |
| --- | ---: | ---: |
| Программа с плеером и таблицами, без звука | 4190–4191 Б | 4184–4185 Б |
| Наибольшее среднее время с IRQ | 1610,56 такта | 1595,62 такта |
| Статическая SRAM / пиковый стек | 433 / 48 Б | 433 / 48 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

На всех 22 нагрузках PWM совпал побитно с предыдущим AVR-плеером и
переносимым C-декодером. Выигрыш составил от 0 до 15,40 такта на
отсчёт. Арифметический тест с полным перебором значений истории signed16
проверил по 306 992 случая для AVR25 ASM, AVR25 C и принудительного
generic. Все 18 образов WebUI повторно собраны с побайтным совпадением.

[Парные замеры](measurements.json) фиксируют AVR-GCC 7.3.0, GNU AVR ABI,
simavr 1.6, 16 МГц, 8 кГц, SRAM512 и очередь 32 с заполнением 24.
