# Умножение LPC на насыщенную историю на AVR25

Для значений истории ±32767 обе ветви используют формулу
`floor(x*32767/256) = 128*x - ceil(x/256)`, где `x` меняет знак при
отрицательном значении истории. Преобразование LSF ограничивает опоры
LPC диапазоном ±32767, а интерполяция остаётся между опорами. Поэтому
смена знака коэффициента допустима. Округление Q12 выполняется
сбросом младшей тетрады произведения. Для вызовов с полным signed16
доступна прежняя ветвь. `LPX4_ENABLE_ASM=0` выбирает переносимый C.

| ATtiny88 | До (`0f5ef996`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3952–3953 Б | 3942–3943 Б |
| Наибольшее среднее время с IRQ | 1584,64 такта/отсчёт | 1584,59 такта/отсчёт |
| Статическая SRAM / пиковый стек | 433 / 44 Б | 433 / 44 Б |

Все 22 нагрузки дали 308 339 значений PWM, побитно совпавших с прежней
сборкой и C. Пропусков не было. Среднее время с IRQ и пик декодера
сократились на отдельных нагрузках до 50 тактов. Все 44 прогона
на ATmega и пересборка 18 образов WebUI также прошли.
[Парные замеры](measurements.json)

Арифметический тест с активным Timer1 IRQ перебирает все 131 070 пар
коэффициента и границы насыщения, сверяя C, AVR25 ASM и forced-generic.

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6 для проигрывателя. 16 МГц при
8 кГц, два сегмента LPC, очередь 32 с заполнением 24 перед стартом.
