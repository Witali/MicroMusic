# Общий счётчик подкадров LPX v9 на AVR

Обе ASM-версии увеличивают байтовый счётчик на границе подкадра.
Бит 3 различает половины, а биты 0 и 1 задают чтение импульсов
через два подкадра для P4/P6 и через четыре для sparse80. Достаточно
младших четырёх бит, поэтому обычное переполнение байта сохраняет
фазы. Вторая половина sparse80 использует уже прочитанные параметры.

| Целевая ASM-сборка | Flash до / после, без звука | Наибольшее среднее время с IRQ после | SRAM / пиковый стек |
| --- | ---: | ---: | ---: |
| ATtiny88 | 3974–3975 / 3974–3975 Б | 1584,69 такта/отсчёт | 433 / 44 Б |
| ATmega328/328P | 4090–4091 / 4056–4057 Б | 785,26 такта/отсчёт | 433 / 35 Б |

На ATmega среднее время уменьшилось на 0,71–0,86 такта на отсчёт.
На всех 22 нагрузках каждого чипа PWM совпал с C, пропусков и роста
пикового времени заполнения очереди не было. Все 18 образов WebUI
совпали побайтно. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
