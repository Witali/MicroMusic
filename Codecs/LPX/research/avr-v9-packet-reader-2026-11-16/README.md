# Общий байтовый буфер битов LPX v9

Оба AVR используют один байтовый буфер и счётчик доступных битов.
При пересечении границы байта декодер читает следующий байт через
общий курсор Flash. На ATmega328/328P декодер вызывает отдельную
функцию чтения, а затем перечитывает состояние буфера,
чтобы сократить число живых регистров. Ширина поля в этой ветке
положительна. ПК и выбираемый C-режим используют переносимый разбор.

| Целевая ASM-сборка | Flash до / после, без звука | Выигрыш с IRQ на отсчёт | SRAM / стек |
| --- | ---: | ---: | ---: |
| ATtiny88 | 4102–4103 / 4102–4103 Б | 0 | 433 / 45 Б |
| ATmega328/328P | 4516–4517 / 4476–4477 Б | 0,46–2,78 такта | 433 / 35 Б |

На 22 нагрузках каждого чипа PWM совпал с C, пропусков не было.
Дополнительные 81 сравнение на ATmega328P охватывают допустимые
импульсы и повреждённые пакеты. Режимы C, PCM16 и чтение через
callback сверены по препроцессорному выводу. Все 18 образов WebUI
совпали побайтно. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
