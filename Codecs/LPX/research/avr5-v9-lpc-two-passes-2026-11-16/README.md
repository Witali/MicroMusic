# Два прохода по пяти опорам LPC на AVR5

Проигрыватель LPX v9 с аппаратным умножением повторяет один блок из
пяти опор дважды. Флаг `T` различает проходы. Перед входом загружается
первая опора без записи самого старого отсчёта в запасное слово.
На обратном переходе загружается и сдвигается шестая опора. ISR
сохраняет `SREG`, включая `T`. Обе архитектуры используют общие
макросы загрузки через `X` и `Z` и сдвига истории.

Двухпроходный цикл и удаление неиспользуемого байта младшего
произведения экономят 246 Б. При масштабировании возбуждения
`MULSU` передаёт знак каждого частичного произведения через перенос.
Оба частичных произведения имеют одинаковый знак, если они ненулевые.
Это экономит ещё 6 Б и 3 такта на отсчёт, компенсируя переход в цикле.
Сумма по-прежнему округляет каждое произведение отдельно. Вариант
выбирается для AVR5 с явным разрешением ASM, форматом v9 и штатной
развёрткой Q4. Переносимый C-эталон доступен для тех же потоков.

| ATmega328 и ATmega328P | До | После |
| --- | ---: | ---: |
| Flash с плеером и таблицами, без звука | 4452–4453 Б | 4200–4201 Б |
| Наибольшее среднее время с IRQ | 789,39 такта/отсчёт | 789,36 такта/отсчёт |
| Статическая SRAM / пиковый стек | 433 / 35 Б | 433 / 35 Б |

На каждом ATmega проверены 22 нагрузки с IRQ. Все 616 678 значений
PWM совпали с C и предыдущей ASM-сборкой. Пропусков не было, среднее
и пиковое время заполнения очереди не выросли. Арифметический тест
проверяет сдвиг десяти слов и сторожевое слово за историей. Отдельная
проверка перебрала все 16 777 216 пары входов для умножения возбуждения.
22 сборки ATtiny88 и 18 образов WebUI совпали побайтно.

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
