# Общий цикл умножения полиномов LPC на AVR25

Разложение операнда `v = 16*hi + rem` оставляет 16-битное слово и
четырёхбитный остаток. Для прямого округления величина
`floor(rem*c/16)` входит в начальное значение накопителя. Для раздельного
округления её делят на 256 и добавляют к частному. На границе +250000
остаток равен нулю, поэтому обе формулы дают одинаковое значение.

В одном блоке из семи шагов обрабатываются по очереди два байта `hi`.
Последний шаг старшего байта вычитает множимое при установленном знаке.
Последовательные смещения
выходных коэффициентов P и Q убирают расчёт индекса на каждом шаге.
Переносимый C-декодер сохраняет прежние правила округления.

| Показатель | База `667360f5` | После |
| --- | ---: | ---: |
| Программа, включая плеер и таблицы, без звука | 4352–4353 Б | 4276–4277 Б |
| Наибольшее среднее время декодера с IRQ | 1619,933547 такта | 1617,933704 такта |
| Статическая SRAM / пиковый стек | 433 / 50 Б | 433 / 50 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

В 21 из 22 нагрузок среднее время декодирования с IRQ уменьшилось.
На оставшейся нагрузке оно совпало. Самый длинный вызов декодера на
каждой нагрузке сократился на 126–867 тактов. Все PWM-отсчёты совпали
с предыдущим плеером и независимым C-декодером. При пересборке все 18
прежних образов WebUI совпали побайтно.

Отдельный AVR ELF проверил 2 460 483 произведения. Перебраны все
коэффициенты в окрестности обоих порогов, а также сетка до пределов
±516096 и детерминированная случайная выборка.

[Парные замеры](measurements.json) фиксируют AVR-GCC 7.3.0, GNU AVR ABI,
simavr 1.6, 16 МГц, 8 кГц, FIFO 32 и предварительное заполнение 24.
