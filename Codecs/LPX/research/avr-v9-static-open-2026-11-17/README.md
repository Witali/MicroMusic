# Одиночный запуск LPX v9 из обнулённой BSS

Среда запуска AVR очищает BSS перед `main`. Статический декодер
проигрывателя использует эти нули при первом и единственном открытии
потока. Метод доступен только проигрывателю при сборке с одной
итерацией. Публичный `begin()` и воспроизведение с повторами сбрасывают
состояние при открытии. На AVR5 проверка заголовка вынесена из `main`,
чтобы LTO не совмещала распределение регистров с циклом декодирования.

| ATmega328 и ATmega328P | До (`3d06727f`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3410–3411 Б | 3356–3357 Б |
| Наибольшее среднее время с IRQ | 760,73 такта/отсчёт | 760,73 такта/отсчёт |
| Статическая SRAM / пиковый стек | 433 / 24 Б | 433 / 24 Б |

Все 22 нагрузки на каждом чипе прошли с IRQ. PWM побитно совпал с C
и предыдущим ASM, пропусков не было. 33 дополнительных прогона
сравнили короткие потоки, повтор и ошибки до и после запуска таймера.
22 образа ATtiny88 и 18 образов WebUI совпали побайтно.
[Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц при 8 кГц, два сегмента
LPC, очередь 32 с начальным заполнением 24. Замеры выполнены в симуляторе.
