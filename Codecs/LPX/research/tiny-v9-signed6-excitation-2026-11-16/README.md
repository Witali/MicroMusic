# Шестибитное возбуждение LPX v9 на AVR25

Код возбуждения занимает диапазон −32…31, а масштаб Q4 кратен 16.
Шесть шагов двоичного умножения оставляют результат с множителем
четыре. Деление масштаба на четыре перед циклом сохраняет точное
произведение. Для отрицательного кода поправка вычитает вклад знака
и убирает оставшийся бит из младшего байта. Переносимый C-бэкенд
вычисляет то же произведение обычным умножением.

| Показатель | База `8a1a0310` | После |
| --- | ---: | ---: |
| Программа, включая плеер и таблицы, без звука | 4276–4277 Б | 4262–4263 Б |
| Наибольшее среднее время декодера с IRQ | 1617,933704 такта | 1617,535848 такта |
| Статическая SRAM / пиковый стек | 433 / 50 Б | 433 / 50 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

Все 22 нагрузки ускорились на 0,21–3,84 такта на отсчёт с учётом IRQ.
PWM совпал побитно с предыдущим AVR-плеером и независимым C-декодером.
Проверены все 2048 сочетаний кода и масштаба на AVR25 ASM, AVR25 C и
принудительном generic. Все 18 прежних образов WebUI воспроизвелись
при повторной сборке побайтно.

[Парные замеры](measurements.json) фиксируют SRAM512, AVR-GCC 7.3.0,
GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц и очередь 32 с заполнением 24.
