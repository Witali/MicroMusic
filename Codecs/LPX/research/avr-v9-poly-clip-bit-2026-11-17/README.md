# Насыщение суммы полиномов до деления

В знаковых 24 битах точное деление суммы пополам нужно при старшем
байте 0 или 255. Для остальных значений результат уже достигает
границы ±32767. В пределах этих двух байтов `ROR` оставляет
отброшенный бит в переносе. Для отрицательных значений `ADC`
добавляет этот бит обратно, реализуя округление к нулю.
Точное значение −32768 ограничивается до −32767.

| Сборка | Flash без звука до (`57ac2cee`) | После | Максимум среднего с IRQ |
| --- | ---: | ---: | ---: |
| ATtiny88 | 3744–3745 Б | 3742–3743 Б | 1579,90 такта/отсчёт |
| ATmega328 и ATmega328P | 3318–3319 Б | 3316–3317 Б | 759,79 такта/отсчёт |

Все 22 нагрузки на каждом чипе дали прежние PWM побитно, без
пропусков и роста времени или памяти. Модель проверила все 16 777 216
значений signed24. На ATmega328P под Timer1 IRQ выполнено 132 088
проверок, включая все значения, для которых используется деление.
Переносимый C выбирается через `LPX4_ENABLE_ASM=0`.
18 собранных образов WebUI совпали побайтно. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц при 8 кГц, два сегмента
LPC, очередь 32 с начальным заполнением 24. Замеры выполнены в симуляторе.
