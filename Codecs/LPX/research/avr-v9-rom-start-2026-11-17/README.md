# Общий запуск проигрывателя LPX v9 на AVR

Декодер проверяет размер и тип заголовка, затем копирует из Flash
десять байт в поля SRAM в порядке формата LPX. Статические проверки
смещений связывают каждое поле с соответствующим словом. Один заранее
проверенный диапазон позволяет использовать короткий цикл `LPM Rd,Z+`.
Проверки частоты, количества отсчётов, коэффициентов и длины идут
после копирования.

Статический экземпляр проигрывателя использует память, уже обнулённую
кодом запуска. Обычный `begin()` сбрасывает историю перед открытием
каждого потока на ATmega. Сборки C и ASM используют одну раскладку
полей. Ускоренное чтение выбирается явным разрешением ASM.

| Целевая ASM-сборка | Flash до / после, без звука | Наибольшее среднее время с IRQ после | SRAM / пиковый стек |
| --- | ---: | ---: | ---: |
| ATtiny88 | 3962–3963 / 3962–3963 Б | 1584,66 такта/отсчёт | 433 / 44 Б |
| ATmega328/328P | 4056–4057 / 3922–3923 Б | 782,99 такта/отсчёт | 433 / 35 Б |

На 22 нагрузках каждого чипа PWM совпал с C. Пропусков, замедлений
и роста пикового времени заполнения очереди не было. Отдельно проверены
повторное воспроизведение и публичный API с повреждёнными и короткими
заголовками. Все 18 образов WebUI совпали побайтно.
[Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
