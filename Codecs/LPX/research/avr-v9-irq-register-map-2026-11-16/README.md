# Имена регистров IRQ через .equ в LPX v9

[`irq_registers.inc`](../../01_ACTIVE_Q0_CODEC/examples/ATTINY88_V5_PLAYER/irq_registers.inc)
задаёт числовые имена для регистра отсчёта и регистра копии SREG.
AVR-GAS использует числовые константы как регистровые операнды.
Сборщик читает ту же пару и резервирует её в основном коде через
`-ffixed`. Путь к .inc передаётся при компиляции, чтобы ассемблер
мог открыть его из временного файла LTO.
[Документация GNU as для AVR](https://sourceware.org/binutils/docs/as.html#AVR-Regs)

Пара `r10:r11` общая для целевых v9-сборок ATtiny88, ATmega328 и
ATmega328P. Проверка ELF берёт номер вектора из заголовка устройства,
сверяет операнды ISR и проверяет использование зарезервированных
регистров в основном коде. Сборка с обычным C ISR доступна отдельно.

| Целевая ASM-сборка | Flash до / после | Пиковый стек до / после | Максимальное среднее с IRQ |
| --- | ---: | ---: | ---: |
| ATtiny88 | 4168–4169 / 4160–4161 Б | 48 / 45 Б | 1591,61 такта |
| ATmega328/328P | 4536–4537 / 4536–4537 Б | 35 / 35 Б | 809,94 такта |

На всех 22 нагрузках каждого чипа PWM совпал побитно, пропусков с IRQ
не было. Статическая SRAM составляет 433 Б. На ATtiny88 суммарный
расход со стеком снизился с 481 до 478 Б. На ATmega замеры времени и SRAM
совпали с базой. 18 образов WebUI пересобрались побайтно.
[Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц, 8 кГц, два сегмента LPC,
очередь 32 с заполнением 24. Измерения получены в симуляторе.
