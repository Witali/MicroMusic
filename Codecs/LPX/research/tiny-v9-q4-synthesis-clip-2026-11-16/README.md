# Прямое насыщение накопителя Q4 на AVR25

Синтез удаляет дробную тетраду каждого произведения до вычитания.
Накопитель в единицах Q4 поэтому всегда кратен 16. Для попадания результата
в signed16 нужно, чтобы старшее слово лежало между −8 и 7. При выходе
из диапазона знак задаёт насыщение, иначе два выходных байта собираются
из тетрад с помощью `SWAP`. Точное значение −32768 заменяется на −32767.
Переносимый C-бэкенд выполняет те же преобразование и насыщение.

| Показатель | База `13041e26` | После |
| --- | ---: | ---: |
| Программа, включая плеер и таблицы, без звука | 4418–4419 Б | 4412–4413 Б |
| Наибольшее среднее время декодера с IRQ | 1622,193879 такта | 1620,015106 такта |
| Статическая SRAM / пиковый стек | 433 / 50 Б | 433 / 50 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

Все 22 нагрузки сохранили точный PWM при сравнении с предыдущей сборкой
и независимым C-декодером. Среднее время декодера с IRQ уменьшилось на
2,07–9,47 такта на отсчёт. Максимум на один вызов сократился на 2–11 тактов.
Прямой AVR-тест в simavr перебрал 16 777 216 целых входов, представленных
в Q4. Проверки C, ASM и принудительного generic дополнительно упражняют
синтез вместе с насыщением, включая сдвиг и границы буфера истории.
Все 18 прежних образов WebUI пересобрались побайтно.

[Парные замеры](measurements.json) фиксируют сборку SRAM512 на
AVR-GCC 7.3.0 и GNU AVR ABI. Симуляция simavr 1.6 использует 16 МГц,
8 кГц, FIFO 32 и предварительное заполнение 24.
