# Общий расчёт масштаба v9 для AVR25 и AVR5

В заголовке LPX v9 пять бит масштаба и три бита усиления читаются одним
запросом. Шкала Q4 вычисляется точными сдвигами двух мантисс и
округляется к ближайшему целому шагу. AVR5 пропускает сдвиги для
индексов 0–5, поскольку они округляются к нулю. На AVR25 используется
прежняя последовательность сдвигов. Если ASM отключён ключом
`LPX4_ENABLE_ASM=0`, доступен переносимый C с исходной таблицей.

| ATmega328 и ATmega328P | До (`573aebc0`) | После |
| --- | ---: | ---: |
| Flash с проигрывателем и таблицами, без звука | 3770–3771 Б | 3740–3741 Б |
| Наибольшее среднее время с IRQ | 770,77 такта/отсчёт | 770,60 такта/отсчёт |
| Статическая SRAM / пиковый стек | 433 / 35 Б | 433 / 35 Б |

На всех 22 нагрузках каждого ATmega PWM побитно совпал с C и
предыдущей ASM-сборкой. Пропусков не было, среднее и пиковое время
и запас очереди прошли парные проверки. На ATmega328P проверены
все 256 сочетаний масштаба и усиления для каждого из P4, P6 и sparse80
в сборках с Q4 и без Q4. 22 образа ATtiny88 и 18 образов WebUI
совпали побайтно. [Парные замеры](measurements.json)

AVR-GCC 7.3.0, GNU AVR ABI, simavr 1.6, 16 МГц при 8 кГц, очередь 32
с заполнением 24 перед стартом, два сегмента LPC. Замеры выполнены
в симуляторе.
