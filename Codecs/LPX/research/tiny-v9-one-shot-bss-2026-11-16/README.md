# Первый поток из очищенной BSS на ATtiny88

Однократный ROM-проигрыватель использует состояние статического декодера
сразу после очистки BSS в AVR-стартапе. Приватный вызов передаёт эту
гарантию в общий парсер. Публичный `begin()` и сборки с повторами
вызывают обычный сброс перед открытием потока.

| Показатель | База `970616ec` | После |
| --- | ---: | ---: |
| Программа, включая плеер и таблицы, без звука | 4404–4405 Б | 4352–4353 Б |
| Наибольшее среднее время декодера с IRQ | 1619,933547 такта | 1619,933547 такта |
| Статическая SRAM / пиковый стек | 433 / 50 Б | 433 / 50 Б |
| Минимум отсчётов в очереди перед выдачей | 24 | 24 |
| PWM-отсчёты / пропуски с IRQ | 308 339 / 0 | 308 339 / 0 |

На всех 22 нагрузках с IRQ совпали PWM, среднее время и пик вызова
декодера. Первый отсчёт появился на 2039–2041 такт раньше. Проверены
14 сценариев запуска и повтора,
включая короткие потоки, ошибки заголовка и обрыв после начала звука.
В трёх дополнительных прогонах вся SRAM перед AVR-стартапом заполнена
значением `0xa5`. PWM совпал, пропусков не было. Во всех трёх ELF
осталась очистка BSS. Сброс декодера удалён линковщиком из однократной
сборки. Все 18 прежних образов WebUI воспроизвелись при сборке побайтно.

[Парные замеры](measurements.json) фиксируют сборку SRAM512 на AVR-GCC
7.3.0 и GNU AVR ABI. Модель simavr 1.6 использует 16 МГц, 8 кГц,
FIFO 32 и предварительное заполнение 24.
