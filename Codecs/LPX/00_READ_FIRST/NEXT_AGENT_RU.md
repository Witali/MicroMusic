# Точное задание следующему агенту (актуально на 25.10.2026)

**База:** `01_ACTIVE_Q0_CODEC/` L4HY v2 Q0; не менять код декодера без отдельного решения. Провести `unittest discover` из README и зафиксировать контрольные SHA эталонов.

**Шаг 1:** закончить универсальный WAV→LPX4, использовать имеющиеся анализаторы первоначального LPX3, а не просто менять упаковку уже готового LPX3. Кодировщик должен автоматически получать LSF и возбуждение из WAV.

**Шаг 2:** применять Python/Numba/batch C++ оптимизатор к незнакомым английским/русским записям и музыке. Ищем качество после Q0 PCM16, не на внутреннем float-LPC. Измеряем STOI (только речь), SER, спектральную ошибку, сохранение уровня, реальные размеры. Полный файл ≤ бюджет; если требуется рост, описать качество-байтовую кривую отдельно.

**Шаг 3:** расширить encoder-side beam search (4/8/16 состояний, окно 20–40 отсчётов) и совместную настройку LSF/возбуждения с конечным C++ PCM16. Сохранять ограничения размера и откат при ухудшении, не усложнять AVR.

**Шаг 4:** выполнить не символический, а связанный AVR ELF/HEX и измерить такты на ATmega328P 16 МГц (или доверенном независимом циклоточном симуляторе). Особое внимание: 20/80/160-сэмпловые пики при LPC пересчётах, ISR, график буфера, overruns/underruns. Значение 2000 CPU-тактов/отсчёт — общий средний бюджет с включённой периферией, а не допустимый максимум `next()`.

**Шаг 5:** сравнить LPX3/LPX4/Opus/AAC-LC на одинаковых *реальных размерах* (для AAC и Opus подобрать битрейты поиском), с одной исходной записью 8 кГц / 16 бит / моно. Лицензии данных фиксировать.

**Ограничения:** не распространять приватные мультфильмы; не выдавать учебную оптимизацию за независимую; не смешивать численный фильтровый SNR и SER к исходнику; не утверждать готовое устройство, если не сняты реальные такты AVR.
