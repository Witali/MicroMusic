# Следующие задачи (следующему агенту)

1. **Восстановить окружение** из `01_CURRENT_PRIMARY_Q0/`, запустить 22 Python-теста и компиляцию C++ из README. Использовать `08_PRIVATE_EVIDENCE/CURRENT_Q0_EXAMPLES/` для двух обучающих русских фраз. Проверить SHA-256 эталонов, размеры, SER/STOI самостоятельно, не использовать скопированные метрики без подтверждения.
2. **Никогда не изменять `src/Lpx4HybridCore.cpp/.h` в основной Q0 ветке без отдельного согласования**. Цель — новый кодировщик, тот же L4HY v2, тот же AVР-декодер и не больший суммарный файл.
3. **Реализовать на ПК delayed-decision (beam) поиск кодов возбуждения**, ширины 4,8,16; окно 20–40 отсчётов и дешёвое продолжение до 80/160, чтобы учесть рекурсию LPC и длинные хвосты. Сначала фиксировать длину существующих кодовых слов и режимы блоков; затем, если полезно, разрешить перераспределение бит при том же размере файла. Все предложения подтверждать полным выходом C++ PCM16.
4. **Совместно оптимизировать LSF и возбуждение** 2–3 проходами при фиксированной длине потока, следить за стабильностью коэффициентов и переходами кадра.
5. **Глобальное распределение бит / rate-distortion**: кандидаты по блокам 80 отсчётов, knapsack или DP с эффектом границ кадров; реальная длина файла ≤ baseline. Добавить грубую и точную стоимость; запрещать обман через изменение PCM выравнивания/усиления.
6. **Критерии приёма**: файл не больше 4931/4047 Б соответственно; SER/ STOI на той же подготовке WAV не уменьшаются; 16-битный декодер совпадает с независимой C++ моделью; не увеличивается число/пик битовых вызовов там, где это может повлиять на 16 МГц, а реальные такты подтвердить на чипе/циклоточном симуляторе. Подтвердить результат на новых русских и английских дикторах; источник лицензии фиксировать.
7. **Уточнить реальное время**: независимая цикл-проверка готовой linked ATmega328P прошивки, включая LSF→LPC на кадрах, LPC-контуры, ISR Timer0/Timer2, stack, audio buffer occupancy, underruns. Не утверждать `16 MHz passes` по ПК замерам или числу операций `readBit()`.
8. **Правовой режим**: материалы `08_PRIVATE_EVIDENCE` держать приватными; не публиковать реальные кинофразы / кодированные производные.
