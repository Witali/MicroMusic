# MicroMusic LPX3 / LPX4 — чистая передача исследований и исходников

**Дата упаковки: 25 октября 2026 года.** Это частный, подготовленный для нового агента проектный архив. Из него удалены временные каталоги, промежуточные компилированные объекты, дубликаты старых ZIP-релизов, кэши и нерезультативные короткие снимки. Ключевые экспериментальные семейства сохранены в виде распакованных автономных проектов.

## С чего начать

**Основная актуальная ветка**: `01_ACTIVE_Q0_CODEC/` — LPX4 L4HY v2, **старый фиксированный LPC Q0** для ATmega328P, 16 МГц, 8 кГц моно, профиль воспроизведения исходно ориентирован на PWM. Пользователь предпочёл совершенствовать *ПК-кодировщик*, а не увеличивать вычисления декодера. Последние проверенные на двух *обучающих* русских фразах результаты:

| Фраза | Байты LPX4 Q0 | PCM16 SER относительно оригинала | STOI |
|---|---:|---:|---:|
| «Чего тебе нужно?» | 4 931 | 32,367 дБ | 0,971482 |
| «Что ж ты не отвечаешь?» | 4 047 | 30,591 дБ | 0,935685 |

`PCM16` измеряется **после** LPC, de-emphasis и постфильтра, **до** PWM. SER здесь = отношение мощности исходной записи к мощности полной ошибки восстановления. Это НЕ аналоговый SNR и НЕ численный SNR фильтра относительно точного арифметического эталона.

**Отдельная ускоренная ветка кодировщика**: `04_PC_ENCODER_BATCH_ACCELERATION/` — Numba + пакетная загрузка C++ в один процесс. Она была проверена на воспроизведение того же потока по сравнению с тогдашним baseline, но не считайте её автоматически влитой в самый новый Q0-кодировщик. При интеграции сверьте исходники и exact PCM.

**История**: `00_READ_FIRST/HISTORY_FULL_RU.md`; краткая история старой передачи `00_READ_FIRST/PREVIOUS_HANDOFF/HISTORY_RU.md`. 

**Исходники старых форматов**: `02_HISTORICAL_FOUNDATIONS/` (включая отдельную историческую Arduino-библиотеку LPC2, НЕ LPX3), `03_RESEARCH_MILESTONES/` (отобранные версии L3AV, Rice v5/v7, Hybrid, CELP, Q1).

**Последнее внешнее исследование**: `05_BENCHMARKS/` — сравнение LPX3/LPX4 c Opus и AAC-LC на ранее неизвестных английских/музыкальных и наших русских фразах. Параметры и оговорки см. в отчётах; не объединять неподобранные одинаковые битрейты с тестами равных файлов по размеру.

**WAV→LPX4**: `06_UNIVERSAL_WAV_ENCODER_WIP/`. Универсальный независимый кодировщик **не завершён**. Из последней рабочей попытки сохранилась вычисленная английская LPC-трасса; готового самодостаточного универсального WAV→L4HY исходника там пока нет. Код нынешнего Q0 опирается на подготовленные LSF/коэффициенты старого потока.

**Приватный звук**: `07_PRIVATE_SPEECH_EXAMPLES/`: изначальные MP3 и производные WAV, PCM, LPC-таблицы, потоки, HTML A/B. **Не публиковать весь архив** из-за прав на исходные речевые фрагменты и производные. Для публикации отделять исходники/синтетику.

## Как протестировать рабочую Q0 ветку

```bash
cd 01_ACTIVE_Q0_CODEC
python -m pip install -r requirements.txt
PYTHONPATH=tools:encoder_vbr/tools python -m unittest discover -s tests -p 'test_*.py' -q
```

Нужны g++ (для C++ декодера), Python 3 и зависимости NumPy/SciPy/Numba/pystoi/soundfile. Для Opus/AAC бенчмарка — FFmpeg со сборкой кодировщиков, которые использовались в исследованиях. Некоторые тесты метрик требуют приватных входных WAV и их правильного размещения.

## Жёсткие технические ограничения

- Память ATmega328P: 2 КБ SRAM и 32 КБ Flash, 16 МГц. При 8 кГц имеется **средний бюджет 2000 CPU-тактов на отсчёт**, включая весь ISR, LPC-подкадры, чтение внешней памяти и буферы.
- **Реальное время на ATmega328P не доказано** аппаратно/независимым циклоточным исполнением полного ELF/HEX. Сумма AVR `.text` секций, ПК-бенчмарки и подсчёт readBit не являются измерением тактов.
- Q1 эксперимент (дополнительный дробный бит) не стал основной версией: математически точнее, но расходует больше ресурсов и не показал убедительного субъективного улучшения.
- Не раздувать код декодера. Исследовать encoder-side lookahead/beam search, совместную оптимизацию LSF+возбуждения и распределение бит при размере L4HY не выше baseline; проверять конечный PCM16 C++ декодером, SER, STOI и прокси числа вызовов чтения бит.
- Тренировочные результаты SER/STOI на двух русских кинофразах нельзя обобщать на независимую речь. 24 октября независимый английский/музыкальный тест показал, что простое LPX3→LPX4 преобразование ухудшает SER и уступает Opus/AAC по соотношению качества и размера.

## Содержание

- `00_READ_FIRST/` — история, подтверждённые результаты, план и манифест.
- `01_ACTIVE_Q0_CODEC/` — главные рабочие исходники Q0 и тесты.
- `02_HISTORICAL_FOUNDATIONS/` — первоначальный LPX3 и исторический LPC2.
- `03_RESEARCH_MILESTONES/` — важнейшие самостоятельные предыдущие разработки, не все промежуточные выпуски.
- `04_PC_ENCODER_BATCH_ACCELERATION/` — ускоренный кодировщик.
- `05_BENCHMARKS/` — реальный сравнительный бенчмарк Opus/AAC/LPX, скрипты, открытая синтетика, оценки.
- `06_UNIVERSAL_WAV_ENCODER_WIP/` — сохранившийся незаконченный этап.
- `07_PRIVATE_SPEECH_EXAMPLES/` — реальные приватные звуковые эталоны и A/B.

Буквальная стенограмма сообщений здесь недоступна: история — восстановленный технический журнал и исходники. Метрики до новой проверки в точном окружении считать историческими воспроизводимыми отчётами, а не новыми аппаратными измерениями.
