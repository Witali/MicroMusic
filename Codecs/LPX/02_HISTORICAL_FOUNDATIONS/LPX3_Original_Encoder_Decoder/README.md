# MicroMusic — LPC2 Voice v3 (LPX3)

## Цель и результат

Эксперимент по сохранению тембра **разных голосов**: низкий мужской и два высоких голоса. Предыдущий LPC2 Improved/Voice v2 использовал стандартную chirp-последовательность возбуждения для всех дикторов. LPC/LSF-фильтр описывает форму спектра, но не сохраняет форму индивидуальных голосовых импульсов, поэтому звучание было приглушённым и иногда менялась высота голоса.

**LPX3** сохраняет старый битовый LPC2 v2 как *параметрический слой* и добавляет более точный слой возбуждения. Чтобы проверить потенциал схемы, созданы профили 2, 3 и 4 бита на отсчёт. Декодер использует **те же 10 коэффициентов LPC/LSF** из вложенного LPC2, но возбуждение получает из кодированного потока, а не из стандартного генератора chirp+noise. Эти два режима намеренно сосуществуют, чтобы сравнивать качество и экономичность.

Это **не низкобитрейтная замена классического LPC2**: файл LPX3 при 8 кГц занимает примерно 19/27/35 кбит/с (с учётом базового LPC2 и служебных данных). Оригинальный LPC2 Voice v2 остаётся режимом примерно 2–4 кбит/с. Высокое сходство оплачивается количеством байтов. LPC2 с такими данными невозможно разместить в 1 КБ Flash ATtiny13A; прежний TinyLPC-7/8 остаётся отдельным MCU-проектом. Приоритет этого эксперимента — **исследовать предел качества и создать эталон** для дальнейшей оптимизации.

## Как работает кодирование

1. Привести запись к моно **8000 Гц**. Записи любой частоты поддерживаются через ffmpeg.
2. Автоматически оценить F₀ через pYIN и выбрать диапазон для LPC2. Испытать исходную Viterbi-трассу и pYIN, степень формантного постфильтра 0.10/0.35 и автоматический диапазон. Выбрать вариант по совокупности STOI и спектральной ошибки; никакого флага `male`/`female` нет.
3. Закодировать спектральную огибающую в исходный LPC2 Voice v2 (LSF, 10 коэффициентов) и сохранить это как вложенный `.lp2`.
4. В **замкнутом цикле** (analysis-by-synthesis) декодировать каждый кандидат квантованного возбуждения, проверять ошибку относительно исходного сигнала с предыскажением, подбирать шаг в каждом блоке 80 отсчётов. Шаг кодируется 1 байтом на 10 мс; сам импульс/возбуждение — 2, 3 или 4 битами на отсчёт.
5. Подобрать яркость спектра только по исходной записи (0–0.7, фиксированная сетка 15 значений), записать её в 16-битное поле заголовка. Никаких ручных настроек по полу диктора.
6. Независимо выполнить декодер Python и JavaScript и проверить побитовый поток/расхождение аудиоотсчётов.

## Испытания

| Фраза | STOI LPC2 Voice v2 | LPX3 2 бит/отсчёт | LPX3 3 бит/отсчёт | LPX3 4 бит/отсчёт |
|---|---:|---:|---:|---:|
| Винни-Пух (низкий мужской голос) | 0.610 | 0.928 | 0.971 | 0.986 |
| «Чего тебе нужно?» (высокий голос) | 0.624 | 0.768 | 0.803 | 0.833 |
| «Что ж ты не отвечаешь?» (высокий голос) | 0.580 | 0.735 | 0.765 | 0.809 |

STOI — суррогатная автоматическая метрика **разборчивости**, а не оценка идентичности тембра. Спектральное расстояние тоже не гарантирует субъективного качества. Сравнивайте варианты на слух в `index.html` или `samples/<name>/AB_original_v2_v3.wav`. Для Винни-Пуха улучшение особенно выражено; на высоких голосах остаётся возможный высокочастотный шум.

**Чистота проверки:** всё аудио в тестах получено из одних и тех же исходных записей, частота 8000 Гц, без подгонки вручную под пол диктора. 9 LPX3-потоков проверены независимыми реализациями Python/JS (максимальное расхождение около 6e-8).

## Установка

Python 3.10+, `ffmpeg`, Chromium/Chrome (для анализа исходного LPC2 Voice v2), `pip install -r requirements.txt`, затем `playwright install chromium` если Chromium отсутствует в системе. Веб-декодер LPX3 не требует Chromium и интернета.

### Автоматически обработать MP3/WAV

```bash
python train_encode.py --input my_voice.mp3 --name my_voice
python make_player.py --clips my_voice --out my_voice_player.html
```

Создаст `samples/my_voice/original.wav`, `base_lpc2.lp2`, три LPX3-файла, их WAV-версии и `metrics.json`. Для быстрой проверки без относительно дорогого pYIN используйте `--fast`.

### Обработать WAV при известном LPC2 v2

```bash
python hybrid_codec.py speech_8000.wav --base speech_8000.lp2 --bits 3 --out sample.lpx3
python hybrid_codec.py sample.lpx3 --out recovered.wav
```

### Пересобрать A/B и проверить декодер

```bash
python benchmark.py
python make_player.py
python make_ab.py
python verify_project.py
```

`index.html` — автономный мобильный плеер. Нажать кнопку **▶** (Web Audio) — никаких длинных `data:` ссылок в HTML audio-тегах. Кнопка «Проверить декодер» реально читает все LPX3-файлы и синтезирует PCM. Дополнительно доступны обычные WAV-файлы для телефонов, на которых HTML-звук заблокирован.

## LPX3 v1, бинарный формат

Заголовок: 24 байта, little endian.

| Смещение | Поле |
|---:|---|
| 0 | ASCII `LPX3` |
| 4 | version = 1 |
| 5 | bits = 2/3/4 |
| 6 | sample rate, uint16 (8000 Гц в тестах) |
| 8 | number of samples, uint32 |
| 12 | embedded LPC2 v2 bytes, uint32 |
| 16 | excitation block size, uint16 (=80) |
| 18 | brightness ×1000, uint16 (0..700) |
| 20 | count of blocks, uint32 |

После заголовка: исходный LPC2 v2 бинарный поток, затем **1 байт на каждый блок** (логарифмический масштаб квантования), затем упакованные младшим битом вперёд коды возбуждения. Диапазон знаковых кодов: `[-2^(bits-1), 2^(bits-1)-1]`; декодер восстанавливает источник и прогоняет его через LPC all-pole фильтр и деэмфазу с тем же коэффициентом, который находится во вложенном LPC2. Формантные LSF интерполируются по 8 подкадрам на 20-мс кадр. Входной LPC2 v1/другие LPC контейнеры теоретически поддерживаются декодером базовой модели, но в выпуске тестировался только v2.

## Структура

- `hybrid_codec.py` — сам кодировщик, битовая упаковка, декодер Python, закрытый контур квантования.
- `train_encode.py` — полностью автоматический запуск на новой записи, перебор настроек, качество.
- `lpx3_decoder.js` — реальный автономный JS-декодер LPC2+LPX3.
- `lpc2_v2_reference.html` — сохранённый оригинальный LPC2 Voice v2, используется при кодировании и преобразовании LSF.
- `make_player.py`, `make_ab.py` — плеер и A/B WAV.
- `benchmark.py`, `verify_project.py` — сравнение с оригиналами и тест синхронности Python/JavaScript.
