# LPC2 decoder для ATmega328P

Это потоковый декодер формата `LPC2`, который создаёт режим **LPC2 Improved**
в `Audio Codec Lab v11`.

## Рекомендуемый профиль файла

В веб-странице перед сохранением `.lp2`:

- кодек: `LPC2 Improved`;
- частота дискретизации: **8 кГц**;
- шаг кадров: **20 мс**;
- окно анализа: **32 мс**;
- LPC order: 10;
- предыскажение: около `0.85`.

Обычный звонкий кадр остаётся 53-битным. При 8 кГц ATmega328P получает
около 2000 тактов на один выходной отсчёт.

## Что реализовано

- разбор 36-байтного заголовка `LPC2`;
- LSB-first битовый поток;
- энергия 5 бит;
- режим возбуждения 2 бита;
- repeat 1 бит;
- pitch 6 бит;
- LSF: `5,5,4,4,4,4,4,3,3,3` бит;
- декодирование LSF и преобразование в LPC;
- интерполяция параметров по 8 подкадрам;
- noise / mixed / voiced / transient excitation;
- 10-полюсный целочисленный синтезирующий фильтр;
- деэмфазис из заголовка;
- лёгкая коррекция яркости;
- ФВЧ/DC-block;
- PWM 62,5 кГц на Arduino D3.

Преобразование LSF в LPC выполняется в `loop()` один раз на кадр с плавающей
точкой. В прерывании используются только целые числа.

## Подключение выхода

`D3 (OC2B) -> 1 кОм -> AUDIO OUT`

Из точки `AUDIO OUT`:

- конденсатор 22 нФ на GND;
- далее желательно разделительный конденсатор 1–10 мкФ;
- вход активной колонки или усилителя.

Нельзя подключать динамик непосредственно к D3. Для динамика нужен усилитель,
например PAM8403 или LM386.

## Конфликты таймеров

Декодер полностью занимает:

- Timer1 — частота дискретизации;
- Timer2 — быстрый PWM;
- D3 — OC2B.

Во время воспроизведения нельзя использовать:

- `tone()`;
- библиотеку `Servo`;
- `analogWrite()` на D3 и D11;
- другие библиотеки, перенастраивающие Timer1/Timer2.

Timer0 не изменяется, поэтому `millis()` продолжает работать, но не следует
делать длительные операции в `loop()`.

## SD-карта

Пример `LPC2_SD_Player` использует стандартную библиотеку SD. Из-за 2 КБ SRAM
она находится близко к пределу ATmega328P. Во время воспроизведения:

- не используйте `String`;
- не печатайте постоянно в Serial;
- не вызывайте `delay()`;
- вызывайте `decoder.service()` на каждой итерации `loop()`.

Если счётчик underrun растёт, лучше:

1. использовать вариант PROGMEM;
2. перейти на SdFat с аккуратным буфером;
3. хранить файл в последовательной SPI Flash;
4. снизить нагрузку других обработчиков прерываний.

## PROGMEM

Для фиксированных фраз LPC2 особенно удобен: при 2–3 кбит/с одна секунда
занимает примерно 250–375 байт.

Преобразование:

```bash
python3 tools/lp2_to_header.py voice.lp2 \
  examples/LPC2_PROGMEM_Player/voice_lpc2.h voiceLpc2
```

После этого откройте пример `LPC2_PROGMEM_Player`.

## Отличие от браузерного декодера

Формат файла разбирается полностью совместимо. Для укладывания в ресурсы
ATmega328P синтезатор немного упрощён:

- LSF преобразуются в LPC один раз на кадр;
- между кадрами интерполируются LPC-коэффициенты;
- для незвонких кадров используется LPC порядка 4 с нулевыми старшими
  коэффициентами;
- тяжёлый 20-полюсный формантный постфильтр браузера не используется.

Яркость и ФВЧ реализованы дешёвыми фильтрами и не требуют дополнительных битов.
