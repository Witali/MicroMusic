# LPX: последовательные раунды ускорения

Начальная версия: `5d608739`. Критерий пользователя: остановиться после
**трёх последовательных раундов с выигрышем ≤1%**. Успешный раунд >1%
сбрасывает этот счётчик. Полезные изменения ≤1% можно сохранить; неудачные
кандидаты откатываются и учитываются как нулевой выигрыш раунда.

Метрика: `100 * (1 - sum(after_wall_cycles) / sum(before_wall_cycles))`
для фиксированных 91 уникального потока, по 32000 отсчётов каждый, из
`research/q0-decoder-size-speed-2026-10-26/streams.json`. ASM AVR5,
ATmega328P 16 МГц / 8 кГц, AVR-GCC 7.3 `-Os`, queue512/prefill384/unroll9,
v3 mask24, активные IRQ. Данные и настройки не меняются между раундами.
Короткая выборка допускается для отсева идей, но не для итогового процента.

Раунд — исследование одного участка декодера с проверкой нескольких
разумных вариантов при необходимости; не разбивать одну правку искусственно
ради счётчика. В конце зафиксировать лучший подтверждённый вариант либо
обоснованный отказ, затем пересчитать счётчик.

Инварианты: прежние потоки/качество, побитовое совпадение native PCM16/PWM,
полезного AVR PWM; C fallback на AVR и других архитектурах; явное включение
ASM, настоящие архитектурные и memory macros. Не ухудшать underrun на
полном наборе и длинных контрольных потоках. Размер Flash, RAM, стек и
максимум окна 160 отсчётов учитывать отдельно. Симуляция не заменяет плату.

## Очередь исследований

1. LPC: накопление в Q4 вместо сдвига каждого произведения на четыре бита.
2. Ограниченная арифметика deemphasis/brightness и PWM.
3. Пакетное чтение unary/Rice вместо вызова readOne для каждого бита.
4. Счётчики, размещение состояния и повторные проверки горячего пути.
5. Точная LSF-интерполяция и преобразование полиномов.
6. Дополнительные направления по результатам профилирования; при необходимости
   пересматривать очередь, сохраняя исходный критерий остановки.

Для каждого раунда сохранять исходные hashes, альтернативы, измерения,
выбранный результат, тесты, процент и текущее число слабых раундов.
Каждое завершённое изменение — отдельный коммит. Полезные архитектурные
приёмы сохранять в AVR cookbook с условиями и пределами измерений.
