# Standalone v5 AVR player

This is a one-shot ATmega328P / 16 MHz player for one or more v5 ROM
segments. OC2B/PD3 uses Timer2 fast PWM at 62.5 kHz; Timer1 CTC requests one
sample every 2000 CPU cycles (8 kHz). The final queued sample plays before
Timer1 stops. Timer2 holds the final duty, as in the diagnostic player.
The production ELF contains no PB0 tick marker, profiling counters, decode
markers or hardware-address metadata.

The selected default is FIFO 256 / prefill 192; FIFO 512 / prefill 384 remains
explicitly available as the measured baseline.

`head`, `tail`, `eof`, `error` and `stopped` are actual playback state. The
foreground publishes head/EOF/error; the ISR publishes tail and terminal
stopped after draining. An abort can also publish stopped while the timer is
inactive or interrupts are masked. Compiler memory
barriers publish queue data before head and finish consumption before tail.
The 512-slot baseline uses short atomic sections for shared 16-bit indices.
The 256/128 builds use byte indices; final head+EOF still publish together
under a short atomic section. This prevents the last-sample ISR from needing
an extra empty output tick. One slot stays empty: capacities 511/255/127.

A bad initial stream or an error during prefill stops before starting audio.
A valid prefix buffered during prefill is left unplayed and discarded; this
matches the existing diagnostic application's prefill-abort behavior. An
error after playback starts drains queued valid output and then stops.
Successful segment boundaries concatenate output without inserted silence.

The checked-in `synthetic_voice.h` is a deterministic 39-byte fixture,
generated by `test_speech_v4.fixture(4, 320)` and `speech_compact.repack`.
Direct compilation uses it by default. The build tool selects a generated
`voice_data.h` inside ignored repository `build/` storage. Multiple input
paths define an ordered reset chain. Private recordings and MIDI inputs do
not belong in this example.

## Build a complete firmware

Run from the repository root with the project's Python packages available:

```text
python Codecs/LPX/01_ACTIVE_Q0_CODEC/tools/build_release_player.py build/release input.l4hy --avr-bin /path/to/avr/bin --queue 256 --enable-asm
```

The tool uses the measured small-code recipe and explicit v5-only flags. It
writes `player.elf`, `player.hex`, a linked map, the exact Flash binary and a
private cost receipt. `--queue` selects the FIFO size and the default prefill
is three quarters of that size; `--prefill` overrides it. Smaller profiles
need their own complete timing admission. Average decode time does not prove
adequate queue headroom.

The default arithmetic backend is C. `--enable-asm` explicitly selects the
supported AVR5 backend. Continuous 8 kHz admission for ASM does not apply to
the slower C path. Hardware definitions come from the actual AVR-LibC device
headers. No diagnostic source participates in the production AVR link.

## Observe playback externally

Compile the host observer against an existing simavr 1.6 / libelf installation
with its zlib and zstd dependencies:

```text
python Codecs/LPX/01_ACTIVE_Q0_CODEC/tools/build_release_observer.py build/observer --include /path/to/native/include/simavr --lib /path/to/native/lib
python Codecs/LPX/01_ACTIVE_Q0_CODEC/tools/build_release_player.py build/release input.l4hy --avr-bin /path/to/avr/bin --queue 256 --enable-asm --observer build/observer/sim_player --lib /path/to/native/lib
```

On Windows add `--wsl Ubuntu` to both commands and provide local paths to the
existing Linux headers/libraries. No tools or packages are installed globally.
The observer gets Timer1 IRQ entry/exit and OCR2B writes from public simavr
APIs. It independently derives useful output, hardware ticks, underruns,
publication/consumption counts, queue state and IRQ duration. Stack observation
covers startup/prefill and playback, with those coverage labels separate.

A separate `player_hardware.cpp` object obtains addresses, vector number and
configuration from vendor headers. It is never linked into the production
ELF. Its sidecar combines those values with actual ELF playback addresses.
Before reading simulated SRAM, the observer validates descriptor bounds,
nonoverlapping state spans, the device model's timers/port, and exact ELF
symbol addresses and sizes. Direct malformed-descriptor tests check rejection
before output artifacts are opened.

Successful playback validation requires full model PWM, exact sample/tick/EOF
counts, zero underruns, an empty queue, the required clock/PWM configuration,
bounded output jitter and no further ticks after EOF. Failure tests separately
check initial abort, prefill abort and draining after playback has started.
Linked-image caching is separate from observer/model/runtime validation, so
changes to host verification refresh evidence without relinking AVR code.

The original project observer uses the [simavr 1.6 interrupt API](https://github.com/buserror/simavr/blob/v1.6/simavr/sim/sim_interrupts.h)
and [IO-register notification API](https://github.com/buserror/simavr/blob/v1.6/simavr/sim/sim_io.h).
No simulator implementation is copied. The existing simavr library is
GPL-3.0-or-later; its sources and licensing remain external and unchanged.
Simulator results do not establish physical-board or analog output behavior.

The selected 256 / 192 profile passes the declared 111 normal + 5 active-IRQ
stress matrix on the frozen final decoder; the complete scope and
[anonymous measured receipts](../../../research/release-player-2026-10-28/README.md)
are retained separately. FIFO 512 remains an explicit validated baseline.
FIFO 128 is available for experiments but rejected by the bounded Flash-size
screen and has no timing admission.
