# A3: глобальное распределение битов Q0

```sh
python tools/global_rate_pcm16.py input.l4hy reference_8k_mono.wav build/global.l4hy --kind speech
python tools/global_rate_pcm16.py music.l4hy music_8k_mono.wav build/music-global.l4hy --kind music --max-candidates 64
```

Вход — один L4HY v2 сегмент до 64 000 отсчётов и исходный PCM16 WAV.
Сохраняются заголовок, LSF и C++-декодер. Нельзя увеличить полный размер
файла, полную ошибку PCM16 или снизить исходный STOI для речи.
По умолчанию нативные bit calls / ROM reads / максимумы за 1/80/160
отсчётов также не могут расти. `--max-cost-growth` позволяет явно изменить
последнее исследовательское ограничение; это не разрешение называть
профиль поддержанным в реальном времени.

1. Полностью нулевое возбуждение перепаковывается существующим режимом
   нулевой разрядности, с тремя вариантами масштаба. Это может сохранять
   PCM побайтно даже при ненулевой памяти LPC/de-emphasis.
2. Из точных Q0 состояний перед каждым блоком 80 отсчётов строятся варианты
   разрядности 0/2/3/4/5/6 и масштаба. Исходный блок всегда остаётся вариантом.
3. Pareto/DP выбирает комбинации по локальной ошибке и битовой стоимости,
   отдельно с абсолютной и нормированной ошибкой. `--max-states` ограничивает
   фронт; при отсечении состояний глобальный оптимум не утверждается.
4. Комбинации целиком регенерируются с последовательной переквантовкой
   или с фиксированными квантованными кодами. Реальная длина считается
   после полной упаковки с действительными pitch/scale контекстами.
5. Проверяются C++ PCM16, независимый парсер и арифметическая модель,
   полная ошибка, STOI и исправленный нативный измеритель нагрузки.
   Не прошедший ограничения вариант отклоняется; исходный поток доступен
   для отката. `--max-candidates` — общий предел уникальных полных проб.

Локальные ошибки и стоимости **не аддитивны для настоящего декодера**:
память фильтра, pitch и дельты масштаба связывают соседние блоки.
DP здесь строит предложения; решение принимает полная нативная проверка.
История состояний и поиск выполняются только на ПК, новых данных или
операций в MCU-код не добавляется.

Минимальный размер кодового слова не гарантирует минимальную нагрузку.
При нарушении read-cost ограничений проверяются варианты упаковки с
существующим RAW-режимом и небольшим запасом 4/16/40 бит на подкадр.
Они сохраняют квантованные значения, но могут занимать больше байтов,
поэтому весь файл снова обязан уложиться в исходный размер. Параметр
`lpx4.encode(..., raw_slack_bits=...)` выключен по умолчанию и не меняет
прежние потоки без явного выбора этой политики.

Крошечный DP проверен полным перебором. Нативные регрессии проверяют
перераспределение бюджета от простых к сложным блокам, сжатие нулевого
возбуждения без изменения PCM, ограничения нагрузки, число проб,
повторяемость и неполный последний блок. После добавления A3 проходят
39 тестов (включая две регрессии исправленных ошибок).

Изменение формата или арифметики AVR здесь не выполняется. Даже равные
read-cost proxies не доказывают равенство тактов; профиль 16 МГц / 8 кГц
из предыдущего полного simavr-измерения остаётся неподдержанным.
