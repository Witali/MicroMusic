# LPX3 / LPX4

Исходники и этапы разработки кодека из
`MicroMusic_LPX_COMPLETE_AGENT_HANDOFF_CLEAN_2026-10-25.zip`.
Актуальная реализация — **[LPX4 Q0](01_ACTIVE_Q0_CODEC/README_RU.md)**:
контейнер L4HY v2, фиксированная арифметика, LPC на 10 коэффициентов,
8 кГц моно, экспериментальный проигрыватель ATmega328P.

Продолжение плана: [результаты оптимизации 25.10.2026](research/q0-encoder-2026-10-25/README.md).
Добавлены WAV-вход, beam/joint-поиск и устойчивые старты LPC; выполнены
сравнение с LPX3/Opus/AAC и измерения полного ELF в simavr.
Следующий этап — [A3: глобальное распределение битов и исправления ошибок](research/q0-global-rate-2026-10-25/README.md).
Он улучшил два из пяти повторно проверенных корпусных примеров при меньшем
размере и прежнем C++-декодере; добавлены защита входных файлов,
аудит Q12 при LSF-refinement и исправление длинного счётчика нагрузки.
Далее добавлен [явно включаемый AVR5 backend](research/q0-avr-realtime-2026-10-25/README.md):
он прошёл полный стенд 16 МГц / 8 кГц без underruns на 19 потоках,
включая длинные сегменты. C fallback и точный восстановленный PCM сохранены.
Последнее продолжение — [проверка всех шести пунктов плана](research/q0-plan-2026-10-25/README.md):
кэш спектра, компактная прошивка, восемь новых голосов, единый поиск
с реальными AVR-тактами, lossless zero packing и тихие границы сегментов.
Далее выполнен [план точного сжатия с учётом распаковки](LOSSLESS_COMPRESSION_PLAN_RU.md):
scale-DP, полный поиск существующих режимов и опциональный компактный v3.
[Измерения](research/q0-lossless-2026-10-25/README.md) показывают размеры,
полный Flash/SRAM и IRQ-такты; v2 по умолчанию сохраняет прежние ELF побайтно.
Далее выполнено [сравнение с Opus, Vorbis и Speex](research/q0-standards-2026-10-25/README.md)
на 27 четырёхсекундных отрывках: SER, RMSE, максимальное отклонение PCM16,
STOI, фактические байты и общий PWM. Сохранены численные результаты,
источники и анонимный локальный набор для прослушивания.
Новый [план качества при меньшем битрейте](LOWRATE_QUALITY_PLAN_RU.md) выполнен:
реальные стоимости кодов, поиск из oversized seed, повторные LSF и совместный
q/scale/pitch-поиск; декодер и его таблицы побайтно прежние.
На 14 общих речевых отрывках новый 12-кбитный потолок против прежнего 16:
фактический audio-битрейт −18,28%, SERΣ 10,59 → 15,10 дБ,
STOI 0,7861 → 0,8294, пик 11961 → 7345 PCM16.
[Отчёт, 82 host-теста, 111 AVR-образов и явный WAV-профиль](research/q0-lowrate-2026-10-25/README.md).

[Расширенный поиск на всех 27 образцах](research/q0-multiseed-2026-10-25/README.md)
проверяет прежний потолок и прежний фактический размер отдельно:
108 точек / 88 полных AVR ELF, без изменения декодера и без underruns.
Затем выполнена [проба 8 кбит/с на трёх прослушиваемых примерах](research/q0-8kbps-2026-10-25/README.md):
те же речь/фортепиано, 7.962–7.990 кбит/с, снижение качества против 12/16
показано явно. Это ограниченный эксперимент, не проверка всего корпуса на 8 кбит/с.

## Проверка актуального Q0

Нужны Python 3, нативный `g++` в PATH и зависимости из `requirements.txt`.
Команды из корня репозитория:

```sh
cd Codecs/LPX/01_ACTIVE_Q0_CODEC
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p 'test_*.py' -v
python tests/verify_release.py 60
python tests/verify_budget.py
```

Тесты используют включённые синтетические данные; приватная речь не нужна.
При импорте прошли 22 теста, проверка 61 совместимого потока и
12 повреждённых входов. Окружение и границы проверки:
[VALIDATION.md](VALIDATION.md).
После продолжения разработки прошли 32 теста; новое окружение и измерения
сохранены в [исследовании](research/q0-encoder-2026-10-25/README.md).
После A3 и исправлений проходят 44 теста; [парные AVR-измерения](research/q0-global-rate-2026-10-25/README.md)
включают все три изменённых потока, в том числе приватный training-пример.
После оптимизации AVR проходят 46 host-тестов, отдельная проверка
32 889 арифметических cases на каждом из C / ASM / forced-generic AVR ELF
с активным Timer1 IRQ и повторная release-проверка 61 потока / 12 ошибок.
На последнем этапе проходят 52 host-теста, 17 931 мутация под ASan/UBSan,
все три разворачивания ASM и непрерывные цепочки из шести сегментов.

**AVR5 с `LPX4_ENABLE_ASM=1` прошёл simavr 16 МГц / 8 кГц** на описанной
матрице: 1302–1771 средних wall cycles/отсчёт, активные IRQ, очередь
512 Б и prefill 384, 0 underruns, точный PWM. Компактный профиль queue 256 /
prefill 160 / unroll 3 также прошёл 19 потоков: SRAM 845 Б, 0 underruns.
Обычный профиль прошёл дополнительные 100 тактов нагрузки на каждый audio IRQ;
200–300 тактов уже не проходят на тяжёлом примере. C по умолчанию
сохраняется, но не успевает на трёх измеренных потоках.
Поддержка относится к этой сборке и данным; физическая плата и
дополнительная нагрузка приложения не проверялись.
[Текущие параметры сборки, ограничения и измерения](research/q0-plan-2026-10-25/README.md).
**Уточнение по новой матрице:** 50 уникальных четырёхсекундных потоков
прошли обычную очередь 512 без underruns; средние интервалы decode достигают
95,39% бюджета. Восьмисекундный непрерывный повтор самого тяжёлого потока
проходит queue512/prefill384/unroll9, но даёт **431 underrun** с
queue256/prefill160/unroll3. Дополнительные 50 тактов на IRQ тоже приводят
к underruns на этом повторе. Поэтому прежний успех compact и запас IRQ
относятся к прежним проверенным данным; общей поддержки compact нет.
[Новые тайминги и границы вывода](research/q0-standards-2026-10-25/README.md#avr-весь-поток-с-активными-прерываниями).
Старые ПК-тесты и структурные счётчики сами по себе не измеряют такты.
Заглушки в `tests/avr_stub/` предназначены для
исторических проверок компиляции; прошивка должна использовать настоящие
заголовки Arduino/avr-libc.

## История и происхождение

[HISTORY.md](HISTORY.md) связывает отдельные коммиты импорта с этапами
разработки. Исходных Git-объектов в ZIP нет: это реконструкция истории
по сохранённым снимкам, без вымышленных авторов или дат коммитов.
Документы `NEXT_AGENT_RU.md` описывают планы на момент передачи.

[IMPORT_MANIFEST.json](IMPORT_MANIFEST.json) содержит SHA-256 архива,
597 сохранённых файлов и 31 исключённого файла с причинами.
Манифест описывает первоначальный импорт, доступный в соответствующих
коммитах. Актуальные tools/tests и ядро затем изменены; их нынешние
hashes нужно брать из новых отчётов или истории Git. `.gitattributes`
отключает преобразование концов строк.
Старый `00_READ_FIRST/SHA256SUMS.txt` относится ко всему внешнему
архиву, включая исключённые файлы. Дополнительные файлы интеграции
и продолжения разработки учитываются историей Git.

Приватные записи и производные из `07_PRIVATE_SPEECH_EXAMPLES/`, а также
LPC-трасса английского диалога остались во внешнем ZIP. Поэтому некоторые
пути в исходных исторических отчётах указывают на отсутствующие здесь
материалы. Сохранены оригинальные уведомления о происхождении и правах;
новая лицензия исходникам не назначалась.
