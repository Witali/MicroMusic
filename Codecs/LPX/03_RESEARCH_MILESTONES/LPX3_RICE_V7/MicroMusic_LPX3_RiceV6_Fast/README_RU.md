# MicroMusic LPX3 Rice v6 Fast — без потери качества

L3AV v6 для ATmega328P, 16 МГц, 8 кГц. Базовый формат: Rice v5, но перед блоком на 80 отсчётов вместо обязательного четырёхбитного индекса передаётся один бит `0`, если режим тот же. При новом режиме — `1` + четыре бита индекса.

Остальная часть потока, LPC-коэффициенты и последовательность квантованного возбуждения не меняются. Не добавляется словарь в SRAM; основная функция LPC `next()` в AVR-объектном коде совпадает по размеру с v5. Отличается только разбор служебного поля раз в 80 отсчётов.

## Проверенные размеры (байт данных, полный контейнер)

| Фраза | v5 | v6 Fast | v7 Compact |
|---|---:|---:|---:|
| «Чего тебе нужно?» | 5219 | 5211 | 5189 |
| «Что ж ты не отвечаешь?» | 4434 | 4429 | 4415 |
| «Сова! Открывай! Медведь пришёл!» | 8283 | 8208 | 8025 |

## Воспроизведение эксперимента

```sh
python3 tests/verify.py --fuzz 200
python3 tests/measure_avr.py  # нужен clang++ с AVR backend и llvm-objdump
```

Конвертация исходной записи L3AV v1: `python3 tools/rice_v6.py input_v1.l3av output.l3av`.
Создание заголовка для Arduino: `python3 tools/make_header.py output.l3av examples/LPX3_RICE_V6_PLAYER/voice_data.h`.

Открыть скетч в `examples/LPX3_RICE_V6_PLAYER/` или `LPX3_RICE_V6_PROFILE/`, выбрать Arduino Nano/Uno ATmega328P 16 МГц. Исходники профилировщика компилировались на уровне AVR-объекта с заглушками, но реальный ELF/HEX и гарантированную частоту без underrun **не проверяли**.

`reference_v5/` — предыдущая версия без изменения кода LPC для независимого сравнения. `reference_v1/` — исходный декодер L3AV v1, используется в регрессионных тестах. Исходные фразы из фильмов в пакет с публичным кодом не включены; приложение содержит только синтетический тест. Исходные данные/результаты сохранены в отдельном ПРИВАТНОМ исследовательском ZIP.

**Внимание**: скомпилированные объектные секции `.text` и `.progmem.data` не равны конечному Flash после линковки. Измерения тактов на физической ATmega328P не проведены; соответствие бюджету 2000 тактов/отсчёт пока не доказано.
