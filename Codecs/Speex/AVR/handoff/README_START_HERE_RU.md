# SPEEX AVR — ПОЛНАЯ ПЕРЕДАЧА ПРОЕКТА ДРУГОМУ АГЕНТУ

**Срез материалов:** 23 октября 2026 г.  
**Целевой MCU:** ATmega328P, 16 MHz, 32 KiB Flash, 2 KiB SRAM.  
**Исследуемый формат:** стандартный Speex Narrowband CBR mode 3: PCM 8 kHz, 160 отсчётов / 20 ms, 160 бит (20 байт) / кадр.  
**Статус:** экспериментальная реализация R4 проверялась на модели LLVM AVR и эталонных потоках; **новый порт оригинальной Xiph 1.2.1 ещё не является собранной/проверенной прошивкой**.

## Начните здесь

1. Прочтите `HANDOFF/01_CURRENT_STATUS_RU.md` и `HANDOFF/02_TIMELINE_AND_DECISIONS_RU.md`.
2. Основная НОВАЯ ветка: `UNPACKED/09_Xiph_Upstream_Port_WIP_ACTIVE/Speex_Upstream_AVR_Port_2026-10-23/`.
3. Старая R4 КОНТРОЛЬНАЯ: `UNPACKED/08_R4_Cache10Fused_REFERENCE/Speex_AVR_LSP_R4/`. **Не перезаписывайте / не исправляйте её в процессе адаптации Xiph.**
4. Если нужны прежние исходники, ассемблер, `.o`, оригинальные WAV, `.spx`, `.spxraw`, побитовые результаты или скрипты — все стадии в `UNPACKED/01_...09_...`.
5. `ORIGINAL_ZIPS/` — ВСЕ девять исторических архивов, сохранены побайтно, как они были до консолидации. Это страховочные первоисточники.
6. `LOOSE_FILE_SNAPSHOTS/` — доступные самостоятельные файлы из файлового пространства текущей беседы, включая промежуточные отчёты.
7. `HANDOFF/04_MEASUREMENTS_AND_WARNINGS_RU.md` объясняет, какие метрики относятся к LLVM-симуляции и какие не доказаны на настоящей ATmega328P.
8. `MANIFESTS/` хранит SHA-256 каждого файла, список стадий и сводку проверки целостности.

## Что не включено и почему

- **Архив исходников Xiph `speex-1.2.1.tar.gz` отсутствует** среди переданных материалов, а скачать его из контейнера не получилось (сеть недоступна). В активной upstream-ветке есть `tools/get_speex_source.py` и ссылка/ожидаемый SHA-256; см. README её каталога. Патчи включены полностью, но НЕ выдаются за полную исходную библиотеку Xiph.
- Полной пословной экспорта всей истории чата с системными метаданными нет: API экспорта диалога здесь недоступен. В `HANDOFF/02_TIMELINE_AND_DECISIONS_RU.md` записана подробная реконструкция запросов, результатов и решений по видимому контексту и сохранённым файлам. Это не verbatim-лог сообщений.
- Настоящие записи человеческой речи с Wikimedia Commons / Common Voice не были успешно загружены на этапе предыдущих тестов; ссылки и скрипт загрузки находятся в стадии 07 и R4. Основные лежащие в архивах речевые тесты — синтетические/технические.

## Проверка целостности

Все девять исторических ZIP проверены через `ZipFile.testzip()` до упаковки (CRC ошибок не обнаружено). Их SHA-256 — в `MANIFESTS/ORIGINAL_ARCHIVES_SHA256.txt`. Полный перечень файлов, включая SHA-256 распакованных данных, — в `MANIFESTS/FILES_SHA256.csv`.

## Лицензии

Алгоритмы и кодовые книги Speex лицензируются на BSD-подобных условиях; в архивах сохранены исходные лицензии. Прежде чем включать в свой репозиторий внешние аудиозаписи, соблюдайте лицензию каждой записи. См. `HANDOFF/05_PROVENANCE_AND_LICENSES_RU.md`.
