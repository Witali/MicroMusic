# ATtiny13A: четырёхголосный музыкальный плеер (GNU AVR assembler)

Проект исполняет упрощённую аранжировку **Lumière** на ATtiny13A (1 КБ Flash, 64 байта SRAM). Никаких внешних ЦАП и PCM-сэмплов: звук выходит аппаратным Fast PWM на **PB1/OC0B**, частота несущей и частота обновления звука — **37 500 Гц** при CPU **9 600 000 Гц**. На PB1 обязательно нужен выходной ФНЧ и усилитель для динамика.

## Что входит

- `synth.S` — исполняемый GNU AVR assembly, четыре программных канала: скрипичная мелодия, клавишный/пианино, гитара/бас, перкуссия (бас-барабан, малый барабан, хай-хэт). Комментарии описывают алгоритмы.
- `score.json` — исходная партитура; `generate.py` создаёт `score.inc`, `config.inc` и `score.meta.json` с упакованными событиями.
- `synth.hex` — готовый Intel HEX. `synth.bin` — те же 823 байта двоичного содержимого Flash.
- `build.py` — воспроизводимая сборка через GNU AVR tools (если установлены) или LLVM AVR assembler и проверенную ограниченную обработку релокаций для этого исходника.
- `verify.py` — исполняет машинные инструкции в модели AVR по тактам и проверяет PWM, музыкальный декодер, отсутствие пропусков Timer0 и лимит ISR.
- `player.html` — автономная веб-страница: внутри встроен **реальный HEX** и эмулятор исполняемых AVR-инструкций; открывается локально, доступ к интернету не нужен.
- `avr_core.js` — ядро того же эмулятора; `render_wav.js` генерирует демонстрационный WAV непосредственно из выполняемого HEX; `preview.wav` — 14 секунд его работы.
- `midi_to_score.py` — базовый импорт SMF MIDI форматов 0/1 в нашу упрощённую структуру; никаких сторонних Python-библиотек не требуется.

## Размер и проверка

Сборка по умолчанию: **823/1024 байт** (остаётся **201 байт**). Уникальные музыкальные события — 246 байт (всё остальное — код, таблицы и список секций).

Исходная партитура имеет 6 уникальных секций, которые перечислены в плейлисте из 15 элементов, без повторного хранения содержимого каждой секции. Формат события — 5 бит номера высоты ноты и 3 бита длительности; дополнительные команды меняют гармонию или секцию.

Для конфигурации по умолчанию проверено моделированием:

- 37 500 аппаратных переполнений Timer0 за секунду без пропусков;
- обычное воспроизведение 0,8 секунды (первые 30 000 прерываний);
- ускоренный стресс-тест 1500 событий, проходящий все 15 вхождений секций;
- максимальное время обработчика в стресс-тесте — **220 тактов** после входа в прерывание (плюс ~4 такта аппаратного входа), ниже лимита 256;
- поток PWM, порождённый независимыми JavaScript- и Python-интерпретаторами AVR, совпал на первых 12 000 отсчётах.

**Это проверка модели AVR, а не измерение на реальном ATtiny13A.** Реальное звучание зависит от питания, RC-генератора, фильтра и усилителя. Инструменты являются экономными имитациями тембров, а не полноценными сэмплами рояля/скрипки.

## Фьюзы и частота 9,6 МГц

Согласно [официальному даташиту Microchip DS40002307A](https://ww1.microchip.com/downloads/aemDocuments/documents/MCU08/ProductDocuments/DataSheets/ATtiny13A-Data-Sheet-DS40002307A.pdf): CKSEL=`10` выбирает внутренний RC 9,6 МГц; SUT=`10` (длинный старт), CKDIV8 должен быть **снят**. Нужен **LOW FUSE = `0x7A`**. High fuse оставляем без изменений. SPIEN и RESET не отключаем.

```bash
# Сначала прочитать текущие фьюзы:
avrdude -c usbasp -p t13 -U lfuse:r:-:h -U hfuse:r:-:h

# Записать ТОЛЬКО Low Fuse (CKDIV8 выключен):
avrdude -c usbasp -p t13 -U lfuse:w:0x7A:m

# Прошить полученный HEX:
avrdude -c usbasp -p t13 -U flash:w:synth.hex:i
```

`CLKPR` дополнительно программно переводится в режим `/1`, даже если микроконтроллер имеет заводской CKDIV8. При частоте 9,6 МГц соблюдайте условие **VCC ≥ 2,7 В**. Внутренний RC-генератор не идеален по точности — при необходимости подстройте `OSCCAL` после сравнения музыкального строя.

## Подключение звука

```text
ATtiny13A PB1 / OC0B (корпус DIP-8: вывод 6)
    |
   2.2 kΩ
    +------- 10 nF ------ GND
    |
   2.2 kΩ
    +------- 10 nF ------ GND
    |
   1 µF (разделительный конденсатор)
    |
    +------ ВЫСОКООМНЫЙ вход усилителя (желательно ≥20 kΩ)
                         |
                    динамик через усилитель
```

Это простой двухзвенный RC-фильтр ~7,2 кГц по отдельным звеньям; итоговая частота среза и подавление несущей зависят от нагрузки и взаимного влияния ступеней. **Не подключайте динамик напрямую к выводу микроконтроллера.** PB1 совмещён с MISO при ISP, поэтому вход аудиоусилителя не должен сильно нагружать его во время прошивки. Поставьте развязывающий конденсатор 0,1 мкФ между VCC и GND рядом с чипом.

## Пересборка

Нужны Python 3 и GNU AVR GCC/binutils либо Clang со встроенным AVR assembler + `llvm-objcopy` и `readelf`.

```bash
python3 build.py
python3 verify.py
```

GNU-инструменты при наличии используются автоматически. Пример изменения набора тембров:

```bash
python3 build.py --lead flute --keys organ --pluck bass --drums off
python3 verify.py
```

Доступные варианты: `--lead violin|flute`, `--keys piano|organ`, `--pluck guitar|bass`, `--drums off|hat|snare` (вариант `snare` включает распределение kick/snare/hat). Алгоритмы неиспользуемых вариантов условно исключаются ещё при ассемблировании. После таких экспериментов `python3 build.py` восстановит стандартную конфигурацию.

## Импорт MIDI

```bash
# Сохраните оригинальный score.json в резервную копию!
python3 midi_to_score.py my-song.mid -o score.json --bars 16
python3 build.py
python3 verify.py
```

`midi_to_score.py` умеет читать Standard MIDI 0/1, отслеживать note-on/note-off, выбирать ведущий трек, квантовать его до четверти доли и получать две басовые основы аккордов на такт из других треков. При необходимости используйте `--melody-track N`, `--bass-track N`, `--tempo N`, `--section-bars 4` и `--bars 8`. Одинаковые блоки мелодии и гармонии сохраняются только один раз.

**Ограничение:** произвольный MIDI не поместится в 1 КБ. Это упрощённая редукция одной мелодии + сопровождения, а не полная передача всей полифонии и всех GM-инструментов. При превышении количества нот/секций/байт сборка останавливается с сообщением об ошибке, не создавая некорректный HEX.

## Послушать

Откройте `player.html` в браузере и нажмите **«Слушать»**. Web Audio воспроизводит значения OCR0B, полученные **исполнением инструкций из встроенного Intel HEX** с учётом циклов, переполнений Timer0 и записи PWM. Готовый отфильтрованный 14-секундный образец доступен в `preview.wav`.

## Права на музыку

В исходном `score.json` указано, что композиция и транскрипция **не являются CC0**; лицензия CC0, упоминаемая там, относится только к записям отдельных инструментов. Не следует распространять аранжировку как свободное музыкальное произведение без проверки прав.
