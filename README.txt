MicroMusic

Музыкальная прошивка ATtiny13A и веб-плеер, исполняющий её AVR-код.
Онлайн: https://witali.github.io/MicroMusic/web-player/

СТЕРЕО (ОТДЕЛЬНАЯ ВЕТКА)
Люмьер · стерео: ATtiny13A/Music/variants/lumiere-stereo/
L = PB0/OC0A (вывод 5), R = PB1/OC0B (вывод 6). Скрипка левее,
гитара правее, пианино и ударные по центру. Flash 1022 Б, два PWM
по 37,5 кГц. Главная страница выводит две осциллограммы и два канала
звука. Полная музыка и сглаживание сохранены.
Сборка: python tools/build-stereo.py
Проверка всей композиции: node tools/audit-stereo.mjs

Локально: node web-player/scripts/serve.mjs 8134
Открыть: http://127.0.0.1:8134/web-player/?firmware=lumiere-stereo

ПРОШИВКА
Единый ритм и штрихи: ATtiny13A/Music/variants/rhythmic/
В папке находятся synth.S, score.json, synth.hex, eeprom.hex, автономный
player.html и звуковой пример preview.wav. Flash 1024 Б: код 710 Б,
таблицы 314 Б. SRAM: 5 Б состояния и максимум 5 Б стека.
Четыре голоса: скрипка, пианино, гитара и ударные; тембры по FluidR3.

Общая дробная фаза синхронизирует все партии по шестнадцатым, включая
восьмые и четверти. Повторные ноты получают новую атаку; явные лиги
сохраняют огибающую. Атака скрипки до полной громкости — около 54,6 мс.
Рассчитываются 18750 основных точек в секунду; между ними выводится
среднее. PWM 37500 Гц, ISR 19 тактов, расчёт микса до 232 активных тактов.

Все 12 старых образов с ошибочным отсчётом ритма удалены из каталога
и текущих файлов проекта, включая ZIP и дубли в HTML. Они доступны
в истории Git до коммита 2271291. Исходные документы импорта и C-прототип
2016 года сохранены. Измерения и лицензия FluidR3: ATtiny13A/Music/reference/fluidr3/.

EEPROM
Прошить отдельно synth.hex во Flash и eeprom.hex в EEPROM.
Фьюзы: Low 0x7A, High 0xFF; внутренний RC 9,6 МГц, CKDIV8 отключён.
В первых 48 Б EEPROM находятся шесть волн по 16 четырёхбитных отсчётов:
две для каждого тонального инструмента, по регистрам. По два отсчёта
в байте; последние 16 Б зарезервированы. При синтезе выбираются волна
и отсчёт по фазе, затем применяется огибающая. EEPROM только читается.
Партитура находится во Flash; огибающие и ударные вычисляются кодом.
Это приближение спектров на короткой таблице, а не проигрывание сэмплов SF2.
