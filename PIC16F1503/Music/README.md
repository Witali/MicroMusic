# MicroMusic — PIC16F1503, ассемблер

Это **настоящая музыкальная PIC16F1503-прошивка**, написанная непосредственно
для PIC16F1 Enhanced Mid-Range. Исходный ассемблер, 14-битные инструкции,
Intel HEX, таблицы, полностью автономный веб-эмулятор и WAV находятся в архиве.
Проект основан на `https://github.com/Witali/MicroMusic`, вариант
`ATtiny13A/Music/variants/rhythmic`, и на ранее подготовленном C-порте PIC.

**Статус:** синтезатор собирается собственным документированным Python-
ассемблером (строгий поднабор синтаксиса MPASM/gpasm), а машинный HEX успешно
выполняется в инструкционном эмуляторе PIC16F1503. **Реальная микросхема и
официальный компилятор Microchip pic-as в этой среде не проверены.**

## Как начать

1. Открыть `web/player.html` в браузере. Внутри находятся исходный PIC HEX и
   настоящий аудиопример, записанный выполнением машинного кода, не C/JS-моделью.
2. Основной исходник — `firmware/micromusic.asm`.
3. Для PICkit/MPLAB загрузить `firmware/micromusic_with_config.hex`. В файле
   содержатся программа и CONFIG1/CONFIG2. Для ручной настройки конфигурации
   отдельно доступны `micromusic.hex` и `micromusic_config.hex`.
4. Пример звука — `reference/preview_pic16_asm.wav` (14 секунд).

## Параметры PIC16F1503

| Свойство | Значение |
|---|---|
| Источник частоты | HFINTOSC 16 МГц; `OSCCON=0x7A` |
| PIC instruction rate | Fosc/4 = 4 MIPS |
| Timer2 | `PR2=63`, `T2CON=0x24`: прескейлер /1, постскейлер /5 |
| PWM3 carrier | 62 500 Гц, аппаратно |
| Частота обновления duty | 12 500 Гц, 320 циклов на отсчёт |
| Шкала duty | 8 бит: `PWM3DCH=v>>2`, `PWM3DCL=(v&3)<<6` |
| Вывод | RA2/PWM3, физический вывод 11 в 14-pin PDIP/SOIC |
| Питание | VDD — вывод 1, VSS — вывод 14 |
| RAM | 128 Б у чипа; состояние проекта в основном 0x20..0x61 + common 0x70..72 |
| Program Flash | 2 048 слов по 14 бит; адреса данных до 0x07D7 |
| Занятые словами команды/таблицы | 1 157/2 048, включая таблицу произведений |
| CONFIG1 | `0x3FC4` — INTOSC, WDT OFF, PWRT ON, CLKOUT OFF |
| CONFIG2 | `0x3FFF` — LVP включён, защита записи выключена |

**Отдельного ЦАП нет**: вывод PWM3 нуждается в аналоговом фильтре. Например,
два последовательных RC-звена 1 кОм + 10 нФ, затем разделительный
конденсатор в высокоомный вход усилителя. Не подключайте динамик напрямую
к RA2 — нужен усилитель.

## Архитектура звука

- 16-битные DDS аккумуляторы для скрипки, рояля и нейлоновой гитары.
- Общий `render_voice`: одна арифметика для всех инструментов.
- 16 отсчётов на волну, два 4-битных signed отсчёта упакованы в один байт.
- Скрипка: два спектральных регистра (низкий и высокий).
- Рояль и гитара: по две регистровые зоны × четыре спектральных состояния
  от яркой атаки к устойчивому звучанию. **Переходы между четырьмя
  состояниями ступенчатые**, а не аудиочастотный интерполятор.
- 256-словная таблица точных произведений `(wave * envelope)>>2` ускоряет
  получение огибающей без программного умножения. Акустические табличные
  данные из MicroMusic адаптированы для PIC.
- Каждый из трёх тональных голосов имеет собственный `note-off`, меняющий
  огибающую, но не фазу. Четвёртый голос — бас-барабан/малый/хай-хэт (шум
  вычисляется один раз на четыре PCM-отсчёта).
- Биполярные сигналы смешиваются относительно unsigned duty=128.
- 16-байтовая SRAM-очередь уменьшает задержки во время декодирования музыки.
- 216 музыкальных событий + 15 ссылок на повторяющиеся секции оригинального
  `Lumière` (80 BPM, 222 секунды); команды `E0..EF` задают аккорд,
  `F0..FE` — маски note-off, `FF` — следующая секция.

## Полностью воспроизводимая сборка

Требуется Python 3 (только стандартная библиотека):

```bash
python tools/build_firmware.py
```

Выполняются генерация таблиц из `source/music-assets.json`, сборка реальных
14-битных PIC-слов `tools/assemble_pic.py`, экспорт Intel HEX и конфигурации
PIC. `firmware/micromusic.lst` — машинный листинг с адресами и исходником.

Генератор использует **точные опкоды из таблицы 27-3** официального даташита
Microchip DS40001607D. Это самостоятельный, ограниченный поднабор
PIC-ассемблера, а не эмуляция машинного кода на C/JS. Синтаксис ориентирован
на MPASM/gpasm; **совместимость с официальным `pic-as` не проверена**.

Эмулятор покрывает используемые музыкальным HEX инструкции PIC, FSR-программное чтение,
прерывания, Timer2 и PWM3. В нём **не** моделируются реальные допуски RC
генератора, аналоговый фильтр, выходной драйвер, питание и все SFR.
Поэтому тест на физическом PIC16F1503 остаётся необходимым.

## Важные отличия от версии ATtiny13A

1. PIC16F1503 не имеет встроенной EEPROM: спектры и партитура помещены во Flash.
2. Звуковой ISR здесь только читает готовый отсчёт и задаёт обе части PWM3 duty.
3. Фильтрация несущей остаётся аналоговой; PWM несущая не понижается с частотой PCM.
4. PIC работает при 4 MIPS от 16 МГц, поэтому 12,5 кГц PCM выбран после
   тестирования. При 15,625 кГц на внутреннем генераторе были редкие underruns.
5. Два дополнительных «хвостовых» голоса из поздней AVR-версии **пока не
   перенесены**. Есть три тональных + один ударный канал.

## Расширенная сверка всех реализованных таймингов (21 октября 2026)

После первоначального аудита проведена дополнительная проверка **временной
модели поддерживаемых узлов** (107 тестов). По даташиту исправлены системные
часы после Reset (500 кГц → 16 МГц), переходная задержка HFINTOSC,
Timer0, Timer1, сравнение TMR2/PR2, время изменения PWM3 duty,
аппаратные фронты PWM3 (режим `capturePwmEdges`) и задержка конвейера при IRQ.
Временная шкала в пикосекундах доступна как `timePs`, секунды — `seconds`.

```bash
node --test tests/official_datasheet_audit.test.mjs tests/official_timing_v2.test.mjs tests/isa_timing_matrix.test.mjs
```

Подробные источники, тестовые случаи и оставшиеся ограничения перечислены
в [TIMING_AUDIT_DS40001607D_RU.md](TIMING_AUDIT_DS40001607D_RU.md).
**Это не полная модель всех периферийных блоков**: внешние T0CKI/T1CKI,
MPLAB SIM, аппаратный WDT, истинный аналоговый PWM и Q-фазы не эмулируются.

## Официальный аудит эмулятора (21 октября 2026)

Исправлены декодер MOVIW/MOVWI и его режимы, зеркалирование RAM, тайминги
доступов к Flash и PCL, побочные эффекты TMR2/T2CON, контекст прерываний
и декодирование зарезервированных кодов. Даны 23 регрессионных теста.
Прошивка и WAV остались побайтно неизменными. **Это всё ещё частичный PIC-
эмулятор**: точный pin-level PWM, режимы осциллятора и MPLAB SIM не проверены.
**Исторический протокол предыдущего аудита:** [AUDIT_MICROCHIP_RU.md](AUDIT_MICROCHIP_RU.md). Актуальная модель фронтов PWM и тактового генератора описана в новом отчёте выше.

## Документация и происхождение

Официальная документация: https://ww1.microchip.com/downloads/en/DeviceDoc/40001607D.pdf
- раздел 3.2.1.2 — чтение Flash через FSR (на один цикл дольше)
- раздел 4.2 — конфигурационные слова CONFIG1/CONFIG2
- раздел 7.5 — аппаратное сохранение контекста при прерываниях
- разделы 20 и 22 — Timer2 и PWM3
- таблица 27-3 — настоящие машинные команды и длительности.

Источник открытых спектральных таблиц: https://github.com/Witali/MicroMusic
Лицензионное уведомление исходного FluidR3 банка: `source/FluidR3-MIT.txt`.
HEX следует проверять на реальной микросхеме перед применением в изделии.
