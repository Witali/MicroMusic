# MicroMusic для PIC16F1503

- `Music/firmware/` — ассемблер музыкального синтезатора и таблицы.
- `Music/source/` — исходное описание музыкальных событий и тембров в JSON.
- `Music/web/pic16-core.mjs` — PIC-эмулятор.
- `Music/tools/`, `Music/tests/` — сборка и проверки.
- `validation/` — уникальные сценарии MPLAB, сравнения и контейнерного запуска; эти внешние симуляторы при импорте не запускались.
- `research/` — хронология C-порта, перехода на ассемблер, аудитов инструкций/таймеров/PWM и сверки SFR по исходникам gpsim. Исходники каждого этапа доступны в Git по указателю.

Сборка и проверки из `Music/`:

```text
python tools/build_firmware.py
python tests/test_firmware.py
node --test tests/*.test.mjs
```

Генерируемые HEX/BIN/листинги игнорируются Git. Плеер создаётся `tools/build_player.py` после генерации его PCM-предпросмотра; сам HTML с вложенным аудио не хранится. Сохранённые отчёты относятся к соответствующим версиям исходников, а не к аппаратным испытаниям.
