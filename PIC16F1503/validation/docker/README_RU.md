# PIC16F1503 — независимая сверка MPLAB X Simulator

## Статус 21 октября 2026

**Не выполнена в настоящем MPLAB SIM.** В рабочей среде ChatGPT отсутствует Docker,
внешние DNS-имена не разрешаются, прямое подключение к публичным IP по HTTPS
заблокировано. Сервис скачивания не смог получить MPLAB X 5.45,
а попытка создать отдельную ветку для CI в GitHub MicroMusic завершилась
`403 Resource not accessible by integration`.

Сценарий `run_mplab_docker.sh` предназначен для Linux-машины с Docker и интернетом.
Он скачивает сторонний контейнер с установленной официальной IDE MPLAB X 5.45
(запасной образ 5.40), запускает **настоящий MDB** и сохраняет его журнал.
Скрипт не запускался успешно в данной среде, поэтому его совместимость
с образами не подтверждена. Сторонние образы следует использовать в
изолированной среде, предварительно проверив их происхождение.

```bash
bash run_mplab_docker.sh
```

Сценарий выполняет MDB-команды из `mdb_check.txt` на одной и той же
прошивке `micromusic_with_config.hex` с SHA-256:

`7787e6dae4f115a36cf4f4a9054ed02c74411106efb02ba861195755854ae578`

Точки сверки: 1, 2, 3, 4, 5, 8, 12, 24, 50, 100, 256, 1024, 4096 инструкций,
регистры PCL, WREG, STATUS, BSR, FSR0L/H, OSCCON, PIR1, PIE1, INTCON,
TMR2, PR2, T2CON, PWM3DCH/DCL/CON и Stopwatch. Файл
`reference_our_emulator.json` — данные собственного JS-ядра, **не Microchip**.
Парсер `compare_logs.py` экспериментальный: если формат MDB отличается,
нужно анализировать `mdb_official_output.log` непосредственно.
