ЛОКАЛЬНЫЕ ИНСТРУМЕНТЫ MICROMUSIC — WINDOWS x64

Из корня репозитория:
  powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup.ps1
  . ./build/toolchains/env.ps1

Скрипт скачивает переносимые архивы с официальных серверов, проверяет SHA-256,
распаковывает их в build/toolchains и проверяет работу инструментов:
  Node.js 22.22.3 — сервер, Node-тесты и сборщик WASM;
  Python 3.13.3 — каталог, JSON/MIDI-конвертер, сборщики аранжировок;
  AVR GCC 7.3.0 / Atmel 3.6.1 Arduino7 — C-компилятор для AVR, GNU avr-as,
    линкер, objcopy, objdump и nm;
  Emscripten 6.0.12 — Clang, wasm-ld и готовый sysroot для C → WebAssembly.

Полный первый запуск скачивает около 800 МБ, из них около 701 МБ — Emscripten.
Повторный запуск использует установленный набор. Права администратора,
глобальная установка, изменение профиля и системного PATH не нужны.
env.ps1 добавляет инструменты в PATH только текущего PowerShell и задаёт EMSDK.
После запуска setup отдельным процессом dot-source env.ps1 в рабочем терминале.
Скрипт работает из любого каталога; все пути вычисляются от его расположения.
Версии, URL и SHA-256 зафиксированы в toolchains-windows-x64.json.

Проверки установки:
  tools/setup.ps1 -CheckOnly
Не скачивает и не распаковывает инструменты, но выполняет проверки в
build/toolchains/verification. Для установки из уже скачанного кэша:
  tools/setup.ps1 -Offline
Если нужного архива нет, Offline останавливается с явной ошибкой.

Проверка не ограничивается --version: компилирует маленький C-модуль в WASM
и исполняет его в Node. Затем независимо собирает все пять synth.S через
GNU AVR GCC/ассемблер и сравнивает байты с сохранёнными synth.bin.
Завершающий байт выравнивания GNU (.text заполняется нулём) приводится к FF
только за меткой конца исходника: это значение стёртой Flash в проекте.
Python дополнительно проверяет собственный AVR-ассемблер и весь каталог.
Прошивки в ATtiny13A/Music не перезаписываются.

После установки:
  node web-player/scripts/build-wasm.mjs
  node --test web-player/tests/*.test.mjs
  python tools/assemble-avr.py --verify
  python web-player/scripts/build_catalog.py --check
  node web-player/scripts/serve.mjs 8134
Откройте http://127.0.0.1:8134/web-player/

Готовый WASM включён в репозиторий: для обычного воспроизведения пересборка
не нужна. Обычная сборка прошивок использует сохранённые JSON и банк тембров,
для неё достаточно включённых Python/Node; npm/pip-пакеты не требуются.
Повторный анализ внешнего SoundFont — отдельная процедура с NumPy и источником
SF2; эти необязательные средства извлечения тембров не входят в данный набор.

Инструменты, кэш архивов и результаты проверки находятся в игнорируемом build/.
При обновлении версии меняйте manifest, соответствующие пути setup/verify
и повторяйте проверку компилятора и всех прошивок.
