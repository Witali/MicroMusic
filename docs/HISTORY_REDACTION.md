# Обезличивание неопубликованной истории, 2026-11-01

В `web-player/reports/bounded-profile-20261026/native-functions.json.gz`
заменены 196 префиксов домашнего каталога на `<user-home>` в поле `object`.
Это метаданные 203 функций WASM для повторного анализа профиля. Имена функций,
смещения и результаты измерений сохранены. В `evidence.json` обновлён SHA-256
сжатого архива; остальные исходники и артефакты не менялись.

Очистка затронула 73 неопубликованных коммита и изменила их идентификаторы.
Опубликованная история не переписывалась. Старые ID в отчётах оставлены как
идентификаторы первоначального происхождения; соответствие новым снимкам
хранится в [карте](../tools/history-redaction-20261101.json).

Перед повторением исторических проверок в новом полном клоне выполните:

```sh
node tools/setup-history-references.mjs
```

Скрипт работает локально, без загрузок. Он создаёт `refs/replace/` для полных
старых ID и лёгкие теги для использованных сокращений. Все ссылки ведут на
обезличенные коммиты; исходные приватные объекты для этого не требуются.
Существующие конфликтующие ссылки не перезаписываются. В клоне, где старые
объекты уже доступны, соответствующие ссылки не создаются. Повторный запуск
безопасен. Неполный клон нужно сначала дополнить историей ветки.

Короткая ссылка разрешается в новый ID, поэтому `git rev-parse` может вернуть
обезличенный ID. Содержимое исторического кода остаётся прежним. Для отключения
замен при инспекции Git используйте `git --no-replace-objects`.

Для проверки отдельного bare-клона доступен параметр `--repository <path>`.
Служебные ссылки, локальные резервные копии и исходные приватные объекты
публиковать не следует. При push этой ветки явно задавайте единственный ref:

```sh
git -c push.followTags=false push --no-follow-tags origin HEAD:refs/heads/codex/avr-to-wasm
```
