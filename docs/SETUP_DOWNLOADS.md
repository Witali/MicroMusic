# Реестр внешних загрузок

Каждый новый внешний файл регистрируется до использования: канонический URL,
версия/редакция, SHA-256, путь, назначение и лицензия либо ссылка на исходные
условия. Это относится и к документации, архивам, моделям симуляторов и внешним
зависимостям. Для файлов из архива указывается исходный пакет и путь внутри него.
При обновлении сохраняется отдельная запись версии и проверяется новый хеш.

| --- | --- | --- |

| Microchip ATtiny_DFP 3.4.278, даташит DS40002307A, справочник инструкций DS40002198A | [downloads.json](../tools/downloads.json): URL, версии, размеры, SHA-256, пути и назначение | [setup-downloads.ps1](../tools/setup-downloads.ps1) |
| Сохранённые определения ATtiny13A/ATtiny88 и лицензии, включая отдельно скачанный текст Apache-2.0 | [provenance.json](../web-player/vendor/microchip/ATtiny_DFP/3.4.278/provenance.json): исходный пакет, URL и хеши оригиналов | [описание происхождения и лицензий](../web-player/vendor/microchip/ATtiny_DFP/3.4.278/README.md) |

Из корня репозитория:

```powershell
# Получить недостающие файлы и проверить каждый по размеру и SHA-256.
powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup-downloads.ps1

# Проверить существующий кэш без сети и изменения файлов.
powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup-downloads.ps1 -Offline -CheckOnly

# Проверить или получить один документ.
powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup-downloads.ps1 -Id avr-instruction-manual
```

Скрипт не устанавливает и не исполняет скачанные файлы. Он хранит их в
игнорируемом `build/`, проверяет загрузку до переименования `.partial` и
останавливается при несовпадении существующего файла. Извлечение файлов из
архивов не выполняется этим скриптом. Для инструментов сборки остаётся отдельный
`tools/setup.ps1` со своим манифестом.

## Состояние регистрации

2026-10-26: пакет ATtiny_DFP найден в существующем кэше; оба PDF восстановлены
из прежнего локального кэша в указанные выше пути. Размеры и хеши проверены
по фактическим файлам и совпадают с ранее сохранёнными ссылками/хешами.
Дата первоначального скачивания PDF неизвестна. DLL извлечены из этого же
проверенного пакета для исследования; выполнен только статический просмотр
экспортов, сравнение симулятора с нашей моделью ещё не выполнено.

Это индекс проверенных источников текущей работы, а не утверждение о полном
аудите всех старых кэшей. Старые файлы без подтверждённого происхождения
должны получить такую пометку; источник и версию нельзя угадывать. Например,
прежний `attiny13.pdf` пока не включён в воспроизводимую установку, поскольку
его точный источник не проверен.

Веб-страницы, прочитанные без сохранения локального файла, приводятся как
ссылки в соответствующем отчёте. При сохранении копии нужно добавить запись
загрузки с хешем. Приватные ссылки, параметры авторизации и персональные пути
в реестр не записываются.

## Исследовательские загрузки официального симулятора

Зарегистрировано перед загрузкой и получено 2026-10-26: MPLAB X SDK **6.25** из
[официального архива SDK](https://ww1.microchip.com/downloads/mplab/x/sdk/archive.html),
канонический HTTPS URL:
`https://ww1.microchip.com/downloads/mplab/x/sdk/mplab-x-sdk-v6.25.zip`.
Назначение — проверить документированный MDBCore API и возможность локального
запуска ATtiny13A без полной установки IDE и без подключения оборудования.
Локальный путь: `build/reference-downloads/mplab-x-sdk-v6.25.zip`.
Фактический размер: 111 698 606 байт; вычисленный SHA-256:
`6f78c110804ff8e6ec53265ff79a508a907a74a31c37fdc3c5c7c9678bc3e2f6`.
Это хеш полученного через HTTPS файла, а не отдельно опубликованная контрольная
сумма производителя. Полная запись сохранена в `tools/downloads.json` под ID
`mplab-x-sdk`. Условия Microchip и сторонних компонентов должны быть сохранены
вместе с локальной распаковкой; архив и исполняемые библиотеки не добавляются
в Git. Наличие SDK пока не доказывает работоспособность автономного симулятора.

Проверка содержимого SDK: JAR и `.class` отсутствуют; руководство MDBCore требует
библиотеки установленного MPLAB X. В `build/mplab-sdk-6.25/` сохранены восемь
оригинальных документов/исходников вместе с лицензией, 351 830 байт;
исходные члены архива перечислены в `derivedAssets` реестра. Подробности,
официальная ссылка на ещё не скачанный IDE и следующий шаг:
[исследование симулятора ATtiny13A](../web-player/native/devices/attiny13a/simulator-oracle.md).

### MPLAB X IDE 6.35: подготовка хоста симулятора

Зарегистрировано до получения, 2026-10-26: официальный установщик Windows
MPLAB X IDE **6.35**, источник —
[страница Microchip](https://www.microchip.com/en-us/tools-resources/develop/mplab-x-ide).
Канонический URL:
`https://ww1.microchip.com/downloads/aemDocuments/documents/DEV/ProductDocuments/SoftwareTools/MPLABX-v6.35-windows-installer.exe`.
Локальный путь: `build/reference-downloads/MPLABX-v6.35-windows-installer.exe`.
Назначение — статически изучить поставку и возможность подготовки локального
хоста официального симулятора ATtiny13A; установщик не запускается, системная
установка, драйверы и физическое программирование не выполняются.
Опубликованный Microchip SHA-256:
`64a5247d5c1e2db7c6fb3b8d2fa43d5578d7efebe2e51db44706b20d441c2061`.
Результат попытки, 2026-10-26: обычный HTTPS GET вернул `Access Denied` со
ссылкой на страницу Microchip `/en-us/error/401.html`. Ни конечный `.exe`, ни
`.partial` не созданы; размер и фактический хеш неизвестны. Встроенный браузер
недоступен, текущий список браузерных подключений пуст; активной загрузки или
дескриптора ожидания нет. Метаданные этой несостоявшейся загрузки записаны в
`plannedAssets` манифеста, а не в список проверенных локальных `assets`.

Содержимое и формат установщика не исследованы. Установщик, драйверы, аппаратные
интерфейсы и непроверенные распаковщики не запускались. Условия лицензии
установщика и сторонних компонентов подлежат чтению после получения файла;
артефакт должен оставаться локальным и не добавляться в Git.

Официальная инструкция
[запуска нескольких экземпляров](https://developerhelp.microchip.com/xwiki/bin/view/software-tools/ides/x/configuration/multiple-instances/)
описывает `--userdir` для изоляции настроек **уже установленной** IDE. Это не
подтверждает переносимую поставку или отсутствие системных изменений при
установке. В изученных официальных инструкциях не найден проверенный способ
распаковки Windows 6.35 без запуска установщика; формат нельзя определять по
расширению `.exe`. Локально имеется `tar.exe`, `7z.exe` в PATH не найден.

Следующий ограниченный шаг: после восстановления обычной загрузки с сайта
Microchip получить этот файл в зарегистрированный путь, сверить опубликованный
SHA-256 и внести фактический размер в `assets`. Затем статически определить
формат и проверить документированную распаковку в отдельный каталог `build/`
с сохранением лицензий. Это условный путь исследования; готовый переносимый
хост симулятора пока не получен, запуск установщика не входит в эту проверку.
