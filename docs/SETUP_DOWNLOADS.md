# Реестр внешних загрузок

Каждый новый внешний файл регистрируется до использования: канонический URL,
версия/редакция, SHA-256, путь, назначение и лицензия либо ссылка на исходные
условия. Это относится и к документации, архивам, моделям симуляторов и внешним
зависимостям. Для файлов из архива указывается исходный пакет и путь внутри него.
При обновлении сохраняется отдельная запись версии и проверяется новый хеш.

| Что | Канонический реестр | Получение/проверка |
| --- | --- | --- |
| Node.js 22.22.3, Python 3.13.3, AVR GCC 7.3.0/Atmel 3.6.1 Arduino7, Emscripten 6.0.12 | [toolchains-windows-x64.json](../tools/toolchains-windows-x64.json): URL, версии, SHA-256 | [setup.ps1](../tools/setup.ps1); инструкция [SETUP_RU.txt](../tools/SETUP_RU.txt) |
| Microchip ATtiny_DFP 3.4.278, даташит DS40002307A, справочник инструкций DS40002198A | [downloads.json](../tools/downloads.json): URL, версии, размеры, SHA-256, пути и назначение | [setup-downloads.ps1](../tools/setup-downloads.ps1) |
| Сохранённые определения ATtiny13A/ATtiny88 и лицензии, включая отдельно скачанный текст Apache-2.0 | [provenance.json](../web-player/vendor/microchip/ATtiny_DFP/3.4.278/provenance.json): исходный пакет, URL и хеши оригиналов | [описание происхождения и лицензий](../web-player/vendor/microchip/ATtiny_DFP/3.4.278/README.md) |
| 30 DLL официального симулятора Windows, 38 249 813 байт | `derivedAssets` в [downloads.json](../tools/downloads.json), исходный пакет ATtiny_DFP 3.4.278, члены `simulator/win32/*.dll` | Локальная распаковка в `build/microchip-simulator/win32/`; это содержимое пакета, отдельной загрузки DLL нет |

Из корня репозитория:

```powershell
# Получить недостающие файлы и проверить каждый по размеру и SHA-256.
powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup-downloads.ps1

# Проверить существующий кэш без сети и изменения файлов.
powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup-downloads.ps1 -Offline -CheckOnly

# Проверить или получить один документ.
powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup-downloads.ps1 -Id avr-instruction-manual
```

Скрипт не устанавливает и не исполняет скачанные файлы. Он хранит их в
игнорируемом `build/`, проверяет загрузку до переименования `.partial` и
останавливается при несовпадении существующего файла. Извлечение файлов из
архивов не выполняется этим скриптом. Для инструментов сборки остаётся отдельный
`tools/setup.ps1` со своим манифестом.

## Состояние регистрации

2026-10-26: пакет ATtiny_DFP найден в существующем кэше; оба PDF восстановлены
из прежнего локального кэша в указанные выше пути. Размеры и хеши проверены
по фактическим файлам и совпадают с ранее сохранёнными ссылками/хешами.
Дата первоначального скачивания PDF неизвестна. DLL извлечены из этого же
проверенного пакета для исследования; выполнен только статический просмотр
экспортов, сравнение симулятора с нашей моделью ещё не выполнено.

Это индекс проверенных источников текущей работы, а не утверждение о полном
аудите всех старых кэшей. Старые файлы без подтверждённого происхождения
должны получить такую пометку; источник и версию нельзя угадывать. Например,
прежний `attiny13.pdf` пока не включён в воспроизводимую установку, поскольку
его точный источник не проверен.

Веб-страницы, прочитанные без сохранения локального файла, приводятся как
ссылки в соответствующем отчёте. При сохранении копии нужно добавить запись
загрузки с хешем. Приватные ссылки, параметры авторизации и персональные пути
в реестр не записываются.

формат и проверить документированную распаковку в отдельный каталог `build/`
с сохранением лицензий. Это условный путь исследования; готовый переносимый
хост симулятора пока не получен, запуск установщика не входит в эту проверку.
