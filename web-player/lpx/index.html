Усиление всей записи

Один коэффициент для всего файла сохраняется в LPX и применяется при воспроизведении. Пики ограничивают достижимую громкость.

Адаптивное уточнение качества работает в обоих режимах. Авто выбирает SIMD при поддержке браузером.

Энкодер сравнивает варианты тона, усиления и спектра, проверяет весь декодированный звук и сохраняет допустимый исходный вариант. В режимах P4/P6 допуск разрешает увеличить размер относительно базового результата; профили 3/8 используют указанный предел полного файла. При 12 и 16 кГц может сохраниться больше верхних частот, обычно ценой размера.

Выберите аудиофайл для конвертации.

Вся запись сохраняется одним непрерывным файлом. Для длинного аудио используется LPX V9 Long — расширение для веб-плеера и ПК. LPX — речевой кодек с потерями; стерео сводится в моно, по умолчанию громкость сохраняется. Нормализация измеряет громкость готового LPX и сохраняет общий коэффициент для воспроизведения. Предел пика — −1 дБFS по отсчётам. Для таких файлов требуется обновлённый LPX-декодер.
