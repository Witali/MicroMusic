ПЛАН УЛУЧШЕНИЯ MICROMUSIC WEB PLAYER

В текущей работе:
[x] Общий плеер в стиле Z80 Lab: каталог, управление, осциллограмма, состояние AVR.
[x] Все уникальные Flash + EEPROM из HEX, BIN, HTML и шести релизов.
[x] Оптимизация AVR: предварительное декодирование, числовой диспетчер,
    фиксированная память, отсутствие очереди и выделений памяти на каждый PWM.
[x] Пропуск только пустого RJMP-цикла с сохранением границ AVR-инструкций.
[x] Побайтовое сравнение PWM и состояния с исходными HTML-эмуляторами.
[x] Измерение ускорения для каждой прошивки, отчёт о времени и условиях.
[x] Вынесение эмуляции в Worker и вывод через AudioWorklet.
[x] Проверка браузерного воспроизведения, паузы, сброса и выбора версии.
[x] Контроль темпа по звуковым часам и реальному времени: расчёт всех
    версий и длительный браузерный прогон финальной без накопления отставания.
[x] Отдельная скрипичная версия: измерение спектра и огибающих нашего
    FluidR3 GM, подбор двух 16-точечных 4-битных волн без увеличения памяти.
[x] Связные ноты без обнуления громкости и фазы, плавный тихий хвост
    после note-off; регрессии для атаки, спада и переходов между нотами.
[x] Все используемые инструменты по FluidR3: 80 тональных нот,
    сравнение пяти струнных пресетов, три ударных, более мягкие спектры.
[x] Три скорости затухания пианино и гитары, разное отпускание,
    согласование фаз атаки/удержания; нерезонансный выходной фильтр.
[x] Синтез в основном цикле; ISR только OUT/SET/RETI, 12 тактов.
[x] Атомарная публикация готового отсчёта, проверка потерь TOV0 и T,
    сохранения флагов, SRAM-стека и совпадения отсчётов с версией 08.
[x] Длинный 16-битный шум вместо 8-битной петли; фильтрация хэта
    по FluidR3, сохранение басового удара и тональных партий.
[x] Плавный PWM 37,5 кГц: опорные точки и средние, подготовка пары в
    основном цикле, ISR 19 тактов с сохранением арифметических флагов.
[x] Сжатие прошивки до 1010 Б: 690 Б кода и 320 Б музыкальных таблиц;
    расчёт микса до 232 активных тактов, проверка всех уровней и волн.
[x] Аудит всей партитуры и огибающих: 522 команды, 16224 тика без пропусков;
    отделены ошибки музыкальной сетки от реального отставания аудиопотока.
[x] Исправить накопительное округление длительностей и свободный счётчик
    ударных: единая дробная музыкальная фаза для всех партий.
[x] Различить связные ноты и повторный штрих, подобрать атаку коротких нот.

Первоначальная проверка: все семь версий прошли расчёт 60 секунд при точных 9,6 МГц
без потерь IRQ. В браузере все семь версий запущены; длительный прогон
финальной версии — 49,4 с, темп 100%, отставание 0 мс, потери IRQ 0.
Звуковые часы: 49365,333 мс; реальные: 49359,300 мс (джиттер доставки UI
около 6 мс). Подробности: reports/verification.json.

Проверка скрипки FluidR3: 38 тестов пройдены, все восемь образов
рассчитаны на 60 секунд без потерь IRQ. В браузере новая версия
проиграна 61,1 с: темп 100%, накопленное отставание 0 мс, IRQ без потерь.
Звуковые часы 61098,667 мс, реальные 61099,500 мс (разница 0,833 мс).

Новая архитектура: 51 тест, все десять образов рассчитаны на 60 секунд.
