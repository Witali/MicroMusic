# Masked INT0 flag after Power-down

The full ATtiny13A model now preserves the flag required by Microchip
[DS40002307A section10.2.5](https://ww1.microchip.com/downloads/en/DeviceDoc/ATtiny13A-Data-Sheet-DS40002307A.pdf#page=60)
when a high, masked edge-sense INT0 input resumes from Power-down clamping.
Frozen high PINB/history previously hid the clamp transition. This affects
any-change, falling-edge and rising-edge sense, including GPIO output PB1.

An explicit pending restoration event is independent of sampled PINB history.
It prevents settled GPIO skipping and publishes once on the first actual
resumed clkI/O rise. Held clocks retain it. Reset discards it; low-level sense
keeps INTF0 clear. Published flags retain GIFR W1C/acknowledgment behavior, and
GIMSK/SREG continue to control CPU requests independently.

The datasheet establishes the post-resumption flag but not its internal
sub-cycle publication phase. The first-rise choice is an explicit digital
fixture policy. Exact clamp/flag/ADC-trigger silicon phase, physical accuracy
and the official simulator oracle remain open. No external software was
downloaded for this correction; it uses the already registered manufacturer
datasheet/device pack and pinned compiler. The
[cookbook](../../docs/avr-asm-cookbook/int0-sleep-restoration.md) records the scope.

## Validation

All **156 focused checks and 2785/2785 default tests pass**, including **32 new tests**: 14 standalone GPIO
cases and 18 complete firmware cases. The same final firmware source passes
4/18 against baseline `62103e92` and 18/18 against the correction. It reads GIFR
in the first instruction after SLEEP and checks retained PINB, empty IRQ stack,
CPU progress and absence of device faults. Coverage includes:

- All three edge senses with INT0 masked and PB1 driven high.
- Internal and external clocks, verification and optimized resumable execution.
- WDT wake and PCINT wake with SREG.I clear, without interrupt vector entry.
- Idle/ADC Noise controls, low levels, DIDR and enabled wake buffers.
- External versus GPIO-driven high inputs, held-clock publication, W1C before
  and after publication, reset and a trillion-half-cycle settled span.
- Seeded bounded advancement compared with every individual GPIO clock edge.

The [before/after record](int0-resume-20261101.json) pins source/compiler inputs,
both native artifacts and test outputs. The separate
[timing replay](int0-resume-timing-20261101.json) compares **44 scenarios / 18066
events** with maximum software error **1 ps**, below the verification-only
10 ns tolerance. Those analytical software fixtures do not measure silicon or
establish the new internal flag publication phase.

Native size changes from 124738 to **124789 bytes** (+51). Four of 218 function
bodies change; exports, zero imports, fixed two-page memory, 8192-byte stack and
the resumable ABI are unchanged. Only `system_gpio.c` and `system_gpio.h` change
among native inputs. The pending byte fits existing structure padding; no ABI
address changes. Legacy `avr.wasm` is byte-identical. An independent native
rebuild is also byte-identical. There is no measured performance claim.
