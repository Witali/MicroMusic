# Settled GPIO dispatch: less repeated work, elapsed gains unproven

Commit `df1c264e` retains a private board certificate for the original complete
GPIO settled predicate. It suppresses repeated internal-clock GPIO advances and
deadline queries until a dependency writer invalidates it. In physical HQ4,
source-entry traces fall from 2,248,976 to 84,075 advances and from 3,858,761 to
177,849 settled checks. CLKI retains its original edge processing. All 1,722
regression checks pass, including 18 new full-private-state differential cases.

The final six-row timing matrix has medians 0.992–1.069x with large control
variation. This change is retained for proven removal of redundant work; these
measurements do **not** establish a sustained elapsed-time gain or exclude small
losses. The default engine stays `wasm`, and no browser real-time gate closes.

## Implementation and correctness boundary

Baseline is `61bafe9f`, native 118,742 bytes, SHA
`33cbb4e4b7b6727f510793e1149099a48c77692bc013755ae739edc4b650c02a`.
The final runtime is 118,946 bytes (+204), SHA
`1fe4bef5bdc458bb8ca2a65636221e4b5ed87a4d5003eca6b60532c4baf45b9f`.
Clang 24 / Binaryen 133, SDK 6.0.12, compiler flags, 109 function exports,
no host imports and fixed two-page memory / 8192-byte stack remain unchanged.
Generated firmware WASM bytes and CPU ABI remain identical in the parity matrix.

Only device.c and the ATtiny13A board integration include change among compiled
inputs. The low-level GPIO implementation, struct and API remain unchanged.
A private byte occupies existing board padding after VCC. Link maps retain
the board at 0xfa10 with size 45,800 bytes. The complete source/ownership audit
is [gpio-activity-audit.md](../native/gpio-activity-audit.md).

Certification reuses the existing raw GPIO deadline answer. Infinite certifies
settled state only with an internal source, clkI/O running and half != UINT64_MAX;
stopped clocks and exhausted timestamps can also return infinite without
settling. True then skips recurring dispatch; false means unknown. A skipped
span preserves final clock_high, including zero-length and gated-clock behavior.
Reverse time still takes the original error path. Reset, domain changes,
accepted GPIO-register writes, Timer0 override changes and internal-source
external-input delivery clear the certificate. GIFR-only IRQ acknowledgement
does not affect the predicate. An observer/connection mask never authorizes a
skip. CLKI always uses the original path, preserving PB3 source/GPIO/ADC3 capture.

No other controller, time conversion, existing same-state deadline invalidation
or full public I/O shadow restoration is skipped. All original entry/exit,
partial-instruction, fault and reset boundaries remain. No new JavaScript calls
are introduced. Exact rebuilt static comparison finds 195 identical bodies,
eight changed, none added/removed; the changed bodies are the scanner, GPIO
service and inlined invalidation owners.

## Source-entry evidence, separate from speed measurements

Seven instrumented pairs compare the enabled policy with
`DEVICE_GPIO_IDLE_CACHE=0` in copied diagnostic builds. Each pair matches its
uninstrumented production reference in public/diagnostic state, memories, IRQ,
PCM and retained pin hashes. Instrumentation times are never speed evidence.

| Physical firmware | Advances, original → cached | Settled checks, original → cached | GPIO deadline queries, original → cached |
| --- | ---: | ---: | ---: |
| Rhythmic | 2,135,496 → 85,336 | 3,778,752 → 179,897 | 2,219,957 → 104,913 |
| Lumière | 2,142,132 → 105,843 | 3,810,891 → 223,204 | 2,235,973 → 132,364 |
| HQ4 | 2,248,976 → 84,075 | 3,858,761 → 177,849 | 2,285,259 → 102,895 |

For CLKI /1, /256, ADC enabled-idle and ADC converting, all source-entry counts
remain equal between policies. These fixtures differ from the timing driver's
queued-input conventions; do not attribute its elapsed differences directly to
these counts. Board service and other peripherals still run at their original
boundaries; their remaining cost needs a fresh profile.

## Uninstrumented measurements and limits

Node 22.22.3 / V8 12.4, Windows, Ryzen 5 5600X. Four-label Williams scheduling,
eight measured trials and four full-workload warmups per label per row. Identical
modules within oldA/oldB and newA/newB provide controls. Construction, snapshots
and diagnostics are outside capture timers. No test/build/profile workload runs
alongside the timings. Host load, CPU frequency, GC and JIT tiers are uncontrolled.
Ratios above one indicate less capture time in the candidate.

| Final v2 physical workload | Cross-version median | Faster pairs | Old identity median | New identity median |
| --- | ---: | ---: | ---: | ---: |
| Rhythmic | 1.047x | 5/8 | 0.948x | 0.997x |
| HQ4 | 0.992x | 3/8 | 1.019x | 0.963x |
| CLKI 20 MHz /1 kernel | 0.996x | 4/8 | 0.976x | 1.004x |
| Internal 20 MHz /1 kernel | 1.029x | 6/8 | 1.052x | 0.994x |
| Internal kernel, active ADC | 1.065x | 7/8 | 0.981x | 1.003x |
| Internal kernel, active watchdog ISR | 1.069x | 5/8 | 0.942x | 0.901x |

Music uses 48,000 frames and kernels 4,800 at 48 kHz: 192 timed runs,
96 warmups, 5,472 snapshots and 5,358 comparisons. The separate 15-case parity
matrix adds 30 executions, 176 snapshots and 88 comparisons: 5,648 snapshots /
5,446 comparisons overall. Each observation matches exact PCM, complete public
and diagnostic state, data/Flash/EEPROM/IRQ and retained pins, with actual divisor,
ADC and ISR activation assertions. Audio consumption can drain pin history; these
hashes are not an independent capture of every physical edge or silicon data.

Control movement and pair spread remain material. For example, rhythmic ranges
0.933–1.191x; HQ4 0.676–1.096x. Even the ADC's 7/8 faster pairs do not establish
portable gains, especially without a second v2 timing interval. Watchdog's
identity controls shift substantially. Do not extrapolate speed to browsers or
other firmware, or declare the earlier synthetic idle-ADC penalty resolved.

## Superseded first variant

`v1/` is an immutable archive of a different 119,052-byte candidate, SHA
`792a4b6d66dd3458c35d0fde452e1ef2fc426ee71aa607ed77e9e4b33fd5670a`.
It recomputed the full predicate after each uncached advance, adding work during
pipeline activity. Two matrices contain 384 timings / 192 warmups. Rhythmic
measured 1.045x then 1.072x; HQ4 0.999x then 0.930x. The latter row prompted the
refinement, but host/control variation prevents attributing all of that loss to
the extra predicate. The archive preserves 16 board cases, 17 low-level GPIO
cases, 15 parity cases and exact source/static/native identities. It has no
complete-suite result. Never pool its timings with v2 or label them as v2.

## Verification and replay

All 1,722 default/shared music-tool checks pass, zero skips (118.49s). The 18 new
board cases compare every private controller, queue, phase, timestamp and memory,
excluding only the new certificate byte; each true certificate is independently
checked against the full original predicate. Coverage includes PINB input timing
before/at/after falling edges, all dependency owners, sleep/PRR, IRQ, reset/POR,
zero/reversed spans, clock changes, sentinel guards and seeded mutations.

An isolated reconstruction byte-matches the final runtime and passes all 18
board cases plus the 15-case generated-CPU parity matrix. The archive contains
both variants, native manifests, source snapshots, static maps/inventories,
timings, paired traces and test output. The verifier checks LF-normalized text /
raw binary hashes, input ownership, ABI, observations and recomputed statistics.
Optional rebuilding uses a fresh ignored directory and preserves production.

```sh
node web-player/reports/gpio-idle-20261025/replay.mjs
node web-player/reports/gpio-idle-20261025/replay.mjs --rebuild
node web-player/reports/gpio-idle-20261025/replay.mjs --rebuild --variant v1

node --test web-player/tests/*.test.mjs tools/avr-music-target-core.test.mjs tools/music-startup.test.mjs
```
