# Сверка AVR-эмулятора и HQ4, 22 октября 2026

Общий JS/WASM-движок исполняет сохранённые HQ4-прошивки с теми же PCM и
моментами записи OCR0B, что симулятор из исходного чата. Для HQ4 добавлены
недостающие команды. Проверка по документации также выявила и исправила
обработку старших байтов указателей при косвенном доступе к data space.

## Официальные документы

Оба PDF заново скачаны с сайта Microchip; их SHA-256 совпали с ранее
зафиксированными в [таблице инструкций](attiny13a-instructions.json).

| Документ | Использованные разделы | SHA-256 |
| --- | --- | --- |
| [ATtiny13A Data Sheet, DS40002307A](https://ww1.microchip.com/downloads/en/DeviceDoc/ATtiny13A-Data-Sheet-DS40002307A.pdf) | 4: CPU/SREG/стек/IRQ; 5: память; 11–12: Timer0; 21: сводная таблица команд | `7c363e5deb94b5527a3ebfe9ac98338ce38e7d4499fe481100b7ede44bf37445` |
| [AVR Instruction Set Manual, DS40002198A](https://ww1.microchip.com/downloads/en/DeviceDoc/AVR-Instruction-Set-Manual-DS40002198A.pdf) | 5: кодировки, формулы флагов и такты; 6.2.2: ATtiny13A относится к AVRe | `d8e75ad7cc92de2b86c718495ed9392096e0192a08269a4dba8da16075be1e00` |

Для длительности использована колонка **AVRe**. В таблице учтены псевдонимы
и разные формы адресации: 123 строки не равны 123 уникальным кодировкам.

## Изменения общего движка

- Добавлены CP и NEG с флагами H/S/V/N/Z/C и одним тактом.
- Реализованы LD/ST через X/Y/Z без изменения указателя, с постинкрементом
  и преддекрементом, LDD/STD через Y/Z со смещением 0–63. Для ATtiny13A
  это два такта; определённые руководством неопределённые сочетания
  операнда с изменяемым указателем отклоняются явно.
- Исправлены и обычный, и ускоренный исполнители: при data space менее
  256 байт XH/YH/ZH не входят в адрес LD/ST и не меняются при изменении
  указателя (§§5.66–68, 5.114–116). Раньше использовался 16-битный адрес.
  LPM продолжает использовать обе половины Z для чтения 1 КБ Flash.
- Косвенное чтение I/O перенесено на завершающий такт инструкции;
  TCNT0 и побочные эффекты записи используют общий периферийный путь.
- Пересобран C/WASM, обновлены хеши сборки и база тестовых оптимизаций.

Покрытие выросло с **85 до 105 из 123 строк**. Не реализованы 18 форм:
ADIW, SBC, SBCI, SBIW, IJMP, ICALL, CPSE, CPC, SBIC, SBIS, CBI, BST, BLD,
LPM без операндов, SPM, SLEEP, WDR, BREAK. Они завершаются явной ошибкой.

## Сравнение с симулятором из чата

Четыре сохранённых копии `avr_emulator.js` — HQ4 release, MulQ4, C-кодировщик
и альтернативный HQ4 fit — побайтно одинаковы. SHA-256:
`dae6393748cc70178a6a6924a2c73f79b6ed67b7517c688ec3657fa9a87a3ffe`.
Более нового ядра в этих пакетах нет. HTML из полного handoff соответствует
поздним balanced/max-STOI образам; отдельный `MicroMusic_HQ4_Full_Private.zip`
содержит более ранний плеер, хотя эталонные WAV в нём те же.

| Образ | Flash | Отсчёты | Несовпадения PCM | Разница времени каждой записи | Пропуски Timer0 |
| --- | ---: | ---: | ---: | ---: | ---: |
| chego | 959 Б | 9 216 | 0 | 0 тактов | 0 |
| otvechaesh | 885 Б | 7 936 | 0 | 0 тактов | 0 |
| vinni | 1 024 Б | 22 272 | 0 | 0 тактов | 0 |
| chego_stoi_max | 957 Б | 9 216 | 0 | 0 тактов | 0 |

Всего 48 640 отсчётов. JS и WASM совпадают также по памяти и состоянию CPU
после каждого отсчёта; отдельно проверен WASM с отключённым ускорением.
ISR: максимум 28 тактов, по пять IRQ на отсчёт; межотсчётный интервал
1279–1281 такт при номинале 1280. Фиксированный ресэмплинг использует
7 500 записей/с; несущая аппаратного PWM — 37 500 Гц.

Совпадение речи не делает архивный симулятор эталоном правильности CPU.
Независимые граничные случаи подтверждают в нём прежние ошибки: ADC
неправильно сохраняет старый Z, NEG не обновляет H, LD -X учитывает XH.
Наш движок проходит эти проверки по официальным формулам.

Подробные значения, хеши исполняемых ядер и машинный отчёт:
[hq4-emulator-comparison.json](../../ATtiny13A/Sound/research/hq4-emulator-comparison.json).

## Проверки и воспроизведение

`avr-speech-instructions.test.mjs` проверяет оба движка: все пары байтов CP,
все значения NEG при всех начальных SREG, адресацию X/Y/Z, все 64 смещения,
неопределённые алиасы, I/O и все 256 значений неиспользуемого старшего байта.
`avr-coverage.test.mjs` сверяет все 65 536 первых кодовых слов с документированными
масками и проверяет время/сохранение флагов каждой строки таблицы.
Общие тесты дополнительно проверяют арифметику, ветвления, пропуски,
стек/IRQ, Timer0, EEPROM, ускорение и музыкальные прошивки.

Полная регрессия окончательного ядра: **402 теста прошли, 0 ошибок,
0 пропущенных**, Node.js v22.22.3. В браузере проверено воспроизведение
HQ4 на JS и WASM через существующие Worker/AudioWorklet. Сводка запуска,
SHA официальных PDF, исходников и тестов: [машинный отчёт](hq4-audit-2026-10-22.json).

Без звукового архива сравнение можно повторить из сохранённого ассемблера:

```text
python tools/verify-frozen-speech.py --avr-bin build/toolchains/avr-7.3.0/bin
node tools/compare-hq4-emulators.mjs --report build/hq4-comparison.json
```

Для прослушивания и сравнения с оригиналом:

```text
python tools/prepare-hq4-preview.py --archive "<Downloads>/MicroMusic_COMPLETE_RESEARCH_HANDOFF_2026-10-22(2).zip"
node web-player/scripts/serve.mjs 8145
```

Открыть `http://127.0.0.1:8145/web-player/?collection=hq4`. Это существующий
Worker/AudioWorklet-плеер с общими JS/WASM-ядрами. По ссылке «Плеер из ChatGPT»
доступен сохранённый автономный плеер. WAV, HEX, бинарники и HTML с вложенным
аудио восстанавливаются в игнорируемый `build/hq4-preview`.

## Границы вывода

Это проверка реализованного подмножества CPU и потока записей OCR0B.
Она не подтверждает полную модель микроконтроллера: физические фронты PB1,
двойная буферизация OCR/PWM, аналоговая RC-цепь, compare IRQ, неподдерживаемые
режимы таймера, watchdog/ADC/sleep, fuse/reset и разброс генератора сюда
не входят. Доступ к отсутствующей памяти диагностируется ошибкой; начальное
состояние SRAM детерминировано моделью. Физический ATtiny13A в этой проверке
не использовался. Подробный перечень ограничений: [общий аудит](attiny13a-audit.txt).
