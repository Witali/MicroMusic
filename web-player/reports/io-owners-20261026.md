# Single-source ATtiny13A I/O ownership

Implemented at `7adcc851034687c2d5ddf890fee1c48ba00a4f98`; baseline
`f06276292b58d049ce5de8b6d6b923090c6f956a`.
This is the first source-level step in the requested
[model simplification plan](../native/MODEL_SIMPLIFICATION.md).

The device-owned `native/devices/attiny13a/io_registers.inc` catalog records
35 distinct I/O byte addresses, using the generated names from official
Microchip ATtiny_DFP 3.4.278. ADC/ADCW/ADCL and EEAR/EEARL aliases share a single
byte owner. These are project storage/bus owners, not a claim that each register
has only one hardware consumer: MCUCR and ADCSRB, for example, also feed other
controllers.

The same catalog now supplies the 31 controller-to-public-memory stores and the
eight-register Timer0 routing predicate. A build-time generator emits a direct
C predicate, with the original comparison order; the compiler unrolls publication
at preprocessing time. There is no runtime table, lookup loop, indirect dispatch,
allocation or additional state. SPL, SREG, OSCCAL and DWDR retain their separate
handling. PRR stays board-owned because its write affects clock domains.

Register read/write side effects, masked-write rules, controller advances,
deadline invalidation, reset, IRQ, pin traces and publication boundaries remain
in their existing implementations. The catalog does not replace those behaviors.
Manufacturer inputs are unchanged; project ownership bindings remain separate.
The build checks generated bindings and pins them, the generator and the
manufacturer JS/JSON views in its source manifest.

## Verification

Rebuilding the native runtime gives **identical bytes** to baseline:

- 118,969 bytes; SHA-256
  `9f1eefa094f9003419251408953309e3b3c4050fc217234b9b95ed0275d87778`.
- No host imports, two fixed memory pages, 109 function exports plus memory.
- CPU generation, native ABI, memory and compiled execution are unchanged.

The 15 focused publication/ownership checks pass. Four new tests cover:

1. Reproducible generated routing against the manufacturer register map.
2. All 64 I/O slots against independent owner expectations, including all vendor
   aliases, 31 published bytes, four local bytes and reserved-address exclusions.
3. Exactly eight Timer0 routes, with board-owned PRR excluded.
4. The real publisher versus the pinned original C publisher for 256 arbitrary
   controller-state samples, comparing all 160 public data-space bytes. Those
   synthetic samples exercise publication only; they are not clocked as valid
   hardware configurations.

All **1892 default/shared-tool tests passed**, zero skipped, in 96.71 seconds.
An isolated reconstruction from the pinned Git inputs rebuilds the same native
bytes and reruns all four ownership cases successfully. Its output does not
replace production files.

No speed measurement was needed to establish executable byte identity. There is
no new speedup, real-time audio, hardware measurement or full-support claim.
The main checklist remains **21/30**, nine open. The next simplification should
audit shared bus-boundary rules and register side effects before consolidating
controller activation or changing event scheduling.
