Проверка потокового аудиоввода

Только короткие синтетические файлы до 1 МБ и 10 секунд. Сравнение двух способов декодирования без подгонки усиления или задержки: Web Audio в частоте исходника и AudioDecoder. Затем к обоим применяется один C++ FIR; пересчёт частоты проверяется отдельно.
