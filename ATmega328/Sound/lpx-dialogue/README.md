# Нормализованный LPX-диалог для ATmega328P

Одна прошивка проигрывает:

1. «Сова! Открывай! Медведь пришёл!»
2. Паузу 0,5 с.
3. «Чего тебе нужно?»
4. Паузу 1,5 с.
5. «Что ж ты не отвечаешь?»
6. Паузу 0,5 с.
7. «И того, и другого, и можно без хлеба».

Длительность — 10,15675 с, 81 254 отсчёта при 8 кГц. После Reset весь
разговор начинается заново; автоматического повтора нет. Короткие отдельные
LPX-сегменты позволяют сохранить все фразы, хотя общий разговор длиннее
лимита 64 000 отсчётов одного потока.

Использованы четыре уже опубликованных исходных WAV из общего каталога.
Их копии ресэмплированы в 8 кГц и нормализованы постоянным усилением до
примерно −18 LUFS перед повторным кодированием LPX P6. Исходный разброс
4,65 LU уменьшился до 0,03 LU; после декодирования — 1,03 LU. Компрессор
и ограничитель не применяются. Наибольший true peak декодированных реплик
−2,56 dBTP до финального выходного усиления. Целые единицы PCM16 записываются через общий проверенный WAV writer.

Перед записью в PWM-очередь применяется один постоянный коэффициент 170/128
(+2,46 дБ) для всего разговора. Диапазон PWM расширен с 47..223 до 20..254
без дополнительного клиппинга. Паузы остаются ровно PWM128, соотношение
громкости реплик сохраняется. Поля `segments.decoded` в манифесте описывают
декодер до этого усиления; `outputLevel` — реальный итог прошивки.

Паузы — полноценные LPX-потоки с нулевым scale. Они дают ровно 4000,
12000 и 4000 значений PWM128; таймер не останавливается между сегментами.
Один стандартный `AVR_V5_PLAYER` разделяет декодер между всеми семью сегментами.
Данные исходных фраз не обрезаются, скорость воспроизведения сохраняется.

Полный Flash — 10,240 KiB, из них программа 4680 Б и сжатые сегменты
5806 Б. Static SRAM — 756 Б; EEPROM не используется. Образ помещается
в консервативный бюджет приложения классического Nano 30 KiB без замены
существующего загрузчика или настроек fuse.

Цель: ATmega328P, 16 МГц, GNU AVR ABI, AVR-GCC 7.3.0. Выход —
D3 / PD3 / OC2B, Timer2 fast PWM 62,5 кГц; Timer1 выдаёт 8 кГц.
Подключение — RC-фильтр и усилитель с общей землёй. Определения регистров
и контактов берутся из существующих заголовков AVR-LibC, без новых адресов.

## Повторение сборки

Нужны Python-пакеты кодека, FFmpeg, host g++, AVR-GCC проекта и simavr 1.6.
Из корня репозитория:

```text
python Codecs/LPX/01_ACTIVE_Q0_CODEC/tools/build_release_observer.py build/nano-dialogue/observer --include /path/to/simavr/include/simavr --lib /path/to/simavr/lib
python tools/build-nano-dialogue.py --avr-bin /path/to/avr/bin --observer build/nano-dialogue/observer/sim_player --lib /path/to/simavr/lib --enable-asm --retain
```

На Windows добавьте `--wsl Ubuntu` к обеим командам. `--enable-asm`
выбирает существующий AVR5-бэкенд с MUL; без него остаётся эквивалентный C.
До публикации сборщик заново компилирует независимые C-декодеры v4/v5 и
v5-only, проверяет их по модели, затем исполняет целый HEX с активными IRQ.
Публикация возможна только после полного совпадения всех 81 254 PWM-значений,
нулевых underrun, точных timer counts, пустой конечной очереди и остановки таймера.
Симулятор учитывает аппаратный вход IRQ и завершение RETI; максимум IRQ —
76 тактов, интервалы вывода — 1995–2005 тактов, минимальный запас стека —
1229 Б по соглашению observer. Физическая плата и аналоговый тракт не измерены.

Подробные журналы, нормализованные исходные копии, ELF и промежуточные
проверки остаются в игнорируемом `build/`. Публичный манифест содержит
только относительные пути, хеши, уровни и количественные результаты.
