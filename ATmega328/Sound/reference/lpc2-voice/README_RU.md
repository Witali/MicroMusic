# MicroMusic — LPC2 Voice v2: сохранение высоты и тембра

В LPC2 Improved v11 основная частота F0 ограничивалась диапазоном 55–420 Гц. Для высоких голосов это искажало периодичность и могло заметно понижать голос.

LPC2 Voice v2 записывает диапазон F0 (пара чисел 16-bit LE в ранее зарезервированных четырёх байтах заголовка) и продолжает использовать 6 бит на высоту в каждом кадре. У старого LPC2 v1 по-прежнему интерпретируется диапазон 55–420 Гц. Новый декодер читает v1 и v2, старый — только v1.

Дополнительно автоматический кодировщик на компьютере исследует оригинальную запись с помощью pYIN, проверяет разные диапазоны, варианты отслеживания F0, две степени постфильтра и сравнивает восстановленный звук по STOI и спектральной ошибке. Старый вариант сохраняется, если новая версия не улучшает результат. Не следует воспринимать такие метрики как объективную гарантию идентичного тембра.

Измерения по двум новым записям:

| Фраза | STOI LPC2 v1 | STOI v2 | Спектральная ошибка v1 → v2 |
|---|---:|---:|---:|
| «Чего тебе нужно?» | 0,567 | 0,620 (0,624 при F0 по оригиналу) | 0,762 → 0,529 (0,542 с точным F0) |
| «Что ж ты не отвечаешь?» | 0,527 | 0,585 | 0,673 → 0,532 |

Для голоса Винни-Пуха прежняя версия пока точнее по спектральной метрике — она и оставлена для сравнения.

## Запуск

Откройте `LPC2_Voice_v2.html`, выберите LPC2 и нужный диапазон F0. Для автоматической обработки разных записей потребуются Python 3, пакеты из `requirements.txt` и Chromium/Playwright:

```bash
python build_encoder.py
python run_experiments.py --clips xtuj-ntt ne-otv vinni
python make_release.py
```

Для запуска вне нашей рабочей папки задайте `MICROMUSIC_DATA_ROOT` — директорию с исходными файлами `release/<имя>/source.wav`, эталонами `release/<имя>/lpc2.wav` и, если есть, прежними файлами `<имя>/teacher.lp2`. В ZIP с кодом аудиофайлов нет; они есть только в частном архиве.

Важно: это пока **полный компьютерный LPC2**, не прошивка ATtiny13A. Её LPC-7 и LPC-8 необходимо переобучать отдельно. Даже исправленный LPC2 не воспроизводит точно исходные колебания голосовых связок и микродетали спектра. Для более близкого тембра понадобится адаптивная модель возбуждения / общий голосовой профиль.
