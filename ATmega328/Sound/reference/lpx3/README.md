# MicroMusic: 3 голоса + эксперимент LPX3 для ATtiny13A

Этот набор содержит **три воспроизводимые прошивки AVR для ATtiny13A** и эксперимент по приближению к LPX3 через короткие шаблоны возбуждения.

## Готовые прошивки, действительно проверенные исполнением AVR HEX

| Фраза | Архитектура | Полный Flash | Данные речи | Образец |
|---|---|---:|---:|---|
| «Чего тебе нужно?» | Adaptive LPC-8 | 1023 Б | 180 Б | `examples/chego` |
| «Что ж ты не отвечаешь?» | Adaptive LPC-8 | 997 Б | 154 Б | `examples/otvechaesh` |
| «Сова! Открывай! Медведь пришёл!» | TinyLPC v5, 7 ступеней | 1012 Б | 435 Б | `examples/vinni` |

Все три сборки проверены повторным ассемблированием, точным сравнением бинарника и выполнением в AVR-эмуляторе. Частота CPU 9.6 МГц, CKDIV8 программно снимается. PWM 37 500 Гц / PB1, звуковые сэмплы 7500 Гц. В тестах не наблюдалось пропусков Timer0. На физическом чипе не тестировалось.

**Плеер:** открыть `index.html` (или отдельный файл `MicroMusic_Three_Voices_LPX3.html`), выбрать одну из трёх фраз, нажать «Оригинал», «LPX3» или «ATtiny», либо проверить встроенный HEX. Аудио встроено в страницу, внешний сервер не нужен. Для Android лучше Chrome.

## Повторная сборка и проверка

Необходимы Python 3, Clang с AVR backend, llvm-objcopy и Node.js. В корне архива:

```bash
python build_verify_all.py
```

Каждый каталог `examples/{chego,otvechaesh,vinni}/` содержит `tinylpc.S`, `voice_tinylpc.bin`, `build_firmware.py`, `tinylpc.bin`, `tinylpc.hex`, `avr_emulator.js`, `verify.js`, `playback.wav`. Скрипт сборки проверяет Flash не более 1024 байт.

## Почему полный LPX3 не помещается

LPX3 хранит квантованный остаток / возбуждение для почти каждого звукового отсчёта плюс LPС2-описание фильтра. Одна только речь в 3-битном LPX3 занимает 4102, 3469 и 9712 байт. ATtiny13A располагает 1024 байт Flash, 64 байт SRAM и 64 байт EEPROM. Декодер и данные обязаны разделить эту память, а EEPROM не содержит исполняемого кода.

### Выполненная попытка упаковать одну часть LPX3

`tools/train_lpx3_pulses.py` извлекает LPC2/LPX3 остаток возбуждения, выделяет короткие импульсы, обучает 4-векторный словарь длиной 8 отсчётов и сохраняет его в 4-битном виде. В `lpx3_experiment/<clip>`:

- `excitation_profiles_16B.bin`: **16 байт**, четыре восьмиотсчётных импульса по 4 бита.
- `excitation_profiles.eep`: 64-байтный EEPROM-образ (16 байт профилей + FF-пустые байты).
- `frame_selectors_2bit.bin`: по 2 бита выбора формы на LPC-кадр. Размеры 9, 8, 22 байта для трёх реплик.
- `results.json`: проверка погрешности формы импульса относительно фиксированного chirp.

Автоматический эксперимент показал **снижение ошибки формы отдельных импульсов** на контрольных фрагментах (39.8%, 51.0%, 39.0%) по сравнению с одним фиксированным шаблоном. Это **не** измерение STOI и не проверка звучания на ATtiny. Шаблоны не включены в выложенные HEX; перенос в AVR потребует дополнительного кода чтения EEPROM, вставки двухбитных селекторов в формат и нового обучения / прослушивания.

Повторить обучение (потребуются numpy, scipy, scikit-learn):

```bash
python tools/train_lpx3_pulses.py --input references/chego/voice_v3_3bit.lpx3 --frames 36 --out lpx3_experiment/chego
```

## Авторские права

`index.html`, `references/` и речевые прошивки содержат аудио/данные на основе фрагментов мультфильмов. Этот набор только для частных экспериментов. Для публикации в публичном репозитории используйте очищенный пакет с **только кодом**, без записей и закодированных производных данных, либо получите необходимые разрешения.
