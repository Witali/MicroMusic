MicroMusic · три голоса и LPX3

ATtiny13A, 9,6 МГц · PWM 37,5 кГц · выход 7500 отсчётов/с · 8-ступенчатый LPC-фильтр для двух коротких реплик. Для Винни-Пуха добавлен ранее собранный 7-ступенчатый вариант. Двухскоростная интерполяция формант и громкости: 4 отсчёта на шаг для быстрых переходов, 8 для протяжных. Скорость автоматически выбирается из исходного голоса и занимает один ранее свободный бит кадра. Все три реплики встроены: интернет не нужен.

LPX3 → сверхкомпактные шаблоны возбуждения (эксперимент)

Полный LPX3 содержит квантованные значения возбуждения почти для каждого сэмпла и в 1 КБ Flash не помещается. Для каждого голоса мы обучили 4 коротких импульсных шаблона по 8 отсчётов, упакованных по 4 бита. Словарь — 16 байт; один двухбитовый индекс на 256 отсчётов речи. Файлы EEPROM и индексов можно скачать прямо из автономной страницы.

Как интегрировать

Загружать 16 байт импульсных профилей из EEPROM (64 байта всего), выбирать двухбитный профиль при чтении LPC-кадра и применять восьмиотсчётный импульс вместо фиксированного. Номера профилей можно разместить в свободных битах формата кадров там, где это возможно. При новой сборке надо измерить дополнительные инструкции и оценить качество на всех трёх записях.

Adaptive LPC-8 — экспериментальная прошивка для двух коротких реплик; Винни-Пух добавлен с ранее созданной прошивкой LPC-7. Третья реплика не проходила новое адаптивное обучение. Сравнение с LPX3 отражает разницу между качественным речевым кодеком и моделью для 1 КБ Flash. Оригинальные фрагменты предназначены для частного исследования и не должны публиковаться без разрешения правообладателей. Проверена программная AVR-эмуляция; аппаратное испытание ещё не выполнено.
