# Звуковые кодеки ATmega328P

- `lpc2/` — исходная Arduino-библиотека LPC2 Improved с SD/PROGMEM-проигрывателями.
- `lpx3/` — текущий LPX3 Rice v4: C++-декодер, Python-кодировщик, тесты и самодостаточные синтетические скетчи.
- `reference/` — исходные браузерные LPC-лаборатории, LPC2 Voice v2 и LPX3 до переноса на AVR; это эталоны на ПК, а не прошивки ATtiny13.
- `research/stages/` — результаты порта L3AV, Fast2, VBR, сравнения словарей и Rice v2/v3/v4. Более ранние исходники доступны на коммитах из корневого указателя.

Rice v4 сжал три сохранённых потока до 5215/4421/8289 Б при неизменных PCM. Rice v3 может быть выгоднее по сумме кода и короткой записи: v4 добавляет код декодера. Цикловой бюджет реального ATmega328P пока не измерен.

Стандартные регрессионные тесты (Python 3 и g++):

```text
python tests/verify.py --fuzz 300
```

Команда запускается из `lpx3/`; на Windows исходный тест ожидает GNU-совместимый драйвер компилятора. При импорте его сборочная функция была заменена внешней обвязкой MSVC без изменения тестовых сценариев и декодеров.

Устаревший одиночный V3-скетч исключён. Для текущего формата используйте `examples/LPX3_RICE_V4_SYNTHETIC/` и `LPX3_RICE_V4_PROFILE_SYNTHETIC/`.
