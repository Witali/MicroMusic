Банк компактных инструментов ATtiny13A
====================================

bank.json хранит измеренные тембры для назначения партиям при сборке.
В прошивку попадают только выбранные формы в EEPROM: два регистра по 8 байт
на голос. Общий банк и измерения в память микроконтроллера не копируются.
Смена инструмента в том же генераторе не требует дополнительного кода AVR.
Модель огибающей и уровень выбираются сборщиком по метаданным профиля.

Инструменты и номера General MIDI (программные номера 0..127):
  acoustic-grand-piano   0   акустический рояль
  acoustic-grand-piano-soft 0 мягкий рояль, отдельный профиль Алисии
  acoustic-guitar-nylon 24   акустическая гитара, нейлоновые струны
  fretless-bass        35   безладовый бас
  violin               40   скрипка
  cello                42   виолончель
  synth-strings-1      50   мягкие синтезаторные струнные Children
  clarinet             71   кларнет
  flute                73   флейта
  off                   —   выключенная партия

Ударные natural-kit выбирают существующий шумовой генератор: GM 35 — басовый
барабан, 38 — малый барабан, 42 — закрытый хай-хэт. Их спектры измерены отдельно;
EEPROM для набора не требуется. percussion: off выключает ударную партию.
Параметры ударных: percussion-profiles.json, подробности percussion-README.txt.
Хай-хэт Люмьера сохранён, малый барабан сочетает мягкий шум с низким корпусом.

Источник — локальный оригинальный FluidR3 GM 3.1, без эффектов, velocity 100;
дополнительные измерения мягкого рояля выполнены при velocity 64.
SHA-256 SoundFont и каждого файла измерений записаны в bank.json. Лицензия
и исходные уведомления сохранены в FluidR3-MIT.txt. Сам SF2 здесь не хранится.
Измерения содержат гармоники, огибающие и хеши исходных PCM, а не инструкции.

Формат и ограничения
-------------------
Одна периодическая форма содержит 16 целых отсчётов -8..7. В EEPROM каждый
отсчёт кодируется как sample+8; первый отсчёт занимает младшие 4 бита байта.
Низкий и высокий регистры размещаются парами по следующим адресам:
  lead:   0..7 / 8..15
  keys:  16..23 / 24..31
  pluck: 32..39 / 40..47
  48..55 / 56..63: спектры атаки рояля в низком/высоком регистрах;
                  без фортепиано заполнены тишиной 0x88.
Имена ролей совместимы с генератором: в любую роль можно назначить любой
инструмент. Они не обязывают использовать скрипку, клавиши или гитару.

violin, acoustic-grand-piano и acoustic-guitar-nylon сохраняют прежние мягкие
формы побайтно. Скрипка использует описанное в fit-report.json смешение
60% solo violin / 40% strings; рояль и гитара — собственные GM-программы.
Безладовый бас сохраняет измеренную тихую форму ±4; её высокий регистр
пока использует тот же низкий профиль и отдельно не измерялся.

Флейта, виолончель и кларнет измерены в четырёх нотах на шести возрастах
180..580 мс. Для MIDI<63 и MIDI>=63 подобраны отдельные формы. Семь гармоник
смягчены фильтром 1/sqrt(1+(harmonic/3.2)^6); детерминированный целочисленный
поиск уменьшает спектральную ошибку, сохраняет нулевую постоянную составляющую
и амплитуду не больше ±5. Нормированное расстояние до смягчённой цели составляет
0.018..0.033; исходные и целевые спектры записаны рядом с формами.

Это компактное приближение тембра: 16 точек не передают многослойные сэмплы,
шум дыхания, изменение спектра во времени и весь диапазон FluidR3. Огибающая
в bank.json является выбором модели генератора, а не копией всех SF2-генераторов.

Сборка и добавление инструментов
------------------------------
Python API tools/instrument-bank.py:
  load_bank() -> проверенный JSON-словарь
  build_eeprom(assignments) -> bytes длиной 64
  describe_assignments(assignments) -> инструмент, огибающая, уровень и адрес
  verify_sources() -> проверка хешей сохранённых измерений

Пример assignments:
  {"lead": "acoustic-grand-piano",
   "keys": {"instrument": "fretless-bass", "level": 6},
   "pluck": "off"}

Отсутствующие роли выключены. level=0..15 — явный параметр огибающей для
сборщика AVR; build_eeprom не масштабирует форму повторно. Шумовые ударные
используют отдельный генератор; percussion принимает off или natural-kit.

Из корня репозитория:
  python tools/instrument-bank.py --lead flute --keys violin --pluck cello \
    --verify-sources --describe --output build/instrument-bank/selected.bin
  python tools/test-instrument-bank.py

Без --output утилита печатает метаданные и не изменяет файлы прошивок.
Для нового назначения в сохранённой score.json укажите engine: "instrument-bank"
и instruments с ID/уровнями партий, затем запустите:
  python tools/build-rhythmic.py ATtiny13A/Music/variants/<имя>
Сборщик выбирает модели огибающей, удаляет выключенные голоса и проверяет
реальный лимит 1024 Б. Он поддерживает также записанные такты 6/8.
Ударный профиль выбирается ключом percussion_kit (по умолчанию natural-kit).
Уровень ударных приближается сдвигами: 1, 1/2, 1/4 или 1/8; 0 выключает код.
Сборщики arrange-* повторно создают аранжировку со своими назначениями.
Обычная сборка не требует NumPy, SF2 или аудиодвижка. Для добавления тембра
сначала сохраняют прямые измерения нужной GM-программы оригинального банка:
tools/render-fluid-violin.mjs (параметр --program) и tools/analyze-fluid-violin.py.
Затем NumPy-операция выводит воспроизводимый компактный fit:
  python tools/instrument-bank.py --fit-measurement path/to/measurements.json
В bank.json добавляют формы, GM-программу, модель огибающей и происхождение
с хешем измерений. Проверки контролируют физическую раскладку всех 64 байт,
тишину, допустимые назначения, происхождение и погрешность новых спектров.

Мягкий рояль
-------------
acoustic-grand-piano-soft использует измеренные спектры 34 нот FluidR3 GM0.
Атака усредняется по 60/90/120 мс, удержание — по 200/300/500 мс, верхние
гармоники сглажены H3.5/H3. Переход атака/удержание ограничен одним отсчётом,
фаза сохраняется. Изменение velocity само по себе не объясняет мягкость:
у измеренных нот спектры почти одинаковы; отличие создано выбором временных
окон и гармоническим сглаживанием. Измерения: reference/fluidr3/piano-soft-measurements.json,
результат и сравнение с VSCO2 CE Upright: piano-soft-fit-report.json.
  python tools/instrument-bank.py --fit-piano-transients ATtiny13A/Music/reference/fluidr3/piano-soft-measurements.json --piano-voicing soft
Уточняйте имя параметра через --help; обычная сборка уже использует готовый профиль.

Для bowed/sustain доступны независимые attackMask/releaseMask:0,1,3,7,15.
Огибающая обновляется при (R24 & mask)==0. У GM50 attackMask1,releaseMask7;
нативное ядро Children использует отдельные описанные уровни/усиление.
