Ударные FluidR3 для ATtiny13A
===========================

Рабочий natural hi-hat из «Люмьера» сохранён: тот же 16-битный LFSR
с периодом 65535, XOR 0x002D, разность двух шестибитных выборок и
два арифметических сдвига. Другой hi-hat вместо него не подставляется.

percussion-profiles.json содержит компактный комплект FluidR3 Standard,
GM percussion bank 128, channel 9, program 0:
  kick  — GM35 Acoustic Bass Drum, имеющийся медленный triangle;
  snare — GM38 Acoustic Snare, половинный шум плюс тихое низкое тело;
  hat   — GM42 Closed Hi-Hat, имеющийся natural hi-hat «Люмьера».

Корпус snare берётся из уже существующего счётчика PWM R15. Его частота
146,484 Гц попадает в полосу 120–250 Гц, где у измеренного FluidR3 snare
сосредоточено около 63% энергии. Сдвиг фазы на -64 начинает тело около
нуля, снижая резкий скачок при атаке. Код добавляет 22 байта к прежнему
шумовому snare; дополнительная SRAM и EEPROM не нужны. Новый параметр
не сбрасывает фазу тональных инструментов.

Комплекты:
  natural-kit          — выбранный мягкий snare: noise/2 + triangle;
  legacy-kit           — прежний noise-only snare для сравнения;
  full-body-comparison — triangle + прежний полный шум.
Во всех трёх kick и hat остаются одинаковыми.

Профили подключены к основной прошивке 01 «Люмьер»: актуальная сборка
занимает 1016 байт Flash, из них 730 байт кода. tools/build-rhythmic.py
вызывает compile_source после специализации инструментов. Выбор в score.json:
  "instruments": { ..., "percussion": "natural-kit" },
  "percussion_kit": "natural-kit"
percussion_kit по умолчанию равен natural-kit. Другие варианты выбора:
legacy-kit / full-body-comparison. Уровень ударных переводится сборщиком
в дополнительное ослабление сдвигами; фактические параметры, комплект
и SHA-256 профилей сохраняются в build-report.json → percussionProfile.
При выключенных ударных сборщик не включает этот участок кода.

Измеренное расстояние по спектральным полосам (меньше — ближе):
  kick GM35                  0,2221–0,2232;
  прежний noise-only snare    0,8179–0,8676;
  выбранный мягкий snare      0,2849–0,3118;
  полный шум + корпус        0,2855–0,3190;
  сохранённый hi-hat          0,1932–0,2421.
Проверены обе фазы общего decay-таймера и три начальных состояния
верхнего байта шума. Условия и все полосы записаны в percussion-verification.json.
Сравнивался цифровой выход после целочисленной midpoint-интерполяции,
до внешнего аналогового фильтра. Это спектральное сравнение, не заявление
о неотличимом воспроизведении PCM SoundFont.

Огибающая намеренно соответствует работающему AVR: R21 = 0,1,2,3
даёт сдвиги [0,1,1,2], то есть уровни 1,1/2,1/2,1/4, затем тишину.
Это следует из двух SBRC/ASR по битам R21; уровни не равны 1,1/2,1/4,1/8.
Первый интервал зависит от фазы общего таймера: 13,65 или 27,31 мс.
Полная длительность 95,57–109,23 мс. Собственного ramp-attack у старого
шума нет; сохранены его небольшая амплитуда и сглаживание midpoint PWM.
Хвосты и изменяющийся спектр исходных сэмплов аппроксимированы грубо.

Консервативные границы цифрового микса до центрального уровня 128:
  kick [-16,+16], hat [-8,+8], выбранный snare [-24,+23].
Даже сумма с тремя максимальными четырёхбитными тональными голосами
остаётся внутри signed-byte диапазона. Дополнительный attenuation_shift
0..3 уменьшает уровень через ASR, без умножения и таблиц.

API tools/percussion-bank.py:
  load_bank() / verify_source(bank);
  select_kit('natural-kit');
  select_gm_note(42);             # неизвестные GM36/44 не заменяются молча
  compile_source(source, kit='natural-kit', bank=None, attenuation_shift=0).

compile_source возвращает AVR-исходник и ничего не пишет. Вызывать после
build-instrument-engine.specialize(), когда percussion включён. Допускается
только известный render_drum -> write_pwm участок. Несовместимые модели,
неизвестный код, изменённый LFSR/hat, неподдерживаемый источник фазы
или слишком большой уровень завершаются ValueError. Константы bias,
shifts и фазового сдвига компилируются в непосредственные операнды.
Вне участка drums исходник сохраняется. Отключённые ударные должны быть
удалены внешним specialize(); этот API не включает их сам.

Проверки:
  python tools/test-percussion-bank.py
  python tools/percussion-bank.py --kit natural-kit
  python tools/percussion-bank.py --measure
Выбор и сборка не требуют NumPy, SoundFont или аудиорендерера.
Только необязательный спектральный пересчёт --measure использует NumPy.
Тесты исполняют собранный AVR для трёх комплектов, kick/hat/snare и обеих
decay-фаз: 41472 сэмпла совпали с целочисленными профилями. Машинные байты
существующего noise/hat участка проверяются на идентичность.

Источники: retained reference/fluidr3/percussion-measurements.json,
его SHA-256, исходного FluidR3 и рендерера сохранены в профилях.
Лицензия FluidR3 — FluidR3-MIT.txt в этой же папке.
В исходных MIDI «Турецкого марша» и Greensleeves ударных нет.
В Children channel9 начинается с 64-й четверти и использует в основном
GM36/44/38; текущая piano/bass адаптация оставляет percussion выключенным.
