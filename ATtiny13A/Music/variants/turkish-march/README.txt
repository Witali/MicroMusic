02 · МОЦАРТ — ТУРЕЦКИЙ МАРШ, НАЧАЛЬНЫЙ ФРАГМЕНТ

Исходное узнаваемое начало сохранено: F4–D#4–D4–D#4–F#4.
Адаптированы первые 56 тактов 2/4 пользовательского MIDI и добавлена
заключительная каденция D#. Продолжительность 46,093 с при 151 BPM.
Это начальный фрагмент, а не весь MIDI. Изменения выразительного темпа
заменены постоянным темпом; шестнадцатая сетка сохраняет повторные Note On.
Мелодия — верхняя нота правой руки, сопровождение — корни левой руки
и ритм устройства. Полифония фортепиано сокращена до четырёх голосов.

Flash 1022 Б: код 710 Б, таблицы/партитура 312 Б; EEPROM 64 Б.
Синтез 18,75 кГц, PWM с промежуточными средними 37,5 кГц; ISR 19 тактов.
Ноты и ударные синхронизирует одна дробная музыкальная фаза.
Прошить synth.hex и eeprom.hex. Фьюзы: Low 0x7A, High 0xFF.

ПОИСК И УПАКОВКА
Программа оценила все 112 префиксов исходной мелодии по тактам,
затем усилила поиск словаря возле границы Flash. Выбран самый длинный
поместившийся проверенный вариант. Запись попыток: packing-search.json.
Точное минимальное размещение всех возможных словарей не гарантируется.
431 музыкальная команда сжата без потерь: 238 Б фраз + 13 Б ссылок,
251 Б вместо 435 Б исходного размещения. Декомпрессор в AVR не добавлялся.
Сначала MIDI редуцируется и привязывается к сетке; последующее сжатие
уже не меняет ни одну команду, порядок, длительность или повторную атаку.

ВОСПРОИЗВЕДЕНИЕ СБОРКИ ИЗ КОРНЯ
  python tools/arrange-turkish-march.py

Для пересборки сохранённой score.json без поиска длины:
  python tools/build-rhythmic.py ATtiny13A/Music/variants/turkish-march

Исходный MIDI и авторская подпись: ../../reference/turkish-march/.
Измерительный отчёт: web-player/reports/turkish-march-verification.json.
Все 444 команды с границами фраз и 3377 тиков огибающих проверены.
Пропусков нот, ударных, запросов таймера и основной программы нет.
Максимальное отклонение от идеальной сетки 13,27 мс за весь фрагмент;
все 7 повторных нот артикулированы. Реальные команды AVR имеют тот же
SHA-256, что несжатая партитура. Отдельный тест исполняет начало прошивки
и сверяет первые девять нот с MIDI; вступление при компоновке не теряется.
