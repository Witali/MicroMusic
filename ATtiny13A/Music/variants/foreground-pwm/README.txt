СИНТЕЗ В ОСНОВНОМ ЦИКЛЕ / ATtiny13A

Версия 09, ?firmware=foreground-pwm. Мягкие тембры FluidR3 из версии 08,
та же EEPROM и партитура, новая организация исполнения AVR-кода.
Flash 1022/1024 Б; EEPROM 64/64 Б. synth.hex + eeprom.hex; сначала Flash,
затем EEPROM. Low Fuse 0x7A, High Fuse заводской 0xFF, 9,6 МГц,
PB1/OC0B — вывод 6. Лицензия банка: FluidR3-MIT.txt.

ПРЕРЫВАНИЕ
Timer0 переполняется раз в 256 тактов, 37 500 раз/с. Настоящий ISR:
  OUT OCR0B, R18
  SET
  RETI
С учётом аппаратного входа (4 такта) и перехода из вектора (2 такта)
это постоянно 12 тактов, 1,25 мкс вместо прежнего максимума 418 тактов.
ISR не меняет рабочие регистры, флаги C/Z и другие арифметические флаги.
SET устанавливает только SREG.T — однобитный флаг ожидающего тика.

ОСНОВНОЙ ЦИКЛ
BRTC ждёт T, CLT принимает тик, RCALL вызывает прежнюю логику синтеза.
Новый отсчёт рассчитывается каждый второй тик: 18 750 Гц. Микшер
накапливает результат в R26; единственная команда MOV публикует
полностью готовый байт в R18. ISR никогда не читает частичный микс.
Во время смешивания музыкальный счётчик R25 сохраняется PUSH/POP.
Все инструкции алгоритма сохраняют T; IRQ может прервать вычисление
на любой границе инструкции, не разрушая его флаги и регистры.

Длинный расчёт может занять больше 256 тактов: очередной тик остаётся
в T и затем обрабатывается коротким вызовом. Два тика до очистки T
означали бы потерю запроса. Поэтому отдельно проверяются потеря TOV0
и повторный SET при уже установленном T. Оба счётчика должны быть нулём;
индикатор потерь в общем плеере включает оба вида. В двухсекундном
прогоне 75 000 опубликованных значений побайтно совпали с версией 08;
длительность расчёта с прерыванием до 422 тактов, максимум стека 9 Б.
Физические записи PWM теперь равномерные и читают последний готовый
отсчёт; их фиксированная фазовая задержка отличается от старого ISR.

СБОРКА И ОГРАНИЧЕНИЯ
  python tools/assemble-avr.py --verify-originals
  python tools/build-foreground-pwm.py
  node tools/render-firmware-preview.mjs ATtiny13A/Music/variants/foreground-pwm 14
  python web-player/scripts/build_catalog.py
  node --test web-player/tests/*.test.mjs
Сборщик поддерживает только используемое здесь подмножество GNU AVR.
Перед сборкой он побайтно сверяет четыре сохранённых исходника с их
готовыми бинарниками, включая результат исходного GNU/LLVM toolchain.
Все адреса кода и данных заново разрешаются по меткам. 2 Б освобождены
удалением ненужных NOP и записи PWM из ветки повтора.
avr_core.js — сохранённый интерпретатор, расширенный только SET/CLT
и переходами по T. Общее оптимизированное ядро сравнивается с ним.

Это программная проверка; физический ATtiny13A пока не испытывался.
Модель усредняет PWM, не моделирует фронты PB1 и аналоговую схему.
Тональные измерения, мягкая настройка и сравнение струнных пресетов:
../fluid-instruments/README.txt и соответствующие JSON в том каталоге.
preview.wav — фактический код AVR, 48 кГц, HP 35 Гц / LP 4 кГц,
Q=0,5, gain=0,65. Плеер открывает эту версию по умолчанию.
