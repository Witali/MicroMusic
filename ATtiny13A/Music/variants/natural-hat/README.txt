Длинный шум тарелок — вариант 10

Вариант 09 сохранён в ../foreground-pwm/ для сравнения. Здесь изменён
шумовой генератор и формирование хэта; мелодия, три тональных голоса,
все таблицы EEPROM, басовый удар и номинальная огибающая ударных прежние.

В старом шумовом генераторе только 255 состояний: при непрерывном расчёте
18,75 кГц рисунок повторялся бы через 13,6 мс. Это может добавлять хэту
заметный тональный призвук. Новый 16-битный генератор проходит 65535
ненулевых состояний: 3,4952 с при непрерывном расчёте. Реальный звук ещё
зависит от огибающей, пропусков расчёта на музыкальных тиках и повторных
ударов, поэтому эти числа описывают генератор, а не период всей записи.
R14 хранит младший байт, SRAM[0x60] — старший; при ударе старший байт
сохраняется. Начальное состояние детерминировано.

Для хэта вместо побитового XOR используется разность соседних значений
шума с дополнительным ослаблением. Измерение реального AVR-выхода по
восьми полосам 35..9000 Гц приблизило спектр к Closed Hi-Hat, GM 42 из
нашего FluidR3 GM: расстояние нормированных корней мощностей 0,3368 →
0,2013 (примерно на 40% меньше). Малый барабан использует тот же длинный
генератор, сохраняя прежнюю форму выборки; басовый удар совпадает побитно.
Это компактная шумовая имитация, а не воспроизведение сэмпла тарелки.
Четыре ступени огибающей ударных сохранены; их плавность ограничена.
Источник и параметры измерения: percussion-measurements.json.

Flash: 1024 Б. EEPROM: 64 Б, совпадает с вариантами 08/09. SRAM: один
байт для шума у нижней границы, аппаратный стек растёт от 0x9F вниз.
Прерывание остаётся OUT / SET / RETI: 12 тактов с входом и вектором.
Пересборка уплотняет несколько переходов и хвостовых вызовов; CLI при
сбросе удалён, поскольку аппаратный сброс уже очищает SREG.I. Выполнение
требует аппаратного сброса/обычного запуска, а не перехода из другого кода
с уже разрешёнными прерываниями. Музыкальный поток при отключённых
ударных сравнен с вариантом 09 по каждому готовому отсчёту.

Сборка:
  python tools/build-natural-hat.py
  node tools/measure-natural-hat.mjs
  python tools/analyze-natural-hat.py
  node tools/render-firmware-preview.mjs ATtiny13A/Music/variants/natural-hat
  python web-player/scripts/build_catalog.py
Анализ требует локальные измерения FluidR3 в build/fluid-grid/drums/ и NumPy;
исходный SoundFont не добавлен в репозиторий. Лицензия FluidR3 рядом.

Проверка:
  node --test web-player/tests/*.test.mjs
В плеере: ?firmware=natural-hat. Для записи в чип нужны оба HEX: synth.hex
во Flash и eeprom.hex в EEPROM. Ограничения эмуляции и фьюзы описаны в
корневом README.txt и web-player/README.txt. Физический чип не измерялся.
