ATtiny13A — Robert Miles — Children

Никакого отдельного JS-синтезатора: браузер исполняет инструкции из synth.hex с длительностями в тактах AVR, обрабатывает переполнения Timer0 и читает записи в PWM-регистр OCR0B.

По умолчанию уже встроены проверенные образы Flash и EEPROM. Для других образов требуется тот же набор поддерживаемых инструкций AVR.

Жёлтая горизонтальная линия обозначает PWM=128. График построен по PWM duty до фильтра, а не по аналоговому напряжению на выходе.
Ожидает нажатия «Слушать».

Если браузер на телефоне не успевает исполнять AVR по тактам, можно послушать заранее рассчитанный WAV из той же прошивки.

Файл preview.wav должен находиться рядом с player.html (он есть в ZIP).
Воспроизводимая конфигурация

ATtiny13A · CPU 9,6 МГц · 37,5 кГц Fast PWM · 18,75 кГц новых отсчётов · выход PB1/OC0B · мелодия, пианино, гитара и ударные. Ноты и секции воспроизводятся из прошитого кода. Браузер имитирует только инструкции, используемые этой конкретной прошивкой.

Это цифровая модель усреднённого PWM-сигнала. Реальная АЧХ зависит от RC-фильтра, усилителя и частоты RC-генератора микроконтроллера.
