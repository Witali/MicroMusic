03. Robert Miles — Children
==========================

В 1 КБ Flash помещена вся основная фортепианная мелодия дорожки 1:
107 тактов 4/4 (428 четвертей), включая узнаваемое начало с первого
такта. Все 256 исходных Note On сохранены после привязки к шестнадцатым.
В конце добавлена тактовая каденция F. Продолжительность — 3:05,14
при постоянном темпе 140 BPM, затем мелодия повторяется.

Выбраны инструменты исходного MIDI: фортепиано (GM program 0) для
мелодии дорожки 1 и тихий безладовый бас (GM program 35) из дорожки 4.
Скрипка заменена таблицами FluidR3 Yamaha Grand Piano и огибающей
фортепиано: быстрая полная атака, затем затухание. Повторные ноты
атакуются заново; связанные ноты продолжаются без новой атаки.
Бас звучит на исходных C#2/A#1/F1, а не на добавленной квинте.
Его таблица построена по измерениям FluidR3 Fretless Bass для этих
трёх нот; верхние гармоники смягчены, уровень снижен до 6 из 15.
Фаза обоих генераторов при смене нот сохраняется.

Назначения находятся в score.json → instruments, а таблицы берутся
из общего ../../instruments/bank.json через tools/instrument-bank.py.
Модели огибающих, пик пиано и тихий уровень баса проверяются по банку.
Общий сборщик инструментов генерирует и таблицы, и код огибающих.
Бас мягко нарастает по два уровня за музыкальный тик до 6 из 15,
при повторной команде партии начинает с половины текущего уровня;
после Note Off затухает по одному уровню за тик. Пиано получает
полную атаку 15 и собственное трёхскоростное затухание. Это компактные
модели генератора, а не полные многослойные огибающие исходных сэмплов.

Из микса убраны добавленная гитара и искусственные ударные. В исходном
MIDI ударные вступают только с 64-й четверти; адаптация оставляет
чистые фортепиано и бас на всём протяжении. Тихий бас удерживается
между сменами гармонии, без имитации всех отдельных басовых атак.
Остальная полифония, эхо и поздние фоновые слои опущены. Изменение темпа
примерно со 140 до 137 BPM на 160-й четверти заменено единым 140 BPM.

Объём: Flash 828 из 1024 байт (546 код + 282 таблицы/партитура),
EEPROM 64 байта. Программа сама находит повторяющиеся команды и
собирает словарь фраз с плейлистом. Партитура после музыкальной
редукции сжимается без потерь: 637 -> 228 байт (включая плейлист).
Это детерминированная эвристика, без заявления о глобальном минимуме.

Общий счётчик шестнадцатых синхронизирует мелодию и смены баса.
Частота синтеза 18 750 Гц, PWM 37 500 Гц; промежуточные значения —
среднее соседних рассчитанных сэмплов. Прерывание занимает 19 тактов.

Файлы:
  synth.S / config.inc / score.inc — исходники сборки;
  synth.hex / synth.bin           — Flash;
  eeprom.hex / eeprom.bin         — таблицы пиано/баса, обязательно прошить;
  score.json                     — музыкальная адаптация и происхождение;
  player.html                    — автономный проигрыватель;
  preview.wav                    — первые 18 секунд реальной эмуляции;
  build-report.json              — размеры, упаковка и SHA-256.
                                  Также — назначения и SHA-256 банка.

Исходный MIDI и его метаданные: ../../reference/children/.
Источник предоставлен пользователем: Robert Miles - Children.mid.
Встроенная подпись MIDI: Copyright © 1996 by Marcel Gonzalez;
bka "DREAMS". Автор музыки: Robert Miles.
Лицензия MIDI из этих метаданных не выводится.
FluidR3-MIT.txt относится к использованным данным тембров FluidR3.

Воспроизведение сборки из корня репозитория:
  python tools/arrange-children.py
  python tools/test-children.py
  node tools/audit-rhythm.mjs children
  node tools/render-firmware-preview.mjs ATtiny13A/Music/variants/children 18

Повторное измерение баса (исходный FluidR3 и SpessaSynth — внешние
файлы с SHA-256, зафиксированными в fretless-measurements.json):
  node tools/render-fluid-violin.mjs --soundfont <FluidR3_GM.sf2> --engine <spessasynth.js> --output build/children/fretless --profile guitar --program 35 --notes 29,34,37 --gate 4 --tail 1.2
  python tools/arrange-children.py --bass-capture build/children/fretless
Здесь параметр profile задаёт лишь формат захвата; program 35 явно
выбирает Fretless Bass. Измеренные гармоники хранятся в reference/children/.

Фьюзы и подключение те же, что у прошивки 01 «Люмьер»:
ATtiny13A, 9,6 МГц, CKDIV8 выключен; PWM PB1, физический вывод 6.
Точные фьюзы приведены в основном web-плеере.
