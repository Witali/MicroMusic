# Целочисленная речь «Чего тебе нужно?»

Модель `period-fixed-v1`, 7500 Гц, 9216 отсчётов. Весь подбор выполняется
автоматически через полный `decode_fixed`, включая округление, насыщение и
целочисленный DC-блокиратор. Линейный float-кеш не используется. Исходный WAV
читается из игнорируемого хранилища и сверяется по SHA-256 с `audio-references.json`.

| Кандидат | STOI | Ошибка лог-спектра | Данные общего формата |
| --- | ---: | ---: | ---: |
| Первое целочисленное преобразование, DC7 | 0,889793 | 0,359248 | 511 байт |
| Автоматический подбор, 12000 предложений | 0,923332 | 0,372118 | 510 байт |
| Одна FIR, без отдельного шумового режима основной волны | 0,923331 | 0,381224 | 510 байт |
| Без FIR, без отдельного шумового режима основной волны | 0,921174 | 0,385720 | 510 байт |

`model.json` — последний вариант таблицы. Он позволяет специализировать
декодер: все активные основные кадры голосовые, у шумового остатка используются
только цвета 0 и 1. Три FIR-строки одинаковы: `[0,0,0,0,1,1,3,7]`; декодеру
достаточно вычислить одну такую форму шума. Текущий общий контейнер сохраняет
все три строки, поэтому размер 510 байт не равен размеру специализированных
AVR-таблиц и не включает машинный код.

Сначала сравниваются качество и ограничения модели. Полный размер прошивки,
SRAM, стек и интервалы отсчётов определяет отдельная сборка/проверка AVR.
Таблица качества сама по себе не доказывает, что прошивка помещается в ATtiny13A.

## Сохранённые материалы

- `initial-model.json` — первое целочисленное преобразование; для обучения
  включён `dc_block_shift=7`.
- `reference-model.json` — лучший общий целочисленный кандидат после 12000
  предложений. `training.json` содержит настройки, историю, версии библиотек
  и хеши входов/исходников.
- `model.json` — упрощённая модель после полного автоматического подбора
  остатка по всем кадрам.
- `white-model.json` — запасной вариант только с высокочастотным шумом,
  позволяющий полностью исключить FIR-вычисления и их историю из AVR.
- `simplifications.json` — измерения упрощений на одной зафиксированной
  контрольной модели, до и после подбора остатка.

В общем поиске минимизировалось `spectral_loss + 8*(1-STOI)` с жёсткими
ограничениями: STOI не ниже начального, ошибка лог-спектра не выше 0,395174,
пик не выше 0,95 и данные не больше 511 байт. Кандидаты с отсечением до или
после DC-блокиратора отвергались. FIR-коэффициенты не менялись; парные правки
голосового словаря сохраняли сумму каждого периода. При упрощении выполнялся
полный перебор уровня/разрешённого цвета остатка в каждом кадре, ограниченный
размером контрольной модели. Это локальный автоматический поиск, без заявления
о глобальном оптимуме или гарантии субъективного качества по одному STOI.

## Воспроизведение

Общий поиск был выполнен версией `ce7d7dd` (до добавления отдельной спектральной
полировки). В текущем скрипте тот же режим выбирается явно:

```powershell
python tools/train-fixed-speech.py --model ATtiny13A/Sound/research/fixed-period/chego/initial-model.json --reference C:/Work/MicroMusic/build/hq4-preview/chego/original.wav --output build/fixed-research-replay --proposals 12000 --dc-shift 7 --objective balanced --seed 23074
python tools/probe-fixed-simplifications.py --model ATtiny13A/Sound/research/fixed-period/chego/reference-model.json --reference C:/Work/MicroMusic/build/hq4-preview/chego/original.wav --output build/fixed-simplifications-replay --variants compact
```

Checkpoint содержит состояние генератора, точные PCM и модели обоих состояний.
Resume проверяет исходные хеши, конфигурацию и соответствие PCM декодеру;
изменение числа оставшихся предложений не меняет последовательность поиска.
Режим `--objective spectral --stoi-floor 0.912` отдельно уменьшает спектральную
ошибку: превышение STOI над порогом не даёт дополнительного выигрыша.
