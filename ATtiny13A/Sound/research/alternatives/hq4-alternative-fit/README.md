# MicroMusic — MiniLPC-HQ4 (ATtiny13A)

Экспериментальные LPC-прошивки для **ATtiny13A, 9,6 МГц**, 1024 байта Flash, 64 байта SRAM. Частота речевых отсчётов 7500 Гц, аппаратный PWM на PB1/OC0B — 37 500 Гц. 8-ступенчатый lattice LPC, 4 формы возбуждения, выборочно обновляемые половины коэффициентов и кадры 64/128/192/256 отсчётов.

**HQ4 предназначен только для нового собственного формата** — старые потоки декодер не поддерживает. Исполняемый код 406 байт, включая векторы и инициализацию.

## Итоговый тест (исходный HQ3 → оптимизированный HQ4)

| Фраза | STOI HQ3 | STOI HQ4 | Spectral HQ3 | Spectral HQ4 | Flash HQ4 |
|---|---:|---:|---:|---:|---:|
| Чего тебе нужно? | 0.894838 | 0.900370 | 1.36688 | 1.36885 | 955 Б |
| Что ж ты не отвечаешь? | 0.816194 | 0.818409 | 1.24683 | 1.25810 | 886 Б |
| Сова, открывай, медведь пришёл | 0.855178 | 0.857352 | 0.94783 | 0.94345 | 1024 Б |

*STOI (pystoi, не extended, 7500 Гц) измеряет разборчивость, не субъективную идентичность голоса. Эти значения получены обучением и проверкой на тех же трёх фразах, что использованы при оптимизации — это не гарантии для произвольного материала.*

Все три AVR HEX были собраны через clang/LLVM и реально исполнены цикловым JS-эмулятором AVR (39 424 PCM-отсчёта, 0 расхождений, 0 пропущенных переполнений Timer0). **На реальной микросхеме пока не испытывались.** Всплесков |ΔPCM| >= 48 не обнаружено. Превышений Flash нет.

## Файлы

- `index.html` — автономный Web Audio A/B-плеер (оригинал, HQ3, HQ4, LPX3) и проверка настоящих HEX в AVR-эмуляторе.
- `results/<voice>/firmware.{S,bin,hex}` — программа + оптимизированный речевой поток.
- `results/<voice>/speech.hq` — битовый поток *без* конечного 0xFF (он добавлен в прошивке).
- `results/<voice>/trained.npz` — **сохранённые обученные параметры** (ключевые точки и длительности).
- `optimize.py` — полный воспроизводимый greedy analysis-by-synthesis: STOI + спектральная ошибка, жёсткие лимиты Flash, щелчков, с возможностью продолжения с checkpoint.
- `polish_timbre.py` — второй проход: уменьшение спектральной ошибки при фиксированном минимуме STOI.
- `codec.py` — упаковка/распаковка нового формата.
- `model.py`, `quality.py` — бит-совместимая модель и измерения.
- `build_verify.py`, `verify_avr.js`, `avr_emulator.js` — сборка, проверка по тактам, повторная генерация WAV.
- `make_player.py` — генерация автономного HTML.
- `convert_audio.py` — MP3/WAV → WAV моно 7500 Гц, выбор участка и нормализация.
- `inputs/` содержит эталонную запись и **старый HQ3-поток только для процесса обучения на ПК**, а не для поддержки в прошивке.
- `synthetic_demo/` и `make_synthetic_demo.py` — тестовый пример без чужих аудиозаписей.

## Требования

Python 3.11+ с пакетами `numpy`, `numba`, `scipy`, `soundfile`, `pystoi`, команды `clang -target avr`, `llvm-objcopy`, Node.js, `ffmpeg` для исходных MP3.

```bash
pip install -r requirements.txt

# Повторить сборку на сохранённых лучших параметрах:
python build_verify.py
node verify_avr.js
python make_player.py

# Дополнительный подбор на выбранной записи (перезаписывает trained.npz):
python optimize.py --voice chego --seconds 60 --seed 513
python polish_timbre.py --voice chego --seconds 20 --min-stoi 0.9001
python build_verify.py && node verify_avr.js && python make_player.py

# Сконвертировать другой исходный файл в новый 7500-Гц эталон:
python convert_audio.py --input voice.mp3 --output voice.wav
```

Внимание: скрипты оптимизации HQ4 **требуют начального потока HQ3 для той же записи**. `convert_audio.py` лишь подготавливает звук, но сам по себе не генерирует первую LPC-кодировку произвольной речи. Уменьшение ошибок на заранее известных записях достигается подбором отдельных параметров и не переносится автоматически на другие голоса.

Архив `Private` содержит фрагменты мультфильмов и производные речевые данные, предназначенные только для частных экспериментов. `Source` не содержит этих записей или закодированной речи; используйте его в публичном репозитории.
