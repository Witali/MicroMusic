# HQ4-T: восстановление спектрального наклона

Эксперимент 2026-10-23 для фразы «Чего тебе нужно?». В LPC2 Improved из
`ATmega328/Sound/reference/lpx3/lpc2_v2_reference.html` после LPC-синтеза есть
de-emphasis. В исходном HQ4 такой стадии нет. Здесь проверен компактный аналог
в настоящей прошивке ATtiny13A, с повторным подбором кадров под новый декодер.

Это первый шаг к более естественному тембру. Полный LPC2 с LSF-интерполяцией,
10-коэффициентным фильтром и формантным постфильтром на ATtiny13 не перенесён.
Нельзя считать уменьшение спектральной ошибки доказательством лучшего звучания.
Результат нужно оценить на слух рядом с исходным HQ4 при одинаковой громкости.

## Изменение декодера

После сохранения результата lattice, перед записью PWM:

```text
y[n] = s8(x[n] + y[n-1] - (y[n-1] >> 2))
```

`x` и `y` — знаковые 8-битные значения. Сдвиг арифметический, сложение AVR
с переполнением по модулю 256; насыщения нет. Начальное состояние `y[-1] = 0`
хранится в R11. На границе повтора оно сохраняется, как и lattice-состояния.
Фильтр не подмешивается в обратную связь LPC. Целочисленное округление
отличается от идеального умножения на 0,75 и учтено в точной модели.

Добавлено семь инструкций на отсчёт и инициализация регистра: **16 байт**.
Декодер вырос с 406 до **422 байт**. Формат кадров, 8 ступеней lattice,
возбуждение, сброс фазы на границах кадров и частота 7500 Гц сохранены.
Тот же поток прочтётся старым декодером, но даст другой звук: профиль
декодера является частью результата и должен храниться вместе с потоком.

## Результаты на каноническом WAV

| Показатель | HQ4 balanced | HQ4-T |
|---|---:|---:|
| Flash: код + речь + маркер | 959 Б | **979 Б** |
| STOI | 0,9006005 | **0,9005003** |
| Нормированная спектральная ошибка | 1,17455 | **0,74184** |
| Та же ошибка после общего highpass 70 Гц | 1,27693 | **0,98023** |
| Скачки ≥48 отсчётов PWM, первый проход | 0 | **0** |

Спектральная ошибка уменьшилась на **36,84%**; после общего среза НЧ —
на **23,24%**. Разница STOI −0,0001002. Формула метрики документирована
в `../hq4_timbre.py`: RMS-выравнивание, окна 128/256/512, модуль разности
логарифмов STFT. Это метрика данного эксперимента, не шкала MOS/PESQ.
Она отличается от исторического `spec` в отчётах HQ4.

Подбор выполнен на самой этой фразе: 8 проходов, seed 23061, 31 682 проверки,
124 принятых изменения, ограничение STOI ≥0,9005. Данные не являются
проверкой обобщения на другие голоса. Полная история: `chego/training.json`;
метрики и версии библиотек: `chego/quality.json`.

Все **27 648 отсчётов трёх повторов** совпали с независимой численной моделью
в JS, WASM и WASM с выключенными оптимизациями исполнения. Проверены также
память и счётчики процессора. Потерь Timer0 и отсчётов нет, интервалы
1279…1281 такт при номинале 1280; максимум ISR 28 тактов. Стек не опускается
ниже 0x99. Отчёт и хеши исходников: `chego/verification.json`.
Проверки программные; физический ATtiny13A в этом эксперименте не измерялся.

## Воспроизведение и сравнение

На сайте: `web-player/?collection=hq4&firmware=hq4-chego-timbre`.
Исходный вариант остаётся по `firmware=hq4-chego`.
Оба исполняют AVR HEX; браузер не заменяет синтез заранее записанным WAV.

HQ4-T громче на выходе. Флажок «Выровнять громкость HQ4 / HQ4-T» изменяет
только уровень прослушивания, сохраняя PWM и прошивку. Коэффициент 0,5094587365
измерен через реальный тракт плеера: 48 кГц, RC 9 кГц, первый проход фразы.
При других частотах среза соответствие приближённое.

## Воспроизводимость

Из корня репозитория; зависимости `codec/requirements.txt`, AVR GCC и Node.js:

```text
python tools/build-hq4-timbre.py --avr-bin build/toolchains/avr-7.3.0/bin --check
python tools/build-hq4-catalog.py --avr-bin build/toolchains/avr-7.3.0/bin --check
node --test web-player/tests/hq4-catalog.test.mjs
```

Для повторного обучения нужен внешний канонический WAV из `audio-references.json`.
Его SHA-256 проверяется до запуска; исходная запись и слушательские WAV в Git
не добавляются. Параметры сохраняются в указанный временный каталог:

```text
python tools/tune-hq4-timbre.py --reference C:/external/chego-original.wav --output build/hq4-search
python tools/report-hq4-timbre.py --reference C:/external/chego-original.wav --output build/hq4-listening
```

Второй сценарий создаёт WAV «оригинал → HQ4 → оригинал → HQ4-T», с общим
highpass 70 Гц, одинаковым RMS и запасом по пику. `chego/speech.hq` и
`chego/firmware.S` — сохранённые источники; бинарные сборки остаются в `build/`.

`tools/compare-lpc2-reference.mjs` позволяет отдельно исполнить сохранённые
функции эталонного LPC2 на float32 PCM без браузера. Размер его потока
не включает AVR-декодер. Страница по умолчанию работает на 16 кГц, поэтому
сравнивать её напрямую с ограниченным 7,5 кГц HQ4 без общей записи и настроек
нельзя. Субъективное предпочтение LPC2 не противоречит высокому STOI HQ4.
