# MicroMusic — LPC2 Improved → ATtiny13A (LPC2-Lite experiment)

**Цель:** приблизить звук предельно компактного речевого синтезатора ATtiny13A к нашему LPC2 Improved, не выдавая экспериментальный TinyLPC за полный декодер LPC2. Пример использует оригинальный загруженный пользователем фрагмент «Сова! Открывай! Медведь пришёл!» только для частного сравнения.

## Что проверено

- **v5:** старый семиступенчатый LPC с 7,5 кГц PCM и 37,5 кГц PWM.
- **`pitch_glide/`:** 7-ступенчатый синтезатор; изменение периода F₀ до ±4 отсчётов сглаживается, шаг 1 через 8 PCM-отсчётов. У крупных скачков период меняется сразу, чтобы не искажать артикуляцию. Тишина упакована командами повторения; «немые» кадры с ненулевым периодом сохраняются отдельно, чтобы не изменить фазу генератора и последовательность LFSR.
- **`mixed_excitation/`:** тот же фильтр, плюс периодическое возбуждение с небольшим псевдошумом (режим `mixed`), выбираемое по кадрам из `lpc2_improved_reference.lp2`. Режим был выбран офлайн — ATtiny13A не декодирует оригинальный LPC2-поток.
- **`lpc2_improved_reference.lp2`:** оригинальный экспериментальный LPC2 Improved v11 для сравнения. Он содержит 10-коэффициентную LSF-модель, частоту основного тона, тип возбуждения и энергию. Это **не** формат для ATtiny13A.

## Проверка качества на исходной фразе

| Вариант | Flash | Речь | STOI ↑ | Ошибка спектра ↓ | Наибольший скачок PCM |
|---|---:|---:|---:|---:|---:|
| TinyLPC v5 | 1012 Б | 435 Б | 0.7789 | 0.5164 | 54 |
| LPC2-Lite F₀ | **1012 Б** | **343 Б** | 0.7780 | 0.5195 | 54 |
| LPC2-Lite mixed | 1020 Б | 343 Б | 0.7573 | 0.5388 | 54 |

Сжатие пауз экономит **92 байта речевых данных** без изменения количества речевых кадров. Для проверки базового упакованного потока получено **22 272 побайтово совпадающих PCM-отсчёта** с v5 (до добавления новой обработки). Небольшая интерполяция F₀ влияет на 2901 отсчёт; режим mixed — на 6065 отсчётов. Метрики показывают, что **пока это не улучшение объективного качества относительно v5**. Предпочтение пользователя LPC2 Improved по тембру остаётся основанием для дальнейшей работы, но эти облегчённые режимы не воспроизводят его 10-полюсный фильтр.

- Проверено исполнение HEX независимым от AVR-прошивки JS-эмулятором инструкций.
- У обеих новых сборок: **22 272 аудиоотсчёта**, **111 360 переполнений Timer0**, `missedTimerOverflows = 0`, `maxISR = 60` тактов, `maxStack = 8` байт, без замеченных нехваток данных кольцевого буфера.
- Частота CPU — 9,6 МГц, делитель CKDIV8 отключён. Выход **PB1 / OC0B**, аппаратный Fast PWM 37,5 кГц. ISR обновляет duty в OCR0B каждые 5 переполнений; главный цикл генерирует 8-битный PCM в 16-байтный кольцевой буфер SRAM.
- Это проверка эмуляцией, **не** измерение на микросхеме. RC-фильтр, кварц/RC генератор, громкоговоритель могут добавить слышимые отличия.

## Формат данных Lite

- Обычный кадр: 5 байт (`pitch`, `gain + K0`, `K1 + K2`, `K3 + K4`, `K5 + K6`). Длительность 256 отсчётов, примерно 34,13 мс.
- Команды `0xE1 ... 0xFE`: последовательность от 1 до 30 кадров полной тишины, 1 байт вместо 5 байт/кадр.
- `0xFF`: переход в начало звукового потока.
- Для `mixed_excitation`: старший бит первого байта (периода) переключает примесь шума, только если период основного тона ≤ 95 отсчётов. Для `pitch_glide` этот бит не используется. Повторения и мягкий F₀ не превращают битстрим в LPC2 Improved — это независимый компактный формат.

## Как прослушать

Откройте `MicroMusic_LPC2_Lite_Emulator.html` в браузере. В нём пять вариантов: оригинал, LPC2 Improved, v5, LPC2-Lite F₀, LPC2-Lite mixed. HTML автономен: в режиме AVR выполняются настоящие машинные инструкции Intel HEX. Есть A/B с оригиналом, осциллограмма и скачивание WAV.

Дополнительно `MicroMusic_AB_LPC2_Lite.wav` содержит последовательное воспроизведение всех пяти вариантов с примерно одинаковой воспринимаемой громкостью (пиковый лимитер, без динамической компрессии).

## Повторить сборку

Нужны Python 3, NumPy, Clang c AVR backend, `llvm-objcopy` и Node.js. Из корня проекта:

```bash
cd pitch_glide
python3 package_stream.py
python3 build_firmware.py
node verify.js

cd ../mixed_excitation
python3 package_stream.py
python3 build_firmware.py
node verify.js
```

`verified_metrics.json` содержит оценки, полученные из конкретных машинных кодов.

## Следующий реальный шаг к LPC2 Improved

ATtiny13A слишком мал для прямого LPC2 Improved с десятью коэффициентами, LSF-конвертацией, восьмью подкадрами интерполяции и спектральным постфильтром. Для качественного улучшения в 1 КБ стоит испытать кодбук спектральных паттернов и спектральный tilt-постфильтр, оптимизируя их **вместе** по исходной записи, а не независимо. Приоритет — уменьшение спектральной ошибки и субъективная разборчивость при сохранении 1 КБ, без попытки копировать каждую функцию исходного LPC2 буквально. Для близости к полному LPC2 Improved разумнее использовать MCU с 4–8 КБ Flash или внешний контроллер/плеер.
