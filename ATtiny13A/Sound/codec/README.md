# MicroMusic / TinyLPC v5 — harmonic excitation research

Эксперимент по воспроизведению короткой русской реплики из исходного аудиофрагмента на **ATtiny13A (1024 Б Flash, 64 Б SRAM)**. Эта сборка предназначена для частного сравнения звучания; реальное устройство пока не измерялось.

## Результаты

| Показатель | v4: AVR HEX | v5: AVR HEX | 4 гармонических профиля (компьютерная модель) |
|---|---:|---:|---:|
| STOI по исходной записи | 0.78245 | 0.77885 | 0.78416 |
| Ошибка 24-полосной спектральной огибающей, ниже лучше | 0.55295 | 0.51643 | 0.53302 |
| Максимальный скачок между соседними 8-битными PCM-отсчётами | 75 | 54 | 56 |
| Скачков соседних отсчётов на 60 или более уровней | 20 | 0 | 0 |
| Flash, включая данные | 1012 Б | 1012 Б | не реализовано на AVR |
| Речевые данные | 435 Б | 435 Б | 435 Б исходных параметров + 22 Б профилей (расчёт, без декодера) |

STOI — метрика разборчивости, **не узнаваемости голоса**. Спектральная ошибка — собственная нормированная оценка спектральной огибающей в 24 полосах. Скачки соседних отсчётов — косвенный признак щелчков, а не их объективное измерение: импульсные согласные тоже могут давать большие производные.

### ATtiny13A v5: реально исполняемая прошивка

- 9.6 МГц CPU, Timer0 Fast PWM на PB1/OC0B, 37.5 кГц несущая и 7.5 кГц PCM, 16-байтный SRAM-буфер.
- 87 кадров по 5 байт: 8-битный период, 4-битная энергия, 7 коэффициентов отражения по 4 бита.
- Основной цикл генерирует PCM, ISR обновляет `OCR0B` каждый пятый период PWM.
- Уточнённый четырёхотсчётный импульс возбуждения **[2,3,2,-1]** вместо v4 **[5,3,0,-2]**. Он имеет другой набор относительных гармонических составляющих и меньший крутой фронт. К нему снова подбирались 7 LPC-коэффициентов и энергия для каждого кадра.
- После компиляции: **1012 / 1024 Б Flash**, **12 Б свободно**.
- В независимом тактовом AVR-эмуляторе: 111360 Timer0 ISR, `missedTimerOverflows=0`, `maxISR=60` тактов (лимит 256), `possibleAudioUnderruns=0`, `maxStack=8`.
- **22 272 / 22 272** 8-битных PCM-отсчёта независимой AVR-эмуляции совпали с точной численной моделью v5, включая переполнения и округление.

### Отдельный эксперимент: 4, 8, 12 гармоник

В `harmonic_bank_experiments.py` к обычному импульсу смешан ряд синусоидальных обертонов (4/8/12). Наборы с контролируемым спадом амплитуд выбирались по STOI, спектральной ошибке и крупным скачкам PCM. Затем `harmonic_profiles.py` выбирает один из четырёх вариантов для каждого речевого кадра (обычный импульс, 4, 8, 12 гармоник); в тесте использованы профили [65, 10, 6, 6] на 87 кадров.

Два бита на выбор профиля × 87 кадров = **174 бита, или 22 байта** без учёта упаковки/декодера/таблиц. **Эти гармонические режимы не исполняются на ATtiny13A** — они запускаются на компьютере и используются только как цель оптимизации. Добавление 22 байт к уже 1012 байтам превышает Flash на 10 байт, не считая дополнительного кода, так что для переноса требуется новый компактный формат.

Проверена идея дифференциального хранения высоты тона: простое поле «тот же период (1 бит) / изменение в пределах ±15 (7 бит суммарно) / абсолютный период (10 бит суммарно)» на наших 87 кадрах занимает примерно **69 байт вместо 87**. Это пока оценка битстрима, не готовая декодирующая прошивка. Можно развивать энтропийное кодирование и серии одинаковых формантных паттернов.

## Прослушивание

- `index.html`: автономный HTML-плеер с оригиналом, AVR-прошивками v3/v4/v5, LPC1/LPC2 Improved и экспериментальными гармониками. Режимы v3/v4/v5 **исполняют AVR HEX**, остальные — браузерные декодеры или вычисленные офлайн модели.
- `TinyLPC_v5_AVR.wav`: необработанный цифровой звук из тактовой модели v5.
- `TinyLPC_v5_AB_original_v4_v5_harmonics.wav`: сравнение на приблизительно выровненной громкости: оригинал → v4 → оригинал → v5 → оригинал → 4 спектральных профиля.
- `harmonics_4_test.wav`, `harmonics_8_test.wav`, `harmonics_12_test.wav`: результаты программной модели; не AVR.
- `spectrogram_v5.png`: спектрограммы оригинала, v4 AVR, v5 AVR, четырёх профилей.

## Сборка и воспроизведение

```bash
cd firmware_broadband
python3 package_stream.py
python3 build_firmware.py
node verify.js
```

Для обработки/подбора на компьютере нужны Python 3, NumPy, SciPy, SoundFile, Numba, `pystoi`, Matplotlib, scikit-learn (для `codec_pattern_experiment.py`), LLVM/Clang AVR и Node.js. Исходные скрипты `harmonic_bank_experiments.py` и `harmonic_profiles.py` работают в корне проекта, используя исходный голос и параметры от v4. `optimize_compact_excitation.py` воспроизводит подбор для новой четырёхотсчётной формы возбуждения (полный поиск может быть длительным). При каждой правке ассемблера обязательны повторная AVR-эмуляция и сравнение отсчётов с математической моделью.

## Ограничения и публикация

- В 1 КБ ещё нет полного LPC2 Improved: десятиполюсного фильтра, LSF-параметров, смешанного возбуждения и спектрального постфильтра. Форматы *не* совместимы побитово.
- Тесты проведены в браузере и независимом AVR-эмуляторе, не на физическом микроконтроллере; внешний фильтр PWM и громкоговоритель повлияют на звук.
- В этом частном архиве содержится оригинальная запись из мультфильма и производные от неё. **Для открытого GitHub нужно заменить её записью, на которую есть права, а также исключить производные аудиоданные/HEX с этой фразой.** Код кодека можно публиковать отдельно, предварительно удалив исходные записи.
