MicroMusic · MiniLPC-HQ4

Оптимизация MiniLPC по оригинальным записям с контролем STOI, спектра и щелчков. Код AVR не увеличен; изменены только речевые данные. Для AVR играет именно результат выполнения HEX; в обычном режиме используется уже проверенный PCM-кэш.

Готово. Нажмите «Слушать» для воспроизведения.

Проверка реальной прошивки

Кнопка «Выполнить HEX в эмуляторе» заново исполняет машинные инструкции AVR с подсчётом тактов, проверяет Timer0, обновления OCR0B, каждую выходную выборку и затем воспроизводит результат. Эта операция может быть медленной на телефоне.

Данные проверки появятся после запуска эмулятора.

Как устроен новый формат

Никакой поддержки старых форматов в прошивке: одна новая последовательность кадров длиной 64, 128 или 256 отсчётов. Короткий код содержит период 0–63 и длительность 64/128/256 отсчётов. При периодах 64–126 используется расширенный двухбайтовый код. Кадр дополнительно хранит громкость и один из четырёх импульсных профилей; LPC-коэффициенты передаются целиком, частично или повторяются с предыдущего кадра. Прошивка не поддерживает старую разметку кадров.

Показатель STOI измеряет преимущественно разборчивость. Оптимизация выполнялась на самих этих фразах, поэтому результаты не являются оценкой качества на неизвестной речи. Здесь LPX3 и оригинал представлены заранее декодированными эталонными WAV, а не AVR-прошивками. Исходные фрагменты — для частных экспериментов.
