# Компактная упаковка параметров без изменения звука

`compact_period.py` упаковывает модели `period-residual-v1` и
`period-colored-v1`. Кадр по-прежнему длится 64 отсчёта; переменную длину
имеет запись его параметров. На выходе распаковки получается обычная модель,
которую проверяет независимый декодер. Его float PCM совпадает точно.

Все шаги фазы сохраняются, в том числе в паузах. В кадре с нулевым уровнем
можно не хранить индекс и голосовой режим: они умножаются на ноль. Аналогично
при нулевом остатке не нужен его цвет. Только эти неиспользуемые поля
канонизируются; данные звучащих кадров не изменяются.

## Формат PX v1

- Заголовок `<4sBHHHH`, 13 байт: `PX 01 00`, флаг цветного остатка,
  количество отсчётов, начальная фаза, масштаб периодов, масштаб остатка.
- Таблица периодов: 256 байт, два знаковых 4-битных значения на байт.
  Она остаётся пригодной для прямого чтения из Flash.
- Для цветного остатка ещё 12 байт симметричных FIR, как в PC v1.
- Далее единый поток битов, младшими битами вперёд. Частота: `0` — прежняя;
  `10s` — изменение ±1; `110xxx` — изменения ±2…±5; `111xxxxxxxx` — абсолютная.
- Основной уровень: бит повтора либо бит изменения + 3 бита значения.
  При ненулевом уровне следуют голосовой бит и индекс: повтор либо 4 бита.
- Уровень остатка: повтор либо 4 бита. При ненулевом уровне цветного остатка
  следует цвет: повтор либо 2 бита. Предыдущее значение каждого поля отдельное,
  не сбрасывается при пропуске неиспользуемого поля.
- Последний байт дополнен нулевыми битами. Число кадров известно по длине
  звука. Лишние данные, ненулевое дополнение и обрезанные поля отклоняются.

Это последовательный формат; WAV и временные точки поиска в Git не хранятся.
Поток не включает исполняемый декодер, константы AVR, таблицу векторов или стек.
PC-распаковка не доказывает пригодность реализации для 64 байт SRAM.

## Измерение на автоматически обученном словаре

| Запись | PC v1, байт | PX v1, байт | Свободно из 1024 Б после данных |
|---|---:|---:|---:|
| Чего… | 680 | 516 | 508 |
| Отвечаешь… | 625 | 509 | 515 |
| Винни… | 1241 | 883 | 141 |

Источник — сохранённые `../research/period-book/<clip>/model.json`.
Связь с хешами моделей/исходников: `../research/compact-period.json`.
На последующих моделях размер может меняться в зависимости от числа повторов.
141 байт остатка Винни слишком мало для предполагаемого полного декодера:
для длинной записи всё ещё нужны более компактная модель/длительности кадров.

Проверка `python tools/test-compact-period.py` охватывает изменения частоты,
паузы, случайные уровни/режимы, обе версии остатка, повреждённые потоки,
повторную упаковку и точное совпадение выходного звука.
