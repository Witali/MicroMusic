MicroMusic VBR LPC-8

Эксперимент с переменной длиной речевых кадров для ATtiny13A: 8-ступенчатый LPC, четыре профиля возбуждения, 7,5 кГц PCM и 37,5 кГц PWM.

Готово. Нажмите «Слушать».

Размер и качество

Flash, код + речь
Речевые данные VBR
Экономия Flash
STOI VBR / старый

Осциллограмма

Воспроизведение — через Web Audio. Для AVR-прошивки используется WAV, предварительно полученный исполнением HEX. Кнопка проверки ниже повторяет машинную эмуляцию.

Эмуляция и файлы

Прошивка на 9,6 МГц, Timer0 Fast PWM, выход PB1/OC0B.

Новый формат речевых кадров

Байт 0: pitch (0 = шум)
Байт 1: gain[3:0] | profile[5:4] | type[7:6]

00: полный кадр         6 байт (8 LPC-коэффициентов)
01: повтор спектра       2 байта (новые pitch/gain)
10: изменить K1–K4      4 байта
11: изменить K5–K8      4 байта

Этот битовый поток — новый формат. Старый формат в AVR-декодере не поддерживается. Кодировщик автоматически выбирает тип кадров через обратное сравнение с исходным звуком и штраф за щелчки. Вариант с фиксированными кадрами показан только для сравнения.

Записи из мультфильмов включены для частного тестирования. Для публикации в открытом репозитории необходимо исключить защищённые аудиофрагменты и производные данные без разрешения правообладателей. Работа на физическом ATtiny13A пока не проверялась.
