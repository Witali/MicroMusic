Оптимизация декодера без изменения формата речи. Код уменьшен с 406 до 388 байт, обработчик PWM — с 28 до 19 тактов. На трёх записях звук совпадает с предыдущей прошивкой отсчёт в отсчёт.

Что проверяет эмулятор?

По нажатию кнопки он исполняет инструкции AVR из встроенного двоичного образа, обрабатывает Timer0 и OCR0B, затем сравнивает каждый PWM-отсчёт с сохранённой контрольной последовательностью. Выполнение происходит порциями, чтобы на телефоне интерфейс не зависал.

Это программное моделирование ATtiny13A, а не испытание на физическом чипе. Данные речи предназначены для частного исследования; не публикуйте производные записи без прав.
