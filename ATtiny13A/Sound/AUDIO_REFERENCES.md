# Звуковые эталоны HQ4

[Публичный HQ4-плеер](https://witali.github.io/MicroMusic/web-player/?collection=hq4)
исполняет три варианта HQ4-T и четыре сохранённых образа HQ4 на общем JS/WASM-движке и работает без
локального архива. Каталог `web-player/hq4-firmware.json` пересобирается из
сохранённого ассемблера сценарием `tools/build-hq4-catalog.py`.

Ссылки на исходную переписку:

- [Название репозитория MicroMusic](https://chatgpt.com/c/6ad737b6-d9b8-83eb-9298-fcb1d0856e90).
- [Перенос разработки MicroMusic](https://chatgpt.com/c/6ad9c364-09e8-83ed-ad79-cb6f32ac3a87).

Чаты доступны при наличии доступа к исходной переписке. WAV сохранены во внешнем
архиве `MicroMusic_COMPLETE_RESEARCH_HANDOFF_2026-10-22(2).zip`, на текущем
компьютере — в каталоге Downloads. Имя архива, SHA-256, точные пути внутри ZIP и
хеши WAV записаны в [audio-references.json](audio-references.json).
Этих данных достаточно, чтобы проверить найденную копию независимо от её
расположения или нового имени после повторного скачивания.

| ID | Фраза | Канонический WAV | Первоначальное вложение |

| `chego` | Чего тебе нужно? | 9 216 отсчётов · 1,2288 с | `xtuj-ntt.mp3` |

| `vinni` | Сова! Открывай! Медведь пришёл! | 22 272 отсчёта · 2,9696 с | `vinni-pux-3654654.mp3` |

Все три эталона: моно, 7 500 Гц, PCM 16 бит. Поле `training_path` указывает
путь относительно `ATtiny13A/Sound`, который ожидают сохранённые скрипты обучения.

Подготовка прослушивания в общем плеере из корня репозитория:

```text
python tools/prepare-hq4-preview.py --archive "<Downloads>/MicroMusic_COMPLETE_RESEARCH_HANDOFF_2026-10-22(2).zip"
node web-player/scripts/serve.mjs 8145
```

Адрес: `http://127.0.0.1:8145/web-player/?collection=hq4`.
Сценарий проверяет SHA-256 архива, оригинальных WAV, Flash и контрольного PCM.
На localhost плеер подхватывает эти дополнительные материалы из `build`;
публичный сайт загружает каталог прошивок, включённый в репозиторий.
Доступны три balanced-образа, maximum-STOI для первой фразы, оригиналы WAV и
ссылка на сохранённый плеер из ChatGPT. [Сверка эмуляторов](../../web-player/reports/hq4-audit-2026-10-22.md).

В `MicroMusic_HQ4_Full_Private.zip` также есть эти три WAV по путям
`MicroMusic_HQ4/MicroMusic_HQ3_Verified_Release/<ID>/original.wav`.
Его SHA-256: `13249f7cd65dba19980a54f3d726d2702a94f04868e1b8cdd0d2f6eb2aca25a4`.
Этот архив содержит более ранний HQ4-плеер; актуальные balanced/max-STOI образы
и соответствующий плеер нужно брать из полного handoff, указанного в JSON.

Сжатая речь, параметры обучения, ассемблер и результаты находятся в Git.
Оригинальные аудиозаписи и ZIP хранятся снаружи репозитория; локальные
восстановленные WAV и предпросмотры относятся к игнорируемым сборочным данным.
