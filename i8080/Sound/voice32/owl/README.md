# «Сова! Открывай! Медведь пришёл!» — Intel 8080

**[BIN 32 КиБ](owl-voice32.bin)** / [Intel HEX](owl-voice32.hex).
КР580ВМ80 / Intel 8080, 3,5 МГц, выход INTE, без ОЗУ.
После RESET начинается воспроизведение: **диагностических тестов, гудков
и отдельного плавного старта нет**. Первый фронт PWM — через 95 T / 27,143 мкс.
Начальная пауза самой записи сохранена.

Использован тот же [движок PCM4](../README.md): **16 линейных уровней**,
два одинаковых импульса на отсчёт, период **109 T**, PWM **32 110,09 Гц**,
обновление звука **16 055,05 Гц**. Длительность записи — 3,38012 с;
отклонение от исходника меньше 0,13 мс. Это пересчёт частоты, без ускорения речи.

Исходный `vinni-pux-3654654.mp3` восстановлен из сохранённого архива и совпал
байт-в-байт с файлом со [страницы Zvukipro](https://zvukipro.com/mult/2937-zvuki-iz-sovetskogo-multfilma-vinni-puh.html).
SHA-256: `e0061b8416ea19fef7103bd0f2d4bc7cce2a51523ec935e544f9d5b471b0db44`.
Эта же фраза определена в [корпусе ATtiny13A](../../../../ATtiny13A/Sound/audio-references.json).
Имя имеет расширение MP3, фактический контейнер/кодек — M4A/AAC;
параметры, хеши и происхождение — в [SOURCE.json](SOURCE.json).

Сохранены [WAV 16 кГц](source-16000.wav) и [упакованные отсчёты](pcm4.json):
54 268 отсчётов, 27 134 байта. Источник заново нормализован по пикам:
минимум → код 0, максимум → 15; исходные пики не обрезаны. Применяется одно
линейное преобразование ко всей фразе, без компрессии динамики. Код тишины — 7.
SNR квантования — 14,37 дБ относительно линейно восстановленного оригинала.
Это оценка PCM, без аналогового фильтра и аппаратуры; прежний вариант
подбирал усиление с ограничением пиков и имел другую ошибку квантования.

Используются общие [build.py](../build.py), [prepare.py](../prepare.py) и
переносимый C-интерфейс [voice.h](../voice.h) / [voice.c](../voice.c).
C остаётся явно доступным и выбран по умолчанию. ASM ROM требует отдельного
выбора архитектуры и разрешения ASM; заголовок использует реальный макрос
`__8080` и `MICROMUSIC_ENABLE_I8080_ASM=1`.

```powershell
python i8080/Sound/voice32/prepare.py --profile owl --source C:/external/vinni-pux-3654654.mp3
python i8080/Sound/voice32/prepare.py --profile owl --check
python i8080/Sound/voice32/build.py --profile owl --backend i8080-asm --architecture i8080 --enable-asm
python i8080/Sound/voice32/build.py --profile owl --backend i8080-asm --architecture i8080 --enable-asm --check
node --test i8080/Sound/voice32/owl/pwm.test.mjs
```

Прямая ROM использует всю память под код/PCM; адресных проверок и CRC-футеров
диагностической прошивки здесь нет. [AUDIT.json](AUDIT.json) подтверждает
совпадение всех ширин с общей C99-версией, нулевое число записей памяти,
отсутствие стартовых гудков и 108 535 интервалов ровно по 109 T.
[TIMING.json](TIMING.json) — отдельная проверка тактов и 1552 сочетаний
уровней/ветвей с нулевой ошибкой относительно программной сетки.

Проверено в эмуляторе, на физической плате не испытывалось. INT должен
оставаться неактивным; WAIT/HOLD нарушат расписание. Активные прерывания
и электрические фронты этими проверками не покрываются.
