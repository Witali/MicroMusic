# Оптимизированная диагностика Intel 8080: общая звуковая процедура

Этот пакет — модификация исходного образа с быстрой таблицей CRC16.
Вместо дублированных фрагментов подачи звуковых сигналов используется одна
общая процедура. Все инструкции относятся к набору Intel 8080, не нужен RAM.
Код звуковой сигнализации: 434 → 72 байта, экономия 362 байта.

Параметры передаются регистрами: D — количество сигналов, E — длина сигнала
(число периодов), H — старший байт счётчика задержки между сигналами.
Для успеха 3×90 периодов, паузы 0x4100; для ошибки 1–4×230 периодов,
паузы 0x4A00. Тоновой цикл EI/DI сохранён; небольшие изменения в
длительности пауз вызваны служебными переходами между повторами.

Важно: общий звуковой цикл не использует RET — это ещё более компактная
альтернатива нескольким вызовам RET из ROM, поскольку число сигналов
передаётся счётчиком. Исходный тест инструкций RET/PCHL остаётся.

Образ ПЗУ пересобран с новой CRC16-коррекцией. Все доступные сценарии
эмулятора пройдены; результаты в emulator_tests.json.

# Intel 8080: быстрая CRC-16 / 64 КБ

Процессор: Intel 8080 (только документированные инструкции), такт 3,5 МГц в модели.
ОЗУ не используется. Звук через INTE; вход INT должен быть неактивным.

## Что изменено

CRC-16 полином 0x002D, init=0000, без отражения, XOR-out=0000.
Проверка всего физического ПЗУ включая 2 байта коррекции; итог CRC=0000.
Таблица старшего байта CRC: 1C00h..1CFFh (256 байт).
Таблица младшего байта CRC: 1D00h..1DFFh (256 байт).
CRC хранится в паре BC; DE адрес читавшегося байта; HL табличный указатель.
Внешний генератор на Python создаёт таблицы и подбирает 2 байта коррекции.

Скорость основного CRC-цикла: 80 T/байт.
Полный исправный запуск: 8.180431 с ранее → 2.057496 с теперь.
Записей в память в эмуляции: 0. Сценариев проверено: 12.

## Файлы

- build.py — воспроизводимая сборка, CRC-коррекция, BIN/HEX, полный ASM.
- Intel8080_ROM*_Diagnostic.asm — прокомментированный исходный ASM.
- Intel8080_ROM*_FULL.asm — полный образ, заданный DB/инструкциями.
- Intel8080_ROM*.bin — прошивка для физической памяти.
- Intel8080_ROM*.hex — Intel HEX.
- verify_8080.js — эмуляционные тесты, включая повреждения и проверку отсутствия записей.
- build_report.json / emulator_tests.json — результаты.

## Дополнительные замечания

32 КБ: A15 не подключена к микросхеме ПЗУ, проверяется A0..A14, CRC до 7FFFh.
64 КБ: A15 подключена и проверяется, CRC до FFFFh.
Специальные контрольные байты: FFF0-FFF1.
Коды INTE и остальные аппаратные тесты из предыдущей сборки не изменены.
При штатном окончании — 3 коротких сигнала, затем DI и HLT.
При ошибке — 1..4 длинных сигнала, затем DI и HLT.
Физическая проверка на реальной плате пока не выполнена.
Стандартный Intel 8080A не гарантирует работу на частоте 3,5 МГц.
