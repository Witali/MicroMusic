# Intel 8080 ROM-only diagnostic — компактная звуковая сигнализация

Это переработанная версия **Intel_8080_32K_64K_ROM_Diagnostic_FAST_CRC16_INTE**.
Используется единая процедура формирования повторяющихся гудков через INTE.
Прошивка не требует ОЗУ и не записывает ничего в память.

**Итог:** звуковая часть 434 → 72 байта, экономия **362 байта**.
32 КБ: 3585 → 3223 байта программного кода. 64 КБ: 3620 → 3258 байт.

Проверено с встроенным эмулятором 8080: 9 сценариев (32 КБ),
12 сценариев (64 КБ, проверены в трёх независимых группах).
Результаты включают правильное число сигналов EI и нулевые записи в ОЗУ.
CRC-16 всех физических ROM проверена независимым побитным расчётом: 0000.

Оставлены исходные тесты PCHL и RET, тесты всех команд и адресов,
ускоренная таблица CRC16. Файл build.py пересобирает прошивку и подбирает
финальные 2 байта CRC, verify_8080.js проверяет сценарии эмулятора.

**Оговорка:** это проверка в эмуляторе. На реальной плате прошивка
дополнительно нуждается в проверке. Номинальные времена звука могут немного
измениться на границах гудков из-за оптимизации управляющих переходов.
