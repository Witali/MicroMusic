# CRC16: алгоритмы и полученные варианты

Для исходной платы без ОЗУ разработаны одиночные CRC16 и совместная проверка двумя разными CRC16. Все основные варианты обрабатывают биты от старшего к младшему, init 0, xorout 0, без отражения. Точные профили: [PARAMETERS.json](PARAMETERS.json).

## Как работает итоговая пара

`G25 = x^16+x^5+x^2+1`, `G47 = x^16+x^6+x^2+x+1`. Их произведение над GF(2) — `1006209BBh`, полиномы взаимно просты. Четыре байта `FFFCh–FFFFh` содержат big-endian остаток произведения по первым 65532 Б; после добавления поля обе CRC полного ПЗУ равны нулю. Это единое контрольное поле, а не конкатенация двух независимо вычисленных CRC16.

В минимальном варианте `DAD H; SBB A; ANA C; XRA L; MOV L,A` выполняет битовый шаг, а один общий цикл используется для обоих полиномов. В быстрых версиях каждый проход использует свою формулу обновления целого байта. [Подробная спецификация](SPECIFICATION_RU.md), [история изменений](../HISTORY_RU.md).

Пара обнаруживает все одно-, двух- и трёхбитовые ошибки на 64 КиБ в математической модели исследования. Известная пропускаемая четырёхбитовая маска имеет степени `[0,1065,1278,3920]`. [Подбор и ограничения](POLYNOMIAL_SELECTION_RU.md).

## Сохранённые материалы

- `research/00…10/` — существенные этапы, ASM/BIN, генераторы, эмуляторы, математические тесты и необходимые регрессионные варианты.
- `data/` — дополнительные результаты поиска, которые не повторяют уже сохранённые CSV этапов.
- [examples/dual_0025_0047_min42_64KiB.bin](examples/dual_0025_0047_min42_64KiB.bin) — готовый пример минимальной проверки полного ПЗУ.
- [integration/no-ram-diagnostics](integration/no-ram-diagnostics/README_RU.md) — самостоятельная диагностика на 32/64 КиБ с одиночной табличной CRC16 `002D`, проверкой адресных линий и звуковой индикацией. Поле коррекции размещено внутри последних 16 байтов; использовать её собственный `build.py`.

Общая проверка перенесённых материалов: `python i8080/CRC/verify.py` из корня репозитория. Она выполняет сборки и испытания в `build/`, не изменяя архивные исходники. Инструкции и фактический отчёт: [VALIDATION_RU.md](../VALIDATION_RU.md).
