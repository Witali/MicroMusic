Для платы без ОЗУ в последнем обсуждении CRC32C выбран приоритет малого кода: **74 байта без таблиц**. Табличный расчёт и генерация таблицы оставлены для быстрого вычисления CRC поступающих данных. Для пары CRC16 `0025+0047` сохранены разные компромиссы: **42 байта / 766 T/Б**, **75 байт / 288,118 T/Б**, **82 байта / 279,118 T/Б**. Эти числа относятся к разным размерам ПЗУ и алгоритмам; непосредственно сопоставлять секунды без учёта объёма нельзя.

Основные версии перечислены в README разделов. Каталоги `research/` содержат исторические варианты и регрессионные данные, необходимые для воспроизводимости. Старые документы в `history/` сохранены как первичные материалы; их прежние пути и рекомендации следует читать с учётом нынешней структуры и последующих результатов.

При переносе исключены повторные копии из `SELECTED_FIRMWARE`, повторяющиеся поисковые CSV, старые навигационные индексы и манифесты, производные HEX, полные листинги уже сохранённых образов и варианты CRC32C с отличающимся только выходом `EI/JMP`. Генераторы позволяют восстановить эти представления. Самостоятельные варианты с разными полиномами, архитектурой или существенным соотношением размера и скорости сохранены. Исходные чаты и архивы не изменялись.

Параметры CRC определены в [CRC16/PARAMETERS.json](CRC16/PARAMETERS.json) и [CRC32/PARAMETERS.json](CRC32/PARAMETERS.json). Нельзя подменять нерефлектированную CRC32C стандартной отражённой CRC32C или смешивать их форматы контрольного поля.

Аудит по Intel выявил и исправил AC и такты XCHG в моделях диагностики, а также недостоверный специальный случай DAA в старых моделях. Основные ядра CRC и их BIN прошли повторное исполнение без изменений. Оригинальные и текущие хеши исправленных моделей записаны отдельно.

Все исторические измерения получены программно. Испытаний этих сборок на физическом Intel 8080 в источниках нет. После изменения прошивки необходимо пересчитывать контрольное поле соответствующим генератором.
